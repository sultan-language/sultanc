# جولة في اللغة

تعرّفك هذه الجولة بلغة السلطان من خلال برامج قصيرة مكتوبة بالكلمات المفتاحية العربية. وهي موجّهة إلى المبرمجين
الذين يعرفون لغة أنظمة أخرى ويريدون قراءة شيفرة السلطان وكتابتها. وكل مثال فيها يُترجَم بالنسخة الحالية من المترجم،
وفي كل قسم إحالة إلى صفحة المرجع التي تشرح قواعده كاملة.

## صياغتان للغة واحدة

العربية والإنجليزية صياغتان متكافئتان للشيفرة المصدرية: فلكل كلمة مفتاحية، ولكل اسم نوع، ولكل دالة في المكتبة
القياسية معنى واحد وكتابتان، ويحوّل المترجم الكتابتين إلى صورة واحدة قبل أي مرحلة لاحقة. ويمكن الجمع بين
الكتابتين في الملف الواحد، ويجوز أن تكتب الأسماء التي تعرّفها بأي من الخطين.

دالة البداية اسمها `الرئيسية` بالعربية و`main` بالإنجليزية، والقيمة التي ترجعها من النوع `عدد` هي حالة خروج
البرنامج. وتعرض النسخة الإنجليزية من هذه الجولة البرامج نفسها مكتوبة بالإنجليزية. وتجد المصطلحات كاملة في صفحة
[المصطلحات العربية](../reference/arabic-terminology.md).

## القيم والأنواع

يربط `دع` اسمًا بقيمة. ولا يمكن تغيير القيمة بعد ربطها إلا إذا سُبق نوعها بـ `متغير`، وعندها تُسنَد إليها قيمة
جديدة بـ `:=`. ويُكتب النوع بعد الاسم. وإذا جاء `دع` في المستوى الأعلى من الملف، خارج أي دالة، عرّف ثابتًا للوحدة
يُحسب في وقت الترجمة.

الأنواع المدمجة هي `عدد`، و`طبيعي`، و`منطقي`، و`حرف`، و`نص`، و`فراغ`، والأعداد الصحيحة ذات العرض الثابت
`ص8`…`ص64` و`ط8`…`ط64`، وأعداد الفاصلة العائمة `ع32` و`ع64`. ويجب أن يكون التحويل بين الأنواع البسيطة (scalar) صريحًا، ويُكتب بـ `مثل`.

```sultan
دع الحد: عدد = 100;

عرف الرئيسية(): عدد {
    دع البايت: ط8 = 255;
    دع النسبة: ع64 = 0.75;
    دع الحرف: حرف = 'س';
    دع الاسم: نص = "سلطان";
    دع العداد: متغير عدد = 0;
    العداد := العداد + 1;
    دع موسع: ص64 = (البايت مثل ص64) - 250;
    أرجع العداد + الحد + (موسع مثل عدد);
}
```

وتشرح صفحة [نظام الأنواع](../reference/type-system.md) نموذج الأنواع وقواعد التحويل بدقة.

## الدوال

تحدد الدالة أنواع معاملاتها ونوع القيمة التي ترجعها. والدوال المجهولة (التي لا اسم لها) تلتقط القيم المحيطة بها،
ويُكتب نوع الدالة على الصورة `دالة(عدد): عدد`. وتُكتب معاملات النوع العامة بين قوسين زاويين، مثل `<T>`.

```sultan
عرف أنشئ_جامعا(المقدار: عدد): دالة(عدد): عدد {
    أرجع دالة(القيمة: عدد): عدد -> القيمة + المقدار;
}

عرف هوية<T>(القيمة: T): T {
    أرجع القيمة;
}

عرف الرئيسية(): عدد {
    دع أضف_عشرة: دالة(عدد): عدد = أنشئ_جامعا(10);
    أرجع أضف_عشرة(هوية(5));
}
```

## التحكم في التدفق

يأخذ `إذا` شرطًا بين قوسين، وكتلًا بين معقوفين، وتنتهي جملته بفاصلة منقوطة. ويختبر `طالما` شرطه قبل كل دورة.
ويأتي `لكل` بصيغة لغة C: تهيئة، ثم شرط، ثم خطوة. ويعمل `تابع_حلقة` و`اخرج_من_حلقة` في الحلقتين كلتيهما.

```sultan
استورد المكتبة.دخ.println;
استورد المكتبة.نصوص.number;

عرف الرئيسية(): عدد {
    دع المجموع: متغير عدد = 0;
    دع ف: متغير عدد = 1;
    طالما (ف <= 5) {
        المجموع := المجموع + ف;
        ف := ف + 1;
    }
    لكل (دع ك: متغير عدد = 0; ك < 10; ك := ك + 1) {
        إذا (ك % 2 == 0) { تابع_حلقة; };
        إذا (ك > 6) { اخرج_من_حلقة; };
        المجموع := المجموع + ك;
    }
    إذا (المجموع > 20) {
        اطبع_سطر("كبير");
    } وإلا {
        اطبع_سطر("صغير");
    };
    اطبع_سطر(عدد_إلى_نص(المجموع));
    أرجع 0;
}
```

## السجلات والتعدادات ومطابقة الأنماط

يعرّف نوع السجل مجموعة من الحقول المسماة، وتُكتب قيمة السجل بين معقوفين، ويُقرأ الحقل بالنقطة. ويُستخدم `نوع`
أيضًا لإعطاء نوع موجود اسمًا آخر، كما في `نوع مئوي = عدد;`. أما التعداد فيسرد حالاته (منشئاته)، ويمكن أن تحمل كل
حالة قيمة يُحدَّد نوعها بـ `بنوع`. ويختار `طابق` الفرع المناسب بحسب النمط، ويتحقق المترجم من أن الفروع تغطي جميع
الحالات. وتستطيع الأنماط تفكيك القيم المحمولة والسجلات، ومطابقة القيم الحرفية للأعداد الصحيحة والحروف والنصوص،
والبدائل المفصولة بـ `|`، والمجالات.

```sultan
نوع نقطة = { س: عدد, ص: عدد };

نوع شكل =
    | دائرة بنوع عدد
    | مستطيل بنوع نقطة
    | نقطة_فقط
;

عرف المساحة(الشكل: شكل): عدد {
    طابق الشكل مع
    | شكل.دائرة(نق) -> { أرجع 3 * نق * نق; }
    | شكل.مستطيل({ س: العرض, ص: الارتفاع }) -> { أرجع العرض * الارتفاع; }
    | شكل.نقطة_فقط -> { أرجع 0; };
}

عرف الرئيسية(): عدد {
    دع الحجم: نقطة = { س: 3, ص: 4 };
    أرجع المساحة(شكل.دائرة(2)) + المساحة(شكل.مستطيل(الحجم)) + الحجم.س;
}
```

والمنشئ الذي لا يحمل قيمة يُكتب دون أقواس في النمط، ومع قوسين فارغين عند إنشاء القيمة، مثل `شكل.نقطة_فقط()`.

## المتجهات

`متجه T` تسلسل قابل للنمو يملك عناصره، وتُكتب قيمته الحرفية بين قوسين مربعين. ويُوصَل إلى العناصر بالفهرسة `[ ]`،
وتعطي الدالة `الطول` عدد العناصر، وتضيف `ألحق` عنصرًا إلى متجه معرَّف بـ `متغير`. وتمرير `&القيم` يُعير المتجه
دون التخلي عن ملكيته.

```sultan
عرف الرئيسية(): عدد {
    دع القيم: متغير متجه عدد = [10, 20];
    ألحق(القيم, 12);
    أرجع القيم[0] + القيم[2] + الطول(القيم);
}
```

## الملكية والاستعارة

لكل قيمة مالك واحد. وإذا استُخدمت قيمة مملوكة، مثل `نص` أو `متجه` أو سجل يحتوي على أحدهما، فإنها تُنقَل، ولا يعود
الاسم القديم صالحًا للاستخدام. أما القيم البسيطة مثل الأعداد فتُنسَخ. والمرجع `&T` يستعير القيمة للقراءة،
و`&متغير T` يستعيرها للكتابة، ويُوصَل إلى القيمة التي يشير إليها المرجع بـ `*`. وتنشئ الدالة `استنسخ` نسخة مستقلة
كاملة. ويتحقق المترجم من ذلك كله قبل توليد الشيفرة، ويحرر القيمة المملوكة عندما يخرج مالكها من نطاقه.

```sultan
استورد المكتبة.دخ.println;
استورد المكتبة.نصوص.number;

نوع حساب = { المالك: نص, الرصيد: عدد };

عرف أودع(الحساب: &متغير حساب, المقدار: عدد): فراغ {
    (*الحساب).الرصيد := (*الحساب).الرصيد + المقدار;
}

عرف أغلق(الحساب: حساب): نص {
    أرجع استنسخ(&الحساب.المالك);
}

عرف الرئيسية(): عدد {
    دع الحساب: متغير حساب = { المالك: "ليلى", الرصيد: 100 };
    أودع(&متغير الحساب, 50);
    اطبع_سطر(عدد_إلى_نص(الحساب.الرصيد));
    اطبع_سطر(أغلق(الحساب));
    أرجع 0;
}
```

تأخذ الدالة `أغلق` معاملها من النوع `حساب` بالقيمة، فيُنقَل `الحساب` إليها عند الاستدعاء. وأي استخدام لـ `الحساب`
بعد ذلك يرفضه المترجم بالخطأ `SULTANC-OWNERSHIP-USE-AFTER-MOVE`، الذي يشير إلى المالك الأصلي وإلى موضع النقل معًا.
ولا يمكن أن تجتمع استعارة للكتابة مع أي استعارة أخرى للقيمة نفسها (`SULTANC-BORROW-CONFLICT`)، ولا يمكن نقل قيمة
مملوكة إلى خارج موضع تخزين مستعار (`SULTANC-OWNERSHIP-MOVE-OUT-OF-REFERENCE`). وتشرح صفحة
[الملكية والإتلاف](../reference/ownership.md) القواعد كاملة، ونموذج الإتلاف، و`استنسخ`.

## الأخطاء

الفشل قيمة عادية. فالنوع `نتيجة T, E` يحمل إما `نتيجة.نجح(القيمة)` أو `نتيجة.خطأ(الخطأ)`، والنوع `اختياري T`
يحمل إما `اختياري.موجود(القيمة)` أو `اختياري.لا_شيء`. ويفكك `طابق` أيًّا منهما. أما العامل `؟` الذي يُكتب بعد
الاستدعاء، فيعيد الخطأ أو القيمة الغائبة إلى المستدعي، ويعطي القيمة في غير ذلك، كما في `دع ق: عدد = اقسم(أ, ب)؟;`.
ويجب أن يكون نوع الخطأ واحدًا في الدالة المستدعية والدالة المستدعاة.

```sultan
استورد المكتبة.دخ.println;
استورد المكتبة.نصوص.number;

عرف اقسم(أ: عدد, ب: عدد): نتيجة عدد, نص {
    إذا (ب == 0) { أرجع نتيجة.خطأ("القسمة على صفر"); };
    أرجع نتيجة.نجح(أ / ب);
}

عرف نصف_الناتج(أ: عدد, ب: عدد): نتيجة عدد, نص {
    دع ق: عدد = اقسم(أ, ب)؟;
    أرجع نتيجة.نجح(ق / 2);
}

عرف اطبع_النتيجة(ن: نتيجة عدد, نص): فراغ {
    طابق ن مع
    | نتيجة.نجح(ق) -> { اطبع_سطر(عدد_إلى_نص(ق)); }
    | نتيجة.خطأ(رسالة) -> { اطبع_سطر(رسالة); };
}

عرف الرئيسية(): عدد {
    اطبع_النتيجة(نصف_الناتج(84, 2));
    اطبع_النتيجة(نصف_الناتج(1, 0));
    أرجع 0;
}
```

توقف الدالة `إنهيار` البرنامج برسالة، وتُستخدم للحالات التي لا يُفترض أن تحدث أبدًا. ويجوز أن ترجع `الرئيسية` نفسها
قيمة من النوع `نتيجة`، وعندها يُطبع الخطأ وينتهي البرنامج بالحالة 1. وتشرح صفحة [الأخطاء](../reference/errors.md)
قيمة الخطأ في المكتبة القياسية ودوالها المساعدة، والمعنى الدقيق للعامل `؟`.

## الوحدات والاستيراد

كل ملف `.sn` وحدة مستقلة. ويجعل `عام` التصريح متاحًا لمن يستورد الوحدة، ويبقى كل ما عداه خاصًا بها. وللاستيراد
ثلاث صيغ: مسار ملف بين علامتي تنصيص، نسبةً إلى الملف الذي يستورده؛ ومسار وحدة مفصول بالنقاط؛ واستيراد أسماء
محددة من مجلد. ويعطي `مثل` الوحدةَ المستوردة اسمًا محليًا تُسبَق به أسماؤها.

```sultan
استورد "geometry_ar.sn";
استورد المكتبة.نصوص.number مثل الأعداد;
من المكتبة.دخ استورد اطبع_سطر;

عرف الرئيسية(): عدد {
    دع الغرفة: مستطيل = { العرض: 5, الارتفاع: 4 };
    اطبع_سطر(الأعداد.عدد_إلى_نص(المساحة(&الغرفة)));
    أرجع 0;
}
```

والوحدة المستوردة:

```sultan
عام نوع مستطيل = { العرض: عدد, الارتفاع: عدد };

عام عرف المساحة(الشكل: &مستطيل): عدد {
    أرجع (*الشكل).العرض * (*الشكل).الارتفاع;
}
```

يُدخل `استورد المكتبة.نصوص.number;` كل اسم عام في تلك الوحدة من المكتبة القياسية إلى النطاق مباشرةً، أما
`استورد المكتبة.نصوص.number مثل الأعداد;` فيجعل هذه الأسماء متاحة على الصورة `الأعداد.الاسم` فقط. وتُكتب
المكتبة القياسية `std` بالعربية `المكتبة`، ولبعض مجلداتها الفرعية أسماء عربية أيضًا (فالمسار `std.text.number` يُكتب
`المكتبة.نصوص.number`). وتشرح صفحة [الوحدات والاستيراد](../reference/modules-and-imports.md) طريقة البحث عن
الوحدات وحل الأسماء.

## استخدام المكتبة القياسية

تكتب الدالة `اطبع_سطر` (من `std.io.println`) سطرًا على الخرج القياسي، وتحوّل الوحدة `std.text.number` الأعداد إلى نصوص وبالعكس،
وتنسّق الوحدة `std.fmt` النصوص بسلاسل تنسيق فيها مواضع للقيم (placeholders) على طريقة Rust. ويُغلَّف كل وسيط لدالة
التنسيق في قيمة تحمل نوعه، وتُفحص سلسلة التنسيق المكتوبة في الشيفرة في وقت الترجمة.

```sultan
استورد المكتبة.تنسيق.fmt;

عرف الرئيسية(): عدد {
    دع الاسم: نص = "سلطان";
    دع ر1: نتيجة طبيعي, خطأ_تنسيق = اطبع_سطرا_منسقا("أهلا يا {}! لديك {} رسائل.", [قيمة_تنسيق.نص(&الاسم), قيمة_تنسيق.عدد(3)]);
    دع ر2: نتيجة طبيعي, خطأ_تنسيق = اطبع_سطرا_منسقا("[{0:>8}] {1:#x} {2:.2}", [قيمة_تنسيق.نص(&الاسم), قيمة_تنسيق.عدد(255), قيمة_تنسيق.ع64(3.14159)]);
    أرجع 0;
}
```

```text
أهلا يا سلطان! لديك 3 رسائل.
[   سلطان] 0xff 3.14
```

وتشرح صفحة [التنسيق](../reference/formatting.md) صياغة مواصفات التنسيق، والمنسقات المخصصة، وقواعد المحاذاة.
وتسرد صفحة [تغطية المكتبة القياسية](../reference/std-coverage.md) كل ما تقدمه المكتبة.
