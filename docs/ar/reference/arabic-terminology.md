# المصطلحات العربية

يعامل السلطانُ العربيةَ لغةً أصيلة في الشيفرة المصدرية وفي المترجم. هذه الصفحة هي المرجع المعتمد للمفردات:
تهجئات الكلمات المفتاحية والأنواع ومفاهيم المترجم والأسماء العامة في المكتبة القياسية بالعربية، مع مقابلاتها
الإنجليزية. وهي موجهة إلى المبرمجين الذين يقرؤون شيفرة السلطان العربية أو يكتبونها، وإلى المساهمين الذين
يسمّون واجهات برمجية جديدة.

السجلات المعجمية في `tools/generate/registry/` هي المرجع الحاسم لتهجئة الكلمات المفتاحية والأنواع بدقة،
ولا تضيف هذه الصفحة تهجئات بديلة. عند مقارنة المعرّفات تُوحَّد صور الألف آ وأ وإ إلى ا ويُتجاهل التطويل
(`tools/generate/registry/identifier_policy_registry.def`).

## اللغة

### الكلمات المفتاحية

| الإنجليزية | العربية | المعنى |
| --- | --- | --- |
| `def` | `عرف` | تعريف دالة |
| `let` | `دع` | التصريح بقيمة |
| `return` | `أرجع` | الرجوع من دالة |
| `if` | `إذا` | فرع شرطي |
| `else` | `وإلا` | الفرع البديل |
| `while` | `طالما` | حلقة «ما دام» (while) |
| `for` | `لكل` | حلقة التكرار (for) |
| `break` | `اخرج_من_حلقة` | الخروج من الحلقة الحالية |
| `continue` | `تابع_حلقة` | الانتقال إلى الدورة التالية من الحلقة الحالية |
| `type` | `نوع` | التصريح بنوع |
| `match` | `طابق` | مطابقة الأنماط |
| `with` | `مع` | بداية فرع المطابقة |
| `mutable` | `متغير` | غلاف القابلية للتغيير |
| `public` | `عام` | تصريح عام |
| `extern` | `خارجي` | التصريح بدالة خارجية |
| `import` | `استورد` | استيراد وحدة |

| `unsafe` | `غير_آمن` | سياق غير آمن |

دالة الدخول إلى البرنامج اسمها `main` بالإنجليزية و`الرئيسية` («الدالة الرئيسية») بالعربية: `عرف الرئيسية(): عدد { … }`.

### الأنواع المدمجة

| الإنجليزية | العربية |
| --- | --- |
| `any` | `أي` |
| `bool` | `منطقي` |
| `string` | `نص` |
| `char` | `حرف` |
| `int` | `عدد` |
| `uint` | `طبيعي` (عدد طبيعي: عدد صحيح ≥ 0، يشمل الصفر) |
| `void` | `فراغ` |
| `i8`, `i16`, `i32`, `i64` | `ص8`, `ص16`, `ص32`, `ص64` |
| `u8`, `u16`, `u32`, `u64` | `ط8`, `ط16`, `ط32`, `ط64` |
| `f32`, `f64` | `ع32`, `ع64` |

تُقرأ `طبيعي` أيضًا بمعنى «عادي» (normal) في نصوص الأعداد العائمة، ولذلك يسمّي تحويل الأعداد العائمة العشرية
أصغر قيمة عادية باسم `أصغر_عادي_عائم` (`compiler/msir/decimal_float_bits.sn`)؛ أما `أصغر_طبيعي` فلا يدل
إلا على دالة المكتبة القياسية التي تعيد الأصغر من عددين طبيعيين.

### أنواع الحاويات المدمجة

هذه الأسماء سياقية: لا تدل على النوع إلا في موضع نوع أو موضع منشئ.

| الإنجليزية | العربية | المنشئات |
| --- | --- | --- |
| `option` | `اختياري` | `some`/`Some` = `موجود`, `none`/`None` = `لا_شيء` |
| `result` | `نتيجة` | `ok`/`Ok` = `نجح`, `err`/`Err` = `خطأ` |
| `vector` | `متجه` | |

### الانتشار وحالات الفشل أثناء التشغيل

`إنهيار` هي التهجئة المعتمدة لـ `panic`، بهمزة تحت الألف؛ و`انهيار` المكتوبة بلا همزة تدل على المعرّف
نفسه. وهي دالة في المكتبة القياسية مبنية على آلية إنهاء العملية فيها، كما هي `اخرج` / `exit`، وليست عملية بدائية في المترجم
ولا رمزًا معجميًا؛ والمترجم يعرف أنها لا تعود أبدًا (انظر [الأخطاء](errors.md)). الأسماء المخفية التي
يولّدها المترجم عند التوسيع (`انتشار__N…`، `نقطة_دخول__…`) معرّفات عادية ذات بادئة محجوزة لا يصرّح بها
أي مصدر.

| الإنجليزية | العربية | المعنى |
| --- | --- | --- |
| `?` | `؟` (U+061F) | عامل الانتشار: آخر لاحقة في الطرف الأيمن من العبارة (الرمز `استفهام`، `QUESTION_OPERATOR`) |
| `panic` | `إنهيار` | العملية الأساسية للإيقاف: تطبع رسالة وتنهي البرنامج (`std.process.panic`) |
| `SULTANC-RUNTIME-PROGRAM-ERROR` | `انتهى_البرنامج_بخطأ` | هوية فشل تشغيل: أعادت `main` خطأ ("the program ended with an error" / «انتهى البرنامج بخطأ») |
| `SULTANC-RUNTIME-PROGRAM-STOPPED` | `توقف_البرنامج` | هوية فشل تشغيل: توقف البرنامج ("the program stopped" / «توقف البرنامج») |
| `runtime.assertion-failed` | `سبب_تشغيل_فشل_تأكيد` | سبب الإيقاف عند فشل تأكيد ("An assertion failed" / «فشل تأكيد») |
| — | `اطبع_فشل_تشغيل` | المسار الوحيد لطباعة فشل التشغيل (`std.process.failure`) |
| — | `البرنامج_بالإنجليزية` | هل يتكلم البرنامج الإنجليزية: اللغة الأساسية لـ `لغة_من_البيئة()` ليست `ar` |
| — | `أبلغ_عن_خطأ_نقطة_الدخول` | الإبلاغ عن الخطأ الذي أعادته `main` |
| — | `إطار_فشل_تشغيل` | إطار iSpeak لفشل التشغيل (`std.process.failure_text`، يكتبه المترجم) |

### التهجئات المعاد تسميتها

أُعيدت تسمية بعض التهجئات العربية لأن الكلمة القديمة لم تكن تدل على المفهوم. وباستثناء دالة الدخول، ما زالت
التهجئة القديمة مقبولة اسمًا بديلًا مهجورًا (deprecated alias). وهي تُترجم تمامًا كالتهجئة الجديدة، ويُصدر
المترجم المستضاف ذاتيًا تحذيرًا واحدًا عند كل استعمال، `SULTANC-SYNTAX-DEPRECATED-SPELLING`، يذكر فيه
التهجئتين القديمة والجديدة (أما Stage0 فيقبل التهجئة القديمة دون تحذير). التهجئات الإنجليزية لا تتغير أبدًا.

| الإنجليزية | العربية القديمة (مهجورة) | العربية الجديدة | السبب |
| --- | --- | --- | --- |
| `while` | `بينما` | `طالما` | `طالما` تعني «ما دام»، وهذا ما تختبره الحلقة. أما `بينما` فظرف زمان («أثناء»، «في حين»)، وهي ترجمة حرفية للكلمة الإنجليزية *while*. |
| دالة الدخول `main` | لقب المشروع «القلعة» (أُزيل، بلا اسم بديل) | `الرئيسية` | `الرئيسية` تعني «الدالة الرئيسية»، وهو المصطلح المعتاد. الاسم القديم، «القلعة»، كان لقبًا للمشروع؛ ولم يعد المترجم يتعرّف عليه إطلاقًا، فالبرنامج الذي ما زالت دالة دخوله الوحيدة تحمل هذا الاسم يُبلغ عن `SULTANC-ENTRYPOINT-NOT-FOUND`. |
| `option` | `اختيار` | `اختياري` | `اختياري` صفة بمعنى «غير إلزامي»، وهي الكلمة المعتادة لحقل أو قيمة اختيارية. أما `اختيار` فاسم يدل على فعل الاختيار نفسه (وفي المترجم يعني انتقاء التعليمات). |
| `some` / `Some` | `بعض` (`اختيار.بعض`) | `موجود` (`اختياري.موجود`) | `موجود` تعني أن هناك قيمة موجودة. أما `بعض` بالعربية فتدل على التبعيض («بعضٌ من»، «جزءٌ من»)، في حين تعني *Some* في ML وRust أن هناك قيمة x؛ وللسبب نفسه تستعمل Haskell وElm الاسم `Just`. |
| `none` / `None` | `لا_شيء` | `لا_شيء` (بلا تغيير) | لا يتغير إلا بادئة النوع: `اختياري.لا_شيء`. |
| `uint` | `غير_موقع` | `طبيعي` | `طبيعي` تعني العدد الطبيعي، **وهو يشمل الصفر** («طبيعي: عدد صحيح ≥ 0، يشمل الصفر»)، مع أن كثيرًا من المصادر العربية تبدأ الأعداد الطبيعية من 1. أما `غير_موقع` فكانت ترجمة حرفية: `موقَّع` تعني الوثيقة التي عليها توقيع، لا العدد ذا الإشارة (signed). |
| `u8`, `u16`, `u32`, `u64` | `غ8`, `غ16`, `غ32`, `غ64` | `ط8`, `ط16`, `ط32`, `ط64` | تأخذ الأنواع الطبيعية ثابتة العرض الحرف الأول من `طبيعي`، كما يأخذ `ص8` الحرف الأول من `صحيح`. |

تهجئات الكلمات المفتاحية المهجورة صفوف في `tools/generate/registry/token_registry.def` (`SULTANC__KEYWORD_DEPRECATED__`)، وتهجئات الأنواع السياقية المهجورة صفوف في `tools/generate/registry/type_registry.def` (`SULTANC__TYPE_CONTEXTUAL_DEPRECATED__`)؛ أما تهجئات منشئات `اختياري` فتُطابَق في `compiler/frontend/types/type_semantic_shape_queries.sn` وفي `bootstrap/src/kernel/type/type_tagged.c` الخاص بـ Stage0. يصدر تحذير الكلمة المفتاحية عند الرمز نفسه؛ أما اسم النوع السياقي والمنشئ فيصدر تحذيرهما حين تصادفهما مرحلة الأسماء في موضع نوع أو منشئ، ولذلك لا يصدر تحذير لمتغير محلي اسمه `اختيار`. أعد كتابة المصادر بالأداة المبنية على المحلل المعجمي، التي لا تغيّر إلا الرموز المعاد تسميتها (لا تمس النصوص الحرفية ولا التعليقات ولا المعرّفات الأطول)، ونتيجتها لا تتغير إذا شُغّلت أكثر من مرة:

<div dir="ltr">

```sh
python3 tools/rename/rename_tokens.py --wave 1 path/to/sources   # بينما -> طالما
python3 tools/rename/rename_tokens.py --wave 7 path/to/sources   # دالة الدخول -> الرئيسية
python3 tools/rename/rename_tokens.py --wave 2 path/to/sources   # اختيار -> اختياري, اختيار.بعض -> اختياري.موجود
python3 tools/rename/rename_tokens.py --wave 3 path/to/sources   # غير_موقع -> طبيعي, غN -> طN
python3 tools/rename/rename_tokens.py --wave 3 --segments path/to/sources   # أصغر_غير_موقع -> أصغر_طبيعي
python3 tools/rename/rename_tokens.py --wave 1 --check path/to/sources   # يعدّ ما تبقى
```

</div>

الأسماء المبنية على الأنواع عديمة الإشارة (unsigned) تتغير معها (`--segments`): يصبح المقطع `غير_موقع` هو `طبيعي` (`أصغر_طبيعي`، `طبيعي_إلى_نص`، `عدد_صحيح_طبيعي`)، وتصبح الصفة المؤنثة `غير_موقعة` هي `طبيعية` (`قيمة_حجة_رسالة.طبيعية`، `قيمة_طبيعية_عشرية_ويب`)، وتصبح `لغير_موقع` هي `لطبيعي` (`سالب_لطبيعي`)، ويصبح مقطع العرض `غ8`…`غ64` هو `ط8`…`ط64` (`ألحق_ط32_كوف`، `اقرأ_ط16_صغير`). أما سائر استعمالات كلمة `غير` فلا تتغير. ويحتفظ الاسم العام في المكتبة القياسية باسمه القديم اسمًا بديلًا (`عام مرادف أصغر_غير_موقع = أصغر_طبيعي;`، `عام مرادف خطأ_تحليل_عدد.سالب_لغير_موقع = خطأ_تحليل_عدد.سالب_لطبيعي;`)؛ ولا تمس الأداة جدول الأسماء البديلة هذا.

تسمّي مصطلحات المترجم المفهوم بدقة بدل أن تترجم كلمة إنجليزية ملتبسة ترجمة آلية. فالمصطلحات المقابلة لكلمات مثل *target*
و*object* و*load* و*store* تحمل ما يكفي من السياق للتمييز بين أهداف الترجمة وملفات الكائنات
وتحميل الوحدات وعمليات الذاكرة.

## الأفعال المستعملة في أسماء المكتبة القياسية

تتبع الأسماء معجمًا للأفعال: `أنشئ` للإنشاء، و`اقرأ` للقراءة، و`اضبط` للضبط، و`أزل` لإزالة عنصر
(بادئة أو متغير)، و`امسح` للتفريغ، و`احذف` لحذف الملفات، و`هل_…` للسؤال، و`حلل` للتحليل،
و`حول_…_إلى_…` للتحويل، و`ابدأ` للبدء، و`خذ` لأخذ قيمة من مالكها (مثل `Option::take` في Rust)،
و`تفقد` للاستطلاع دون انتظار، و`اقفل` و`افتح_قفل` للقفل وفكّه، و`حاول_…` للمحاولة دون انتظار، و`نفذ`
لتنفيذ شيء، و`انتظر` / `أيقظ` / `نبه` للانتظار والإيقاظ والتنبيه، و`أرسل` / `استقبل` للإرسال
والاستقبال، و`أسقط` لإسقاط طرف، و`استنسخ` للاستنساخ، و`نسق` للتنسيق.

## الأخطاء واللغات (std.error)

أسماء `std.error` ([الأخطاء](errors.md)) عربية، ولها أسماء بديلة إنجليزية (`مرادف`). وتحتفظ القيمة
المنطقية `خطأ` / `false` وحالتا النتيجة `نتيجة.نجح` / `نتيجة.خطأ` بأسمائها.
