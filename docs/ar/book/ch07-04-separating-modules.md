# فصل الوحدات في ملفات

يبني هذا القسم حزمة صغيرة فيها مكتبة، كما تُنظَّم المشاريع الكبيرة.

## الترتيب

ابدأ من الحزمة `متجر` في القسم 7.1، وفي بيانها `[lib] path = "src"`. تحتاج الأسعار إلى حساب الضريبة، فيذهب في وحدة خاصة به،
في مجلد لكل ما يخص الأسعار:

```text
متجر/
├── Supax.toml
└── src/
    ├── main.sn
    ├── متجر.sn
    └── prices/
        ├── prices.sn
        └── tax.sn
```

<sub>الملف: src/prices/tax.sn</sub>

```sultan ignore
عام عرف مع_الضريبة(المبلغ: عدد): عدد {
    أرجع المبلغ + المبلغ * نسبة_الضريبة() / 100;
}

عرف نسبة_الضريبة(): عدد {
    أرجع 15;
}
```

الملف `src/prices/tax.sn` هو الوحدة `متجر.prices.tax`: اسم الحزمة، ثم المجلدات واسم الملف تحت `src`.

## أسماء عربية للوحدات

أسماء الملفات والمجلدات إنجليزية، وتستطيع الحزمة أن تعطي وحداتها أسماء عربية كما تفعل المكتبة القياسية. وتُكتب الأسماء في
*ملفات الجذر* (root files): `src/الاسم.sn` لوحدات الحزمة العليا، و `المجلد/المجلد.sn` لوحدات مجلد ما. وكل سطر يسمّي وحدة
وكتاباتها الأخرى:

<sub>الملف: src/متجر.sn</sub>

```sultan ignore
وحدة prices { ar: الأسعار };
```

<sub>الملف: src/prices/prices.sn</sub>

```sultan ignore
وحدة tax { ar: الضريبة };
```

فيصير `استورد متجر.الأسعار.الضريبة;` مثل `استورد متجر.prices.tax;`. وملف الجذر الخاص بالمكتبة القياسية،
`library/std/std.sn`، يصرّح بالأسماء العربية لوحداتها بهذه الطريقة.

ويستورد البرنامج الرئيسي الوحدة باسمها العربي:

<sub>الملف: src/main.sn</sub>

```sultan ignore
استورد المكتبة.دخ.اطبع_سطر;
استورد المكتبة.نصوص.أعداد;
استورد متجر.الأسعار.الضريبة;

عرف الرئيسية(): عدد {
    اطبع_سطر(عدد_إلى_نص(مع_الضريبة(200)));
    أرجع 0;
}
```

و `نسبة_الضريبة` خاصة بـ `متجر.الأسعار.الضريبة`، فلا يستطيع `main.sn` استدعاءها:

## كيف تقسّم البرنامج

لا يوجد ترتيب واحد صحيح، لكن بعض العادات تعمل جيدا:

- وحدة لكل موضوع: كل ما يخص الأسعار في `الأسعار`، وكل ما يخص العملاء في `العملاء`. والوحدة التي لا تستطيع أن تسميها بكلمة
  واحدة تفعل غالبا شيئين.
- ضع النوع والدوال التي تعمل عليه في الوحدة نفسها.
- أبقِ `main.sn` قصيرا: قراءة المدخلات، واستدعاء المكتبة، وطباعة النتيجة. فالعمل الحقيقي في المكتبة، حيث تستطيع الاختبارات
  والبرامج الأخرى استخدامه أيضا.
- ابدأ بملف واحد، وقسّم حين يكبر جزء بما يكفي ليستحق اسما خاصا.

## الخلاصة

- الحزمة `Supax.toml` ومجلد `src`، و `[lib] path = "src"` تجعل `src` مكتبة.
- `src/main.sn` و `src/bin/الاسم.sn` برامج.
- كل ملف وحدة، ولا يُرى خارجها إلا ما صُرِّح به `عام`.
- تستورد `استورد أ.ب.ج;` و `استورد أ.ب.ج مثل بادئة;` و `من أ.ب استورد ج;` الوحدات بأسمائها، وتستورد
  `استورد "file.sn";` بالمسار.
- `src/أ/ب.sn` في الحزمة `الاسم` هو الوحدة `الاسم.أ.ب`، وملفات الجذر تعطي الوحدات كتابات أخرى.
