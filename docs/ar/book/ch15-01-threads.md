# استخدام الخيوط

## إطلاق خيط

تشغّل `أطلق_بقيمة(د)` الدالة `د` في خيط جديد، وترجع *مقبضا* (handle) له. وتنتظر `انضم_بقيمة(&متغير المقبض)` انتهاء الخيط،
وتعطي ما أرجعته `د`:

```sultan
استورد المكتبة.دخ.اطبع_سطر;
استورد المكتبة.نصوص.أعداد;
استورد المكتبة.خيوط.خيط;

عرف الرئيسية(): عدد {
    طابق أطلق_بقيمة(دالة(): عدد -> 20 * 2) مع
    | نتيجة.خطأ(_) -> { أرجع 1; }
    | نتيجة.نجح(المقبض) -> {
        ليكن الخيط: متغير مقبض_خيط_بقيمة<عدد> = المقبض;
        طابق انضم_بقيمة(&متغير الخيط) مع
        | اختياري.موجود(القيمة) -> { اطبع_سطر(عدد_إلى_نص(القيمة)); }
        | اختياري.لا_شيء -> { أرجع 2; };
    };
    أرجع 0;
}
```

```text
40
```

قد يفشل إطلاق الخيط، لأن النظام قد يرفض إنشاء خيط آخر، فترجع `أطلق_بقيمة` قيمة `نتيجة`. وترجع `انضم_بقيمة` قيمة `اختياري`
تكون `لا_شيء` إن توقف الخيط دون قيمة. وللخيط الذي لا يرجع شيئا تعمل `أطلق` و `انضم` بالطريقة نفسها.

والدالة المعطاة لـ `أطلق_بقيمة` هنا دالة مجهولة بلا معاملات، من الفصل العاشر.

## تقسيم العمل

يأخذ الخيط بيانات يعمل عليها بالتقاطها. والقيمة المالكة الملتقطة تنتقل إلى الخيط، فيكون مالكها الوحيد، ولا يلمسها شيء آخر وهو
يعمل:

```sultan
استورد المكتبة.دخ.اطبع_سطر;
استورد المكتبة.نصوص.أعداد;
استورد المكتبة.خيوط.خيط;

عرف اجمع_مدى(القيم: &متجه عدد, البداية: عدد, النهاية: عدد): عدد {
    ليكن المجموع: متغير عدد = 0;
    لكل (ليكن ع: متغير عدد = البداية; ع < النهاية; ع := ع + 1) {
        المجموع := المجموع + (*القيم)[ع];
    }
    أرجع المجموع;
}

عرف اجمع_في_خيط(القيم: متجه عدد): نتيجة مقبض_خيط_بقيمة<عدد>, خطأ_خيط {
    أرجع أطلق_بقيمة(دالة(): عدد -> اجمع_مدى(&القيم, 0, الطول(القيم)));
}

عرف الرئيسية(): عدد {
    ليكن الأول: متغير متجه عدد = [];
    ليكن الثاني: متغير متجه عدد = [];
    لكل (ليكن ع: متغير عدد = 1; ع <= 1000; ع := ع + 1) {
        إذا (ع <= 500) {
            ألحق(الأول, ع);
        } وإلا {
            ألحق(الثاني, ع);
        };
    }
    ليكن المجموع: متغير عدد = 0;
    طابق اجمع_في_خيط(الأول) مع
    | نتيجة.خطأ(_) -> { أرجع 1; }
    | نتيجة.نجح(م1) -> {
        طابق اجمع_في_خيط(الثاني) مع
        | نتيجة.خطأ(_) -> { أرجع 1; }
        | نتيجة.نجح(م2) -> {
            ليكن أ: متغير مقبض_خيط_بقيمة<عدد> = م1;
            ليكن ب: متغير مقبض_خيط_بقيمة<عدد> = م2;
            طابق انضم_بقيمة(&متغير أ) مع
            | اختياري.موجود(ق) -> { المجموع := المجموع + ق; }
            | اختياري.لا_شيء -> { أرجع 2; };
            طابق انضم_بقيمة(&متغير ب) مع
            | اختياري.موجود(ق) -> { المجموع := المجموع + ق; }
            | اختياري.لا_شيء -> { أرجع 2; };
        };
    };
    اطبع_سطر(عدد_إلى_نص(المجموع));
    أرجع 0;
}
```

```text
500500
```

يُجمع كل نصف من الأعداد في خيطه، في الوقت نفسه، وتجمع `الرئيسية` الناتجين. وتأخذ `اجمع_في_خيط` متجهها بالقيمة: فينتقل المتجه
إلى الدالة، ثم إلى الـ closure، ثم إلى الخيط الجديد.
