# تنظيم الاختبارات

الاختبارات نوعان، وتحفظهما الحزمة في مكانين.

## اختبارات الوحدة، بجوار الشيفرة

*اختبار الوحدة* (unit test) يفحص وحدة واحدة وحدها، ومنها دوالها الخاصة. ويعيش في ملف الوحدة نفسه، بجوار الشيفرة التي يفحصها.
وهذه وحدة `متجر.الأسعار.الضريبة` من الفصل السابع، مع اختبار لدالتها الخاصة `نسبة_الضريبة`:

<sub>الملف: src/prices/tax.sn</sub>

```sultan ignore
استورد المكتبة.تصحيح.تأكد;

عام عرف مع_الضريبة(المبلغ: عدد): عدد {
    أرجع المبلغ + المبلغ * نسبة_الضريبة() / 100;
}

عرف نسبة_الضريبة(): عدد {
    أرجع 15;
}

@@اختبار
عرف النسبة_خمسة_عشر_بالمئة(): فراغ {
    تأكد(نسبة_الضريبة() == 15);
}
```

يشغّل `supax test --lib` اختبارات المكتبة. ويبدأ من *ملف جذر* المكتبة، `src/الاسم.sn`، ويشغّل اختبارات كل وحدة يستوردها
ملف الجذر. وفيه أيضا الأسماء العربية من الفصل السابع:

<sub>الملف: src/متجر.sn</sub>

```sultan ignore
وحدة prices { ar: الأسعار };

استورد متجر.الأسعار.الضريبة;
```

## اختبارات التكامل، في `tests`

*اختبار التكامل* (integration test) يستخدم المكتبة كما يستخدمها برنامج آخر: عبر أسمائها العامة فقط. ويعيش في المجلد `tests`
أعلى الحزمة، ويستورد المكتبة باسمها:

<sub>الملف: tests/prices.sn</sub>

```sultan ignore
استورد المكتبة.تصحيح.تأكد;
استورد متجر.الأسعار.الضريبة;

@@اختبار
عرف تضاف_الضريبة(): فراغ {
    تأكد(مع_الضريبة(200) == 230);
}

@@اختبار
عرف الصفر_يبقى_صفرا(): فراغ {
    تأكد(مع_الضريبة(0) == 0);
}
```

وتكتشف اختبارات التكامل ما تفوته اختبارات الوحدة: أجزاء تعمل وحدها وتفشل معا، وواجهات عامة يصعب استخدامها.

## تشغيلها كلها

```text
متجر/
├── Supax.toml
├── src/
│   ├── متجر.sn
│   ├── main.sn
│   ├── bin/
│   │   └── report.sn
│   └── prices/
│       ├── prices.sn
│       └── tax.sn
└── tests/
    └── prices.sn
```

```console
$ supax test
       يشغّل lib src/متجر.sn
نجح النسبة_خمسة_عشر_بالمئة

نتيجة الاختبارات: ناجحة. نجح: 1؛ فشل: 0؛ استُبعد: 0
       يشغّل bin src/main.sn

نتيجة الاختبارات: ناجحة. نجح: 0؛ فشل: 0؛ استُبعد: 1
       يشغّل bin src/bin/report.sn

نتيجة الاختبارات: ناجحة. نجح: 0؛ فشل: 0؛ استُبعد: 1
       يشغّل test tests/prices.sn
نجح تضاف_الضريبة
نجح الصفر_يبقى_صفرا

نتيجة الاختبارات: ناجحة. نجح: 2؛ فشل: 0؛ استُبعد: 0
       انتهى في 0.87 ث
```

يشغّل كل هدف اختباراته. والبرنامجان `main.sn` و `report.sn` يستوردان الوحدة أيضا، لكن اختبارها يخص المكتبة، فيعدّانه مستبعدا
بدلا من تشغيله مرة ثانية.

## الخلاصة

- الاختبار دالة `@@اختبار` بلا معاملات ترجع `فراغ`، و `تأكد` تفحص داخلها.
- يشغّل `sultanc test الملف.sn` اختبارات الملف، ويتركها البناء العادي.
- يذكر الفشل سطر التأكيد، وأي فشل يجعل الحالة 1، وكل اختبار يعمل وحده.
- يشغّل `--filter` بعض الاختبارات، ويسردها `--list`، ويشغّل `supax test` اختبارات الحزمة.
- اختبارات الوحدة بجوار الشيفرة، واختبارات التكامل في `tests` بالأسماء العامة فقط.
