# المتجهات

يحمل المتجه، `متجه ن`، قيما من نوع واحد `ن`، بترتيب، ويمكن أن يكبر. فـ `متجه عدد` يحمل أعدادا، و `متجه نص` يحمل نصوصا، و
`متجه نقطة` يحمل سجلات.

## إنشاء متجه والقراءة منه

يُكتب المتجه بقيمه بين قوسين مربعين، والمتجه الفارغ `[]`. ويقرأ `م[ع]` القيمة في الموضع `ع` بدءا من 0، وتعطي `الطول(م)`
عدد القيم:

```sultan
استورد المكتبة.دخ.اطبع_سطر;
استورد المكتبة.نصوص.أعداد;

عرف الرئيسية(): عدد {
    ليكن الأوليات: متجه عدد = [2, 3, 5, 7, 11];
    اطبع_سطر(عدد_إلى_نص(الأوليات[0]));
    اطبع_سطر(عدد_إلى_نص(الأوليات[الطول(الأوليات) - 1]));
    اطبع_سطر(عدد_إلى_نص(الطول(الأوليات)));
    أرجع 0;
}
```

```text
2
11
5
```

القيمة الأخيرة في `الطول(م) - 1`. وماذا عن موضع غير موجود؟ حين يكون الموضع مكتوبا في الشيفرة يرى المترجم المشكلة:

```sultan fail
استورد المكتبة.دخ.اطبع_سطر;
استورد المكتبة.نصوص.أعداد;

عرف الرئيسية(): عدد {
    ليكن الأوليات: متجه عدد = [2, 3, 5];
    اطبع_سطر(عدد_إلى_نص(الأوليات[10]));
    أرجع 0;
}
```

```text
خطأ[SULTANC-SAFETY-INDEX-OUT-OF-BOUNDS]: الفهرس خارج الحدود الصالحة — الفهرس الواقع خارج الحدود هو 10. الطول هو 3.
  --> main.sn:6:34..6:36
   |
 6 |     اطبع_سطر(عدد_إلى_نص(الأوليات[10]));
   |                                  ^^
   |
```

وغالبا يُحسب الموضع أثناء عمل البرنامج، فلا يستطيع المترجم معرفته. فيفحصه البرنامج حين يقرأ، ويتوقف إن كان بعد النهاية، كما
يتوقف عند تجاوز الحد:

```sultan
استورد المكتبة.دخ.اطبع_سطر;
استورد المكتبة.نصوص.أعداد;

عرف القيمة_عند(القيم: &متجه عدد, الموضع: عدد): عدد {
    أرجع (*القيم)[الموضع];
}

عرف الرئيسية(): عدد {
    ليكن الأوليات: متجه عدد = [2, 3, 5];
    اطبع_سطر(عدد_إلى_نص(القيمة_عند(&الأوليات, 10)));
    أرجع 0;
}
```

```console
$ ./primes

الفهرس 10 خارج المدى للطول 3 عند main.sn:5:10
```

تعطي الرسالة الموضع، وطول المتجه، والمكان في المصدر الذي قرأه.

القراءة بعد نهاية المتجه من أقدم أخطاء برمجة الأنظمة وأخطرها: فيقرأ البرنامج أيا كانت الذاكرة التي تلي المتجه، ويكمل
بقيم عبثية، أو ببيانات غيره. أما برنامج السلطان فلا يقرأ ذاكرة خارج المتجه أبدا. وحين لا تعرف هل الموضع موجود، فقارنه
بـ `الطول` أولا.

## الإضافة والتغيير

المتجه الذي يتغير يجب أن يكون `متغير`. وتضيف `ألحق` قيمة في آخره، وتستبدل `م[ع] := القيمة` القيمة في موضع:

```sultan
استورد المكتبة.دخ.اطبع_سطر;
استورد المكتبة.نصوص.أعداد;

عرف الرئيسية(): عدد {
    ليكن الدرجات: متغير متجه عدد = [];
    ألحق(الدرجات, 70);
    ألحق(الدرجات, 95);
    ألحق(الدرجات, 82);
    الدرجات[0] := 75;
    اطبع_سطر(عدد_إلى_نص(الطول(الدرجات)));
    اطبع_سطر(عدد_إلى_نص(الدرجات[0]));
    أرجع 0;
}
```

```text
3
75
```

لا تقول `[]` وحدها شيئا عما سيحمله المتجه، بل يقوله النوع المصرَّح به، `متجه عدد`.

## المرور على كل قيمة

تزور حلقة `لكل` على المواضع كل قيمة بالترتيب:

```sultan
استورد المكتبة.دخ.اطبع_سطر;
استورد المكتبة.نصوص.أعداد;

عرف الرئيسية(): عدد {
    ليكن الأسعار: متجه عدد = [120, 45, 300, 15];
    ليكن المجموع: متغير عدد = 0;
    ليكن الأعلى: متغير عدد = الأسعار[0];
    لكل (ليكن ع: متغير عدد = 0; ع < الطول(الأسعار); ع := ع + 1) {
        المجموع := المجموع + الأسعار[ع];
        إذا (الأسعار[ع] > الأعلى) {
            الأعلى := الأسعار[ع];
        };
    }
    اطبع_سطر(عدد_إلى_نص(المجموع));
    اطبع_سطر(عدد_إلى_نص(الأعلى));
    أرجع 0;
}
```

```text
480
300
```

## المتجهات والدوال

يملك المتجه قيمه، فتنطبق قواعد الملكية. والدالة التي تقرأ متجها تستعيره، `&متجه ن`، وتقرؤه عبر `*`:

```sultan
استورد المكتبة.دخ.اطبع_سطر;
استورد المكتبة.نصوص.أعداد;

عرف المتوسط(القيم: &متجه عدد): عدد {
    ليكن المجموع: متغير عدد = 0;
    لكل (ليكن ع: متغير عدد = 0; ع < الطول(*القيم); ع := ع + 1) {
        المجموع := المجموع + (*القيم)[ع];
    }
    أرجع المجموع / الطول(*القيم);
}

عرف الرئيسية(): عدد {
    ليكن العلامات: متجه عدد = [80, 90, 100];
    اطبع_سطر(عدد_إلى_نص(المتوسط(&العلامات)));
    اطبع_سطر(عدد_إلى_نص(الطول(العلامات)));
    أرجع 0;
}
```

```text
90
3
```

والدالة التي تغيّر متجها تأخذ `&متغير متجه ن`:

```sultan
استورد المكتبة.دخ.اطبع_سطر;
استورد المكتبة.نصوص.أعداد;

عرف ضاعف_الكل(القيم: &متغير متجه عدد): فراغ {
    لكل (ليكن ع: متغير عدد = 0; ع < الطول(*القيم); ع := ع + 1) {
        (*القيم)[ع] := (*القيم)[ع] * 2;
    }
}

عرف الرئيسية(): عدد {
    ليكن الأعداد: متغير متجه عدد = [1, 2, 3];
    ضاعف_الكل(&متغير الأعداد);
    اطبع_سطر(عدد_إلى_نص(الأعداد[2]));
    أرجع 0;
}
```

```text
6
```

## متجهات القيم المالكة

يعمل متجه النصوص بالطريقة نفسها، مع قاعدة من الفصل الرابع: إخراج نص من المتجه ينقله ويترك ثغرة. أما طباعته فلا تأخذه،
لأن `اطبع_سطر` تستعير نصها فقط:

```sultan
استورد المكتبة.دخ.اطبع_سطر;

عرف الرئيسية(): عدد {
    ليكن الأسماء: متغير متجه نص = ["هدى", "آدم"];
    ألحق(الأسماء, "زيد");
    لكل (ليكن ع: متغير عدد = 0; ع < الطول(الأسماء); ع := ع + 1) {
        اطبع_سطر(الأسماء[ع]);
    }
    أرجع 0;
}
```

```text
هدى
آدم
زيد
```

ولتحتفظ بنص لك، أو لتمرره إلى دالة تحتفظ به، استنسخه بـ `استنسخ(&الأسماء[ع])`. وحين يخرج المتجه من نطاقه يحرر كل نصوصه
معه.

## الترتيب والحذف والإدراج

في `المكتبة.مجموعات.ترتيب` ترتيب المتجهات والبحث في المرتب منها، وفي `المكتبة.مجموعات.متجهات` باقي العمليات اليومية:

| الدالة | ما تفعله |
| --- | --- |
| `رتب_عدد(&متغير م)` و `رتب_طبيعي` و `رتب_نصوص` | ترتب من الأصغر إلى الأكبر |
| `بحث_ثنائي_عدد(&م, القيمة)` | تجد قيمة في متجه مرتب: `موجود(الموضع)` أو `لا_شيء` |
| `أزل_عند(&متغير م, ع)` | تحذف القيمة في `ع` وترجع `موجود(القيمة)`، أو `لا_شيء` بعد النهاية |
| `أدرج_عند(&متغير م, ع, القيمة)` | تدرج قيمة في `ع` وتزيح ما بعدها |
| `اعكس_المتجه(&متغير م)` | تعكس الترتيب |
| `امسح_المتجه(&متغير م)` | تحذف كل القيم |

```sultan
استورد المكتبة.دخ.اطبع_سطر;
استورد المكتبة.نصوص.أعداد;
استورد المكتبة.نصوص.تحويل;
استورد المكتبة.مجموعات.ترتيب;
استورد المكتبة.مجموعات.متجهات;

عرف الرئيسية(): عدد {
    ليكن الأعداد: متغير متجه عدد = [42, 7, 19, 3];
    رتب_عدد(&متغير الأعداد);
    اطبع_سطر(عدد_إلى_نص(الأعداد[0]));
    طابق أزل_عند(&متغير الأعداد, 0) مع
    | اختياري.موجود(الأصغر) -> { اطبع_سطر(عدد_إلى_نص(الأصغر)); }
    | اختياري.لا_شيء -> { اطبع_سطر("فارغ"); };
    اطبع_سطر(عدد_إلى_نص(الطول(الأعداد)));
    ليكن المدن: متغير متجه نص = ["الرياض", "القاهرة", "عمان"];
    رتب_نصوص(&متغير المدن);
    اطبع_سطر(صل_النصوص(&المدن, &"، "));
    أرجع 0;
}
```

```text
3
3
3
الرياض، القاهرة، عمان
```

ترجع `أزل_عند` قيمة `اختياري`، لأن الموضع قد لا يوجد. وتصل `صل_النصوص` من `المكتبة.نصوص.تحويل` متجه نصوص بفاصل بينها.

## متجهات من متجهات

قد تكون قيم المتجه متجهات، فيتكوّن جدول: `الشبكة[الصف][العمود]`:

```sultan
استورد المكتبة.دخ.اطبع_سطر;
استورد المكتبة.نصوص.أعداد;

عرف الرئيسية(): عدد {
    ليكن الشبكة: متجه متجه عدد = [[1, 2, 3], [4, 5, 6]];
    اطبع_سطر(عدد_إلى_نص(الشبكة[1][2]));
    اطبع_سطر(عدد_إلى_نص(الطول(الشبكة[0])));
    أرجع 0;
}
```

```text
6
3
```
