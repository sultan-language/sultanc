# استدعاء C

كثير من الشيفرة المفيدة مكتوب بلغة C: واجهات نظام التشغيل، والضغط، وقواعد البيانات، والرسوميات. ويستطيع السلطان استدعاءها
مباشرة، بطريقتين:

- أن تصرّح بنفسك بدالة C بـ `خارجي`، وتربط المكتبة التي تعرّفها؛
- أو أن تستورد ملف ترويسة C (header)، أو ملف مصدر C كاملا، ويقرأ المترجم التصريحات منه.

## التصريح بدالة C

يصرّح `خارجي عرف` بدالة معرّفة خارج السلطان: اسمها ومعاملاتها ونوع قيمتها، بلا جسم. وهذه `labs` من مكتبة C القياسية، التي
ترجع القيمة المطلقة لـ `long`:

```sultan ignore
استورد المكتبة.دخ.اطبع_سطر;
استورد المكتبة.نصوص.أعداد;

خارجي عرف labs(القيمة: ص64): ص64;

عرف الرئيسية(): عدد {
    ليكن المسافة: ص64 = labs(-1234);
    اطبع_سطر(عدد_إلى_نص(المسافة مثل عدد));
    أرجع 0;
}
```

ويجب أن يطابق التصريح دالة C بالضبط: فـ `long` في C هو 64 بت على لينكس وماك ذوي الـ 64 بت، فهو هنا `ص64`. ولا يستطيع المترجم
أن يتحقق من ذلك مقابل مكتبة C، فالتصريح الخاطئ خطأ برمجي لا يظهر إلا حين يعمل البرنامج.

ويجب أن تُربط مكتبة C بالبرنامج. فيربط `-l c` المكتبة `libc`، ويربط `-l الاسم` المكتبة `libالاسم`، ويضيف `-L المجلد` مجلدا
يُبحث فيه عنها:

```console
$ sultanc main.sn -o distance -l c
$ ./distance
1234
```

وبدون `-l c` يفشل الربط، لأن لا شيء يعرّف `labs`:

```text
خطأ[SULTANC-LINK-UNDEFINED-SYMBOL]: رمز يستخدمه البرنامج غير معرّف في أي مدخل مربوط — الرمز غير المعرّف هو ⁨`labs`⁩. يشير ربط ELF إلى رمز خارجي لا يعرّفه أي مدخل.
```

ولا يحتاج `sultanc run` إلى `-l`: فالمفسّر يجد دوال مكتبة C أثناء عمل البرنامج.

## استيراد شيفرة C

كتابة كل تصريح بيدك بطيئة، وكل تصريح قد يكون خاطئا. فبدلا من ذلك يستطيع السلطان أن يستورد C مباشرة. فيقرأ
`استورد "file.h";` ترويسة C ويحوّل تصريحاتها إلى وحدة سلطان. ويفعل `استورد "file.c";` أكثر: فيترجم شيفرة C أيضا، جزءا من
البرنامج، بواجهة C الخاصة بالسلطان. فلا حاجة إلى مترجم C، على أي منصة.

وهذا ملف C صغير بجوار البرنامج:

<sub>الملف: geometry.c</sub>

```c file=geometry.c
#include <stdint.h>

int64_t rectangle_area(int64_t width, int64_t height) {
    return width * height;
}

int count_vowels(const char *text) {
    int count = 0;
    for (; *text; text++) {
        switch (*text) {
        case 'a': case 'e': case 'i': case 'o': case 'u':
            count++;
        }
    }
    return count;
}
```

والبرنامج الذي يستخدمه:

<sub>الملف: main.sn</sub>

```sultan
استورد "geometry.c";
استورد المكتبة.دخ.اطبع_سطر;
استورد المكتبة.نصوص.أعداد;
استورد المكتبة.نصوص.من_بايتات;

عرف الرئيسية(): عدد {
    اطبع_سطر(عدد_إلى_نص(rectangle_area(6, 7) مثل عدد));
    ليكن الكلمة: متجه ط8 = بايتات_منتهية_بصفر_من_نص("banana");
    اطبع_سطر(عدد_إلى_نص(count_vowels(&الكلمة[0]) مثل عدد));
    أرجع 0;
}
```

```text
42
3
```

ترجمه كأي برنامج آخر، فيجد المترجم `geometry.c` بجوار `main.sn`:

```console
$ sultanc main.sn -o shapes
```

## كيف تصل أنواع C

يصير كل نوع C نوع السلطان الذي بحجمه: `int` هو `ص32`، و `int64_t` هو `ص64`، و `double` هو `ع64`. والمؤشر إلى `const char`
هو `*ط8`، مؤشر إلى بايت تقرؤه الدالة فقط، وبدون `const` هو `*متغير ط8`. والبنية (struct) التي يستطيع السلطان التعبير عن
تخطيطها تصير سجلا، وغيرها، والبنى المصرّح بها فقط، تصير أنواعا *معتمة* لا تُستخدم إلا عبر المؤشرات.

ونص C مؤشر إلى بايتات تنتهي ببايت صفر. وتصنع `بايتات_منتهية_بصفر_من_نص` من `المكتبة.نصوص.من_بايتات` هذه البايتات من `نص`،
و `&الكلمة[0]` يشير إلى أولها.

وبعض تصريحات C لا شكل لها في السلطان: `long double`، والماكرو الذي يشبه الدالة. فتُترك خارج الوحدة، ويقول المترجم ذلك بتحذير
يسمّي كلا منها. واستيراد ترويسة نظام كبيرة مثل `stdlib.h` يُظهر عددا من هذه التحذيرات، والتصريحات التي تستخدمها موجودة مع
ذلك.

## المؤشرات الخام و `غير_آمن`

قد ترجع دالة C مؤشرا خاما، `*ن`. وقراءة الذاكرة التي يشير إليها مؤشر خام شيء لا يستطيع المترجم فحصه، فيجب أن تُكتب داخل كتلة
`غير_آمن`:

```sultan fail
عرف الرئيسية(): عدد {
    ليكن القيم: متجه ط8 = [1 مثل ط8, 2 مثل ط8];
    ليكن المؤشر: *ط8 = &القيم[0];
    ليكن الأول: ط8 = *المؤشر;
    أرجع الأول مثل عدد;
}
```

```text
خطأ[SULTANC-SAFETY-UNSAFE-OPERATION]: العملية تتطلب نطاق غير آمن صريحا
  --> main.sn:4:20..4:27
   |
 4 |     ليكن الأول: ط8 = *المؤشر;
   |                    ^^^^^^^
   |
```

```sultan
عرف الرئيسية(): عدد {
    ليكن القيم: متجه ط8 = [1 مثل ط8, 2 مثل ط8];
    ليكن المؤشر: *ط8 = &القيم[0];
    ليكن الأول: متغير ط8 = 0;
    غير_آمن {
        الأول := *المؤشر;
    }
    أرجع الأول مثل عدد;
}
```

لا تعطّل `غير_آمن` الفحوص في باقي البرنامج. فهي تحدد الأسطر القليلة التي تكون أنت، لا المترجم، المسؤول فيها عن صلاحية
الذاكرة، فيعرف القارئ أو المراجع أين ينظر. أبقِ كتل `غير_آمن` صغيرة، وغلّفها بدوال معاملاتها آمنة، كما تفعل المكتبة القياسية مع
استدعاءات النظام الخاصة بها.

ويصف [جسر](../internals/jisr.md) في توثيق البنية الداخلية كيف تُترجم تصريحات C، وكل ما يجوز أن تحويه شيفرة C المترجمة.
