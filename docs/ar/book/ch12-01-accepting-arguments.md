# استقبال وسائط سطر الأوامر

أنشئ المشروع:

```console
$ supax new باحث
$ cd باحث
```

يعمل البرنامج بـ*وسيطين* (arguments): الكلمة المطلوبة، والملف الذي يُبحث فيه. ومع سوباكس تأتي وسائط البرنامج بعد `--`، حتى لا
يقرأها سوباكس على أنها له:

```console
$ supax run -- إبرة كومة.txt
```

## قراءة الوسائط

في `المكتبة.عمليات.وسيطة` الدالة `وسيطة(ع)`، التي ترجع الوسيط في الموضع `ع` قيمةً `اختياري نص`: `موجود(النص)`، أو `لا_شيء`
حين لا يوجد وسيط في ذلك الموضع. وفي `المكتبة.عمليات.عدد_الوسائط` الدالة `عدد_الوسائط()`، وهي عدد الوسائط. ابدأ بطباعتها كلها:

<sub>القائمة 12-1: طباعة كل وسيط. الملف: src/main.sn</sub>

```sultan ignore
استورد المكتبة.دخ.اطبع_سطر;
استورد المكتبة.عمليات.وسيطة;
استورد المكتبة.عمليات.عدد_الوسائط;

عرف الرئيسية(): عدد {
    ليكن العدد: طبيعي = عدد_الوسائط();
    لكل (ليكن ع: متغير طبيعي = 0; ع < العدد; ع := ع + 1) {
        طابق وسيطة(ع) مع
        | اختياري.موجود(النص) -> { اطبع_سطر(النص); }
        | اختياري.لا_شيء -> { };
    }
    أرجع 0;
}
```

```console
$ supax run -- إبرة كومة.txt
        يبني باحث v0.1.0 (/projects/باحث)
       انتهى في 0.14 ث → build/bin/باحث
       يشغّل build/bin/باحث
/projects/باحث/build/bin/باحث
إبرة
كومة.txt
```

في الموضع 0 مسار البرنامج نفسه، والوسائط التي كتبتها تبدأ من الموضع 1.

## حفظ الوسائط في متغيرات

يحتاج البرنامج إلى وسيطين، وينبغي أن يقول كيف يُستخدم حين يغيبان. فيخرج كل منهما من `اختياري` بـ `طابق`، والوسيط الغائب يطبع
سطر الاستخدام وينهي البرنامج بالحالة 2، وهي الحالة المعتادة لبرنامج استُدعي بطريقة خاطئة. ويأتي ذلك في أول القائمة التالية.
