# الدوال

تعطي الدالة اسما لعمل ما، فيُنفَّذ مرات كثيرة من أماكن كثيرة. وقد كتبت دالة من قبل: `الرئيسية`، حيث يبدأ كل برنامج. ويبيّن
هذا القسم كيف تكتب غيرها.

## تعريف دالة واستدعاؤها

```sultan
استورد المكتبة.دخ.اطبع_سطر;

عرف الرئيسية(): عدد {
    اطبع_سطر("مرحبا من الرئيسية");
    دالة_أخرى();
    أرجع 0;
}

عرف دالة_أخرى(): فراغ {
    اطبع_سطر("مرحبا من دالة أخرى");
}
```

```text
مرحبا من الرئيسية
مرحبا من دالة أخرى
```

تبدأ `عرف` تعريف الدالة، ثم الاسم، ثم المعاملات بين قوسين، ثم نقطتان ونوع القيمة التي ترجعها الدالة. و `دالة_أخرى` لا
ترجع شيئا، ويُكتب ذلك `فراغ`. ولا تحتاج دالة `فراغ` إلى `أرجع` في آخرها.

وتستدعي `الرئيسية` الدالة `دالة_أخرى` بكتابة اسمها ثم قوسين. ويجوز تعريف الدوال بأي ترتيب في الملف: فتستطيع `الرئيسية` أن
تستدعي دالة معرّفة تحتها.

## المعاملات

تستطيع الدالة أن تأخذ قيما من مستدعيها، تسمى *المعاملات* (parameters). ولكل معامل اسم ونوع، والنوع يُكتب دائما:

```sultan
استورد المكتبة.دخ.اطبع_سطر;
استورد المكتبة.نصوص.أعداد;
استورد المكتبة.نصوص.تحويل;

عرف اطبع_القياس(القيمة: عدد, الوحدة: &نص): فراغ {
    اطبع_سطر(صل_نصين(&عدد_إلى_نص(القيمة), الوحدة));
}

عرف الرئيسية(): عدد {
    اطبع_القياس(5, &" سم");
    اطبع_القياس(12, &" كغ");
    أرجع 0;
}
```

```text
5 سم
12 كغ
```

والقيم المعطاة في الاستدعاء، `5` و `&" سم"`، هي *الوسائط* (arguments)، وتقابل المعاملات بالترتيب.

ونوع المعامل الثاني `&نص`: مرجع إلى نص. فتقرأ الدالة النص دون أن تأخذه من مستدعيها. ويشرح
[الفصل الرابع](ch04-02-references-and-borrowing.md) ذلك بعمق، والآن يكفي أن الدالة التي تقرأ نصا فقط تأخذ `&نص`.

ويتحقق المترجم من كل استدعاء مقابل التعريف، فالوسيط الناقص خطأ:

```sultan fail
عرف اجمع(أ: عدد, ب: عدد): عدد {
    أرجع أ + ب;
}

عرف الرئيسية(): عدد {
    أرجع اجمع(1);
}
```

```text
خطأ[SULTANC-CALL-ARGUMENT-COUNT-MISMATCH]: عدد حجج النداء غير مطابق — الدالة تتوقع حجتين، لكن النداء يمرر حجة واحدة. عدد حجج الاستدعاء لا يطابق عدد معاملات الدالة.
  --> main.sn:6:10..6:17
   |
 6 |     أرجع اجمع(1);
   |          ^^^^^^^
   |
```

## إرجاع قيمة

الدالة التي ترجع قيمة تذكر نوعها بعد النقطتين، وتعطي القيمة بـ `أرجع`:

```sultan
استورد المكتبة.دخ.اطبع_سطر;
استورد المكتبة.نصوص.أعداد;

عرف مربع(س: عدد): عدد {
    أرجع س * س;
}

عرف الرئيسية(): عدد {
    اطبع_سطر(عدد_إلى_نص(مربع(7)));
    اطبع_سطر(عدد_إلى_نص(مربع(3) + مربع(4)));
    أرجع 0;
}
```

```text
49
25
```

ويحل محل الاستدعاء القيمةُ التي ترجعها الدالة، فيجوز استخدامه حيث تُستخدم أي قيمة، ومن ذلك داخل استدعاء آخر أو تعبير آخر.

وتنهي `أرجع` الدالة فورا، فيجوز أن تظهر في أي مكان من الجسم. وفحص الحالات الخاصة أولا والرجوع مبكرا يبقي باقي الدالة
بسيطا:

```sultan
استورد المكتبة.دخ.اطبع_سطر;

عرف صف(العمر: عدد): نص {
    إذا (العمر < 0) {
        أرجع "غير صالح";
    };
    إذا (العمر < 18) {
        أرجع "قاصر";
    };
    أرجع "بالغ";
}

عرف الرئيسية(): عدد {
    اطبع_سطر(صف(-1));
    اطبع_سطر(صف(12));
    اطبع_سطر(صف(40));
    أرجع 0;
}
```

```text
غير صالح
قاصر
بالغ
```

ويجب أن يصل كل طريق في دالة ترجع قيمة إلى `أرجع`. فإن أمكن أن ينتهي طريق دونها، لم يترجم البرنامج:

```sultan fail
عرف الإشارة(ن: عدد): عدد {
    إذا (ن > 0) {
        أرجع 1;
    };
}

عرف الرئيسية(): عدد {
    أرجع الإشارة(2);
}
```

```text
خطأ[SULTANC-FLOW-MISSING-RETURN]: ليست كل مسارات التنفيذ ترجع قيمة — ينتهي أحد مسارات الدالة دون إرجاع قيمة.
  --> main.sn:1:1..5:2
   |
 1 | عرف الإشارة(ن: عدد): عدد {
   | ^
   |
```

فحين يكون `ن` صفرا أو أقل، تنتهي `الإشارة` دون قيمة ترجعها. والإصلاح أن تذكر ما ترجعه في ذلك الطريق أيضا، مثل `أرجع 0;`
قبل `}` الأخيرة.

### جمل، لا تعابير

جسم الدالة قائمة *جمل* (statements)، تنتهي كل منها بـ `;`: `دع`، أو إسناد، أو استدعاء، أو `إذا`، أو `طابق`، أو حلقة، أو
`أرجع`. والقيمة وحدها ليست جملة، فآخر قيمة في الجسم لا تُرجَع وحدها، بل `أرجع` تُكتب دائما. وكذلك `إذا` و `طابق` تختاران
أي الجمل يُنفَّذ، ولا تنتجان قيمة. فيسهل أن تجد كل موضع ترجع منه الدالة قيمة: ابحث عن `أرجع`.

## المعاملات ثابتة

المعامل متغير كغيره، وثابت إلا إذا قال نوعه `متغير`. وتغيير معامل `متغير` يغيّر نسخة الدالة نفسها فقط، وتبقى قيمة
المستدعي كما هي:

```sultan
استورد المكتبة.دخ.اطبع_سطر;
استورد المكتبة.نصوص.أعداد;

عرف عد_تنازلي(ن: متغير عدد): فراغ {
    طالما (ن > 0) {
        اطبع_سطر(عدد_إلى_نص(ن));
        ن := ن - 1;
    }
}

عرف الرئيسية(): عدد {
    دع البداية: عدد = 3;
    عد_تنازلي(البداية);
    اطبع_سطر(عدد_إلى_نص(البداية));
    أرجع 0;
}
```

```text
3
2
1
3
```

## تغيير متغير المستدعي

لتسمح لدالة بتغيير متغير يملكه مستدعيها، مرّر *مرجعا قابلا للتغيير*. فنوع المعامل `&متغير ن`، ويكتب الاستدعاء
`&متغير الاسم`، وتقرأ الدالة المتغير وتكتبه عبر `*`:

```sultan
استورد المكتبة.دخ.اطبع_سطر;
استورد المكتبة.نصوص.أعداد;

عرف أضف_مكافأة(الدرجة: &متغير عدد, المكافأة: عدد): فراغ {
    *الدرجة := *الدرجة + المكافأة;
}

عرف الرئيسية(): عدد {
    دع الدرجة: متغير عدد = 10;
    أضف_مكافأة(&متغير الدرجة, 5);
    اطبع_سطر(عدد_إلى_نص(الدرجة));
    أرجع 0;
}
```

```text
15
```

و `&متغير` في الاستدعاء إلزامية. فبقراءة `الرئيسية` وحدها ترى أن `أضف_مكافأة` قد تغيّر `الدرجة`، دون أن تنظر في
`أضف_مكافأة` نفسها.

## إرجاع قيمتين

ترجع الدالة قيمة واحدة، لكن هذه القيمة قد تكون صفّا. اكتب أجزاءه بين قوسين بعد `أرجع`:

```sultan
استورد المكتبة.دخ.اطبع_سطر;
استورد المكتبة.نصوص.أعداد;

عرف اقسم(أ: عدد, ب: عدد): (عدد, عدد) {
    أرجع (أ / ب, أ % ب);
}

عرف الرئيسية(): عدد {
    طابق اقسم(17, 5) مع
    | (الناتج, الباقي) -> {
        اطبع_سطر(عدد_إلى_نص(الناتج));
        اطبع_سطر(عدد_إلى_نص(الباقي));
    };
    أرجع 0;
}
```

```text
3
2
```

## دالة تستدعي نفسها

يجوز للدالة أن تستدعي نفسها، وهذا *الاستدعاء الذاتي* (recursion)، ويناسب المسائل التي تُعرَّف بنسخة أصغر منها:

```sultan
استورد المكتبة.دخ.اطبع_سطر;
استورد المكتبة.نصوص.أعداد;

عرف المضروب(ن: عدد): عدد {
    إذا (ن <= 1) {
        أرجع 1;
    };
    أرجع ن * المضروب(ن - 1);
}

عرف الرئيسية(): عدد {
    اطبع_سطر(عدد_إلى_نص(المضروب(10)));
    أرجع 0;
}
```

```text
3628800
```

ويحتاج كل استدعاء ذاتي إلى حالة لا تستدعي فيها الدالة نفسها، وهي هنا `ن <= 1`. وبدونها تظل الدالة تستدعي نفسها حتى تنفد
ذاكرة الاستدعاءات.

## الخلاصة

- تعرّف `عرف الاسم(المعامل: النوع, …): نوع_القيمة { … }` دالة، وكل نوع يُكتب.
- الدالة التي لا ترجع شيئا ترجع `فراغ`.
- ترجع `أرجع` قيمة وتنهي الدالة، ويجب أن يصل كل طريق في دالة ترجع قيمة إليها.
- المعاملات ثابتة إلا إذا كانت `متغير`، وتغييرها لا يغيّر قيمة المستدعي.
- يسمح `&متغير ن` للدالة بتغيير متغير مستدعيها، عبر `*`.
- يرجع الصف قيمتين أو أكثر معا.
