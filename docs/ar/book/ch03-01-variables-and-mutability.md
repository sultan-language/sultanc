# المتغيرات والتغيير

يعطي المتغير قيمةً اسما. وقد قابلت `دع` في الفصل الثاني، ويعرض هذا القسم قواعدها كاملة.

أنشئ مشروعا جديدا لأمثلة هذا الفصل، أو استخدم `sultanc run main.sn` مع الملفات المفردة. فكل قائمة هنا برنامج كامل.

## التصريح بمتغير

```sultan
استورد المكتبة.دخ.اطبع_سطر;
استورد المكتبة.نصوص.أعداد;

عرف الرئيسية(): عدد {
    دع السنة: عدد = 2026;
    اطبع_سطر(عدد_إلى_نص(السنة));
    أرجع 0;
}
```

```text
2026
```

اقرأ `دع السنة: عدد = 2026;` هكذا: "لتكن `السنة`، من النوع `عدد`، تساوي 2026". وتأتي الأجزاء دائما بهذا الترتيب: الاسم،
ثم النقطتان، ثم النوع، ثم `=`، ثم القيمة.

والنوع يُكتب دائما. فلا يستنتج السلطان نوع المتغير من قيمته أبدا، حتى حين يستطيع ذلك. فالبرنامج يُقرأ أكثر بكثير مما
يُكتب، وحين يكون النوع بجوار كل اسم لا تحتاج إلى تتبّع مصدر القيمة لتعرف ما هي.

وتطبع `اطبع_سطر` نصوصا لا أعدادا، فتحوّل `عدد_إلى_نص` (من `المكتبة.نصوص.أعداد`) العدد إلى نص أولا.

## المتغيرات ثابتة افتراضيا

حين يأخذ المتغير قيمة، لا تتغير هذه القيمة. جرّب أن تغيّرها:

```sultan fail
استورد المكتبة.دخ.اطبع_سطر;
استورد المكتبة.نصوص.أعداد;

عرف الرئيسية(): عدد {
    دع العدد: عدد = 5;
    اطبع_سطر(عدد_إلى_نص(العدد));
    العدد := 6;
    اطبع_سطر(عدد_إلى_نص(العدد));
    أرجع 0;
}
```

```text
خطأ[SULTANC-MUTABILITY-WRITE-TO-IMMUTABLE]: لا يمكن الكتابة إلى قيمة غير متغيرة — القيمة غير المتغيرة التي جرت محاولة الكتابة إليها هي ⁨`العدد`⁩. جرت محاولة إسناد قيمة إلى متغير غير قابل للتعديل.
  --> main.sn:7:5..7:10
   |
 7 |     العدد := 6;
   |     ^^^^^ الاستخدام غير الصالح
   |
  ::: main.sn:5:5..5:23
   |
 5 |     دع العدد: عدد = 5;
   |     ^^^^^^^^^^^^^^^^^^ صُرّح به هنا دون `متغير`
   |
  = مساعدة: صرح بالمتغير بـ⁨`متغير`⁩ لتكتب فيه
```

يقول المترجم إن `العدد` ثابت (immutable): لا يمكن تغييره. وهذا يحميك من نوع شائع من الأخطاء: حين يعتمد جزء من البرنامج على
بقاء قيمة كما هي، ويغيّرها جزء آخر، فيخطئ الجزء الأول خطأ يصعب تتبّعه. فإن لم يكن المتغير قابلا للتغيير، لم تحتج أبدا إلى
البحث عن المكان الذي غيّره.

لكن تغيير القيم كثيرا ما يكون ما تحتاجه بالضبط: عدّاد، أو مجموع يتراكم، أو موضع. وللسماح بذلك اكتب `متغير` قبل النوع:

```sultan
استورد المكتبة.دخ.اطبع_سطر;
استورد المكتبة.نصوص.أعداد;

عرف الرئيسية(): عدد {
    دع العدد: متغير عدد = 5;
    اطبع_سطر(عدد_إلى_نص(العدد));
    العدد := 6;
    اطبع_سطر(عدد_إلى_نص(العدد));
    أرجع 0;
}
```

```text
5
6
```

و `متغير` جزء من النوع، فهي أول ما تقرؤه عن المتغير، وتقول لقارئ الشيفرة: هذه القيمة ستتغير، فانتبه لها.

ولاحظ العلامتين المختلفتين. `=` لا تظهر إلا في التصريح، حيث يُنشأ الاسم. و `:=` لا تظهر إلا في الإسناد، حيث يأخذ متغير
موجود قيمة جديدة. فحين ترى `:=` فهناك تغيير دائما.

ولا توجد عوامل مركّبة مثل `+=`، بل اكتب التعبير كاملا:

```sultan
استورد المكتبة.دخ.اطبع_سطر;
استورد المكتبة.نصوص.أعداد;

عرف الرئيسية(): عدد {
    دع المجموع: متغير عدد = 0;
    المجموع := المجموع + 10;
    المجموع := المجموع * 3;
    اطبع_سطر(عدد_إلى_نص(المجموع));
    أرجع 0;
}
```

```text
30
```

## التصريح الآن، والقيمة لاحقا

يجوز التصريح بمتغير دون قيمة، ثم إعطاؤه قيمة لاحقا. وقد فعل الفصل الثاني ذلك مع `التخمين`، الذي جاءت قيمته من `طابق`.
وهذا مفيد كلما اعتمدت القيمة على قرار:

```sultan
استورد المكتبة.دخ.اطبع_سطر;

عرف الرئيسية(): عدد {
    دع الحرارة: عدد = 31;
    دع النصيحة: نص;
    إذا (الحرارة > 30) {
        النصيحة := "اشرب ماء";
    } وإلا {
        النصيحة := "استمتع بيومك";
    };
    اطبع_سطر(النصيحة);
    أرجع 0;
}
```

```text
اشرب ماء
```

ما زالت `النصيحة` ثابتة: تأخذ قيمة واحدة، في أي طريق يسلكه البرنامج. ويتحقق المترجم من أمرين. الأول: أن كل طريق يعطي
المتغير قيمة قبل استخدامه:

```sultan fail
استورد المكتبة.دخ.اطبع_سطر;

عرف الرئيسية(): عدد {
    دع الحرارة: عدد = 31;
    دع النصيحة: نص;
    إذا (الحرارة > 30) {
        النصيحة := "اشرب ماء";
    };
    اطبع_سطر(النصيحة);
    أرجع 0;
}
```

```text
خطأ[SULTANC-FLOW-USE-BEFORE-INITIALIZATION]: استخدام قبل التهيئة — القيمة المستخدمة قبل التهيئة هي ⁨`النصيحة`⁩. تُستخدم القيمة قبل تهيئتها.
  --> main.sn:5:5..5:20
   |
 5 |     دع النصيحة: نص;
   |     ^^^^^^^^^^^^^^^
   |
```

لو كانت الحرارة 20 لما كان لـ `النصيحة` قيمة حين تستخدمها `اطبع_سطر`. ويجد المترجم هذا الطريق دون تشغيل البرنامج. وتشير
الرسالة إلى تصريح `النصيحة`، المتغير الذي قد يُستخدم فارغا، والاستخدام هو `اطبع_سطر` تحته.

والثاني: أن المتغير الثابت يأخذ قيمته مرة واحدة فقط، فإسناد ثان بـ `:=` إلى `النصيحة` في الطريق نفسه هو خطأ الثبات نفسه
الذي رأيته قبل قليل.

## الثوابت

تصرّح `دع` خارج كل الدوال بـ *ثابت* (constant):

```sultan
استورد المكتبة.دخ.اطبع_سطر;
استورد المكتبة.نصوص.أعداد;

دع ثواني_الدقيقة: عدد = 60;
دع ثواني_الساعة: عدد = ثواني_الدقيقة * 60;

عرف الرئيسية(): عدد {
    اطبع_سطر(عدد_إلى_نص(ثواني_الساعة * 24));
    أرجع 0;
}
```

```text
86400
```

يُحسب الثابت أثناء ترجمة البرنامج لا أثناء تشغيله، فقيمته موجودة في البرنامج الناتج، ولا يكلّف استخدامها شيئا. وإن فشل
حسابه، كأن يقسم على صفر، فلا يترجم البرنامج.

والثوابت مفيدة للقيم التي تشترك فيها أجزاء كثيرة من البرنامج وينبغي أن تُسمّى مرة واحدة: حدّ، أو حجم، أو تحويل وحدة. فإذا
تغيرت القيمة لاحقا غيّرت سطرا واحدا.

## النطاق

يوجد المتغير من تصريحه إلى نهاية *الكتلة* (block) التي تحويه. والكتلة هي الشيفرة بين `{` و `}`: جسم دالة، أو فرع من
`إذا`، أو جسم حلقة. وهذه المنطقة هي *نطاق* المتغير (scope).

```sultan
استورد المكتبة.دخ.اطبع_سطر;
استورد المكتبة.نصوص.أعداد;

عرف الرئيسية(): عدد {
    دع الخارجي: عدد = 60;
    إذا (الخارجي > 0) {
        دع الداخلي: عدد = الخارجي + 5;
        اطبع_سطر(عدد_إلى_نص(الداخلي));
    };
    اطبع_سطر(عدد_إلى_نص(الخارجي));
    أرجع 0;
}
```

```text
65
60
```

لا يوجد `الداخلي` إلا داخل `إذا`، وبعد `}` التي تغلقها يختفي الاسم:

```sultan fail
استورد المكتبة.دخ.اطبع_سطر;
استورد المكتبة.نصوص.أعداد;

عرف الرئيسية(): عدد {
    دع الخارجي: عدد = 60;
    إذا (الخارجي > 0) {
        دع الداخلي: عدد = الخارجي + 5;
    };
    اطبع_سطر(عدد_إلى_نص(الداخلي));
    أرجع 0;
}
```

```text
خطأ[SULTANC-NAME-UNKNOWN]: الاسم ⁨`الداخلي`⁩ غير معروف — الاسم المطلوب مفقود أثناء حل المراجع.
  --> main.sn:9:25..9:32
   |
 9 |     اطبع_سطر(عدد_إلى_نص(الداخلي));
   |                         ^^^^^^^
   |
```

وفي الكتلة الواحدة لا يُصرَّح بالاسم إلا مرة واحدة:

```sultan fail
عرف الرئيسية(): عدد {
    دع السعر: عدد = 10;
    دع السعر: عدد = 12;
    أرجع السعر;
}
```

```text
خطأ[SULTANC-NAME-DUPLICATE-DECLARATION]: تصريح مكرر — الاسم المعرف أكثر من مرة هو ⁨`السعر`⁩. صُرح بالاسم نفسه أكثر من مرة في هذا النطاق.
  --> main.sn:3:5..3:24
   |
 3 |     دع السعر: عدد = 12;
   |     ^^^^^^^^^^^^^^^^^^^
   |
  ::: main.sn:2:5..2:24
   |
 2 |     دع السعر: عدد = 10;
   |     ^^^^^^^^^^^^^^^^^^^ سياق مرتبط
   |
  = ملاحظة: يظهر التصريح السابق كمصدر مرتبط
```

فلا يمكن أن يخفي `دع السعر` ثانٍ الأول بصمت في الكتلة نفسها. فإن كانت القيمة تحتاج إلى التغيير فاجعل المتغير `متغير`،
وإن كانت قيمة أخرى فأعطها اسما آخر. ويجوز لكتلة داخلية أن تصرّح باسم تستخدمه كتلة خارجية، وداخل الكتلة الداخلية يعني الاسم
المتغير الداخلي.

## الأسماء

يبدأ الاسم بحرف أو `_`، ثم حروف وأرقام و `_`. والحروف عربية أو لاتينية، في البرنامج نفسه. والأسماء اللاتينية تفرّق بين
الحروف الكبيرة والصغيرة: `total` و `Total` اسمان مختلفان.

وفي الأسماء العربية يعامل المترجم `أ` و `إ` و `آ` و `ا` حرفا واحدا، ويتجاهل التطويل `ـ`، فـ `أحمد` و `احمد` اسم واحد.
فالكتّاب العرب يكتبون هذه الحروف بطرق مختلفة، ولا ينبغي أن يتعطل البرنامج بسبب ذلك.

والعرف أن تُكتب أسماء المتغيرات والثوابت والدوال كلمات تصل بينها `_`: `السعر_الكلي` و `ثواني_الساعة`.

## الخلاصة

- تصرّح `دع الاسم: النوع = القيمة;` بمتغير، والنوع يُكتب دائما.
- المتغيرات ثابتة إلا إذا قال نوعها `متغير`، و `:=` تعطي المتغير القابل للتغيير قيمة جديدة.
- يجوز أن يأخذ المتغير قيمته بعد تصريحه، مرة واحدة، في كل طريق قبل استخدامه.
- `دع` خارج الدوال ثابت، يُحسب وقت الترجمة.
- يعيش المتغير حتى نهاية كتلته، ويُصرَّح بالاسم مرة واحدة في الكتلة.
