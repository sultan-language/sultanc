# ب. العوامل والرموز

عوامل السلطان ورموزه، مع الفصل الذي يشرح كلا منها. وهي نفسها في البرامج العربية والإنجليزية، إلا `؟` فلها كتابة إنجليزية
أيضا، `?`.

## العوامل

| العامل | مثال | المعنى | الفصل |
| --- | --- | --- | --- |
| `+` `-` `*` `/` | `أ + ب` | الحساب، و `/` بين الأعداد الصحيحة تقرّب نحو الصفر | [3.2](ch03-02-data-types.md) |
| `%` | `أ % ب` | الباقي، بإشارة `أ` | [3.2](ch03-02-data-types.md) |
| `-` | `-أ` | السالب | [3.2](ch03-02-data-types.md) |
| `==` `!=` | `أ == ب` | يساوي، لا يساوي | [3.2](ch03-02-data-types.md) |
| `<` `<=` `>` `>=` | `أ < ب` | مقارنات الترتيب | [3.2](ch03-02-data-types.md) |
| `&&` `\|\|` | `أ && ب` | و، أو، ولا يُحسب الطرف الأيمن إلا عند الحاجة | [3.2](ch03-02-data-types.md) |
| `!` | `!أ` | ليس | [3.2](ch03-02-data-types.md) |
| `&` `\|` `^` | `أ & ب` | و، أو، أو الحصرية على البتات | [3.2](ch03-02-data-types.md) |
| `~` | `~أ` | عكس البتات | [3.2](ch03-02-data-types.md) |
| `<<` | `أ << ن` | إزاحة إلى اليسار | [3.2](ch03-02-data-types.md) |
| `>>` | `أ >> ن` | إزاحة منطقية إلى اليمين: تملأ بالأصفار | [3.2](ch03-02-data-types.md) |
| `>>>` | `أ >>> ن` | إزاحة حسابية إلى اليمين: تحفظ الإشارة | [3.2](ch03-02-data-types.md) |
| `مثل` | `أ مثل ط8` | تحويل نوع العدد | [3.2](ch03-02-data-types.md) |
| `:=` | `س := 5;` | الإسناد إلى متغير `متغير` | [3.1](ch03-01-variables-and-mutability.md) |
| `&` | `&س` | مرجع للقراءة | [4.2](ch04-02-references-and-borrowing.md) |
| `&متغير` | `&متغير س` | مرجع قابل للتغيير | [4.2](ch04-02-references-and-borrowing.md) |
| `*` | `*ر` | القيمة التي يشير إليها مرجع أو مؤشر | [4.2](ch04-02-references-and-borrowing.md) |
| `؟` | `د()؟` | تعطي قيمة `نجح`، أو ترجع الخطأ | [9.2](ch09-02-recoverable-errors.md) |
