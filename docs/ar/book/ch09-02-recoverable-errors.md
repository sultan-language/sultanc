# أخطاء قابلة للمعالجة بـ `نتيجة` و `؟`

أغلب الإخفاقات ليست أخطاء برمجية. فالملف مفقود لأن المستخدم أخطأ في كتابة اسمه، والعدد لا يُقرأ لأن في المدخلات خطأ مطبعيا.
وينبغي أن يلاحظ البرنامج ويقرر ماذا يفعل: يسأل من جديد، أو يستخدم قيمة افتراضية، أو يبلّغ عن المشكلة ويتوقف بأدب.

## `نتيجة`

كما بيّن الفصل السادس، ترجع الدالة التي قد تفشل `نتيجة ن, خ`: إما `نتيجة.نجح(القيمة)`، قيمة من النوع `ن`، وإما
`نتيجة.خطأ(المشكلة)`، خطأ من النوع `خ`:

```sultan
استورد المكتبة.دخ.اطبع_سطر;
استورد المكتبة.نصوص.أعداد;

عرف اقسم(أ: عدد, ب: عدد): نتيجة عدد, نص {
    إذا (ب == 0) {
        أرجع نتيجة.خطأ("قسمة على صفر");
    };
    أرجع نتيجة.نجح(أ / ب);
}

عرف الرئيسية(): عدد {
    طابق اقسم(84, 2) مع
    | نتيجة.نجح(القيمة) -> { اطبع_سطر(عدد_إلى_نص(القيمة)); }
    | نتيجة.خطأ(الرسالة) -> { اطبع_سطر(الرسالة); };
    طابق اقسم(1, 0) مع
    | نتيجة.نجح(القيمة) -> { اطبع_سطر(عدد_إلى_نص(القيمة)); }
    | نتيجة.خطأ(الرسالة) -> { اطبع_سطر(الرسالة); };
    أرجع 0;
}
```

```text
42
قسمة على صفر
```

لا يستطيع المستدعي استخدام العدد دون `طابق` تجيب أيضا عن "وإن فشل؟". فالفشل يُعالج، أو يُمرَّر، أو يُتجاهل عمدا، لكنه لا
يُنسى.

ونوع الخطأ `خ` يمكن أن يكون أي شيء: رسالة `نص`، أو تعدادا يسرد المشكلات الممكنة، أو النوع القياسي `فشل` المعروض أدناه.

## تمرير الخطأ إلى الأعلى بـ `؟`

كثيرا ما لا تستطيع الدالة إصلاح الخطأ بنفسها، فينبغي أن تسلّمه لمستدعيها. وبـ `طابق` يكلّف ذلك أربعة أسطر لكل استدعاء:

```sultan ignore
    دع الأول: عدد;
    طابق اقسم(المجموع, العدد) مع
    | نتيجة.نجح(القيمة) -> { الأول := القيمة; }
    | نتيجة.خطأ(المشكلة) -> { أرجع نتيجة.خطأ(المشكلة); };
```

و `؟` بعد الاستدعاء تفعل الشيء نفسه بمحرف واحد. فإن رجع الاستدعاء بـ `نجح` أعطت `؟` قيمته، وإن رجع بـ `خطأ` أرجعت الدالة ذلك
الخطأ فورا:

```sultan
استورد المكتبة.دخ.اطبع_سطر;
استورد المكتبة.نصوص.أعداد;

عرف اقسم(أ: عدد, ب: عدد): نتيجة عدد, نص {
    إذا (ب == 0) {
        أرجع نتيجة.خطأ("قسمة على صفر");
    };
    أرجع نتيجة.نجح(أ / ب);
}

عرف متوسط_مرتين(المجموع: عدد, العدد: عدد, الإضافي: عدد): نتيجة عدد, نص {
    دع الأول: عدد = اقسم(المجموع, العدد)?;
    دع الثاني: عدد = اقسم(الأول, الإضافي)?;
    أرجع نتيجة.نجح(الثاني);
}

عرف الرئيسية(): عدد {
    طابق متوسط_مرتين(100, 5, 2) مع
    | نتيجة.نجح(ق) -> { اطبع_سطر(عدد_إلى_نص(ق)); }
    | نتيجة.خطأ(خ) -> { اطبع_سطر(خ); };
    طابق متوسط_مرتين(100, 0, 2) مع
    | نتيجة.نجح(ق) -> { اطبع_سطر(عدد_إلى_نص(ق)); }
    | نتيجة.خطأ(خ) -> { اطبع_سطر(خ); };
    أرجع 0;
}
```

```text
10
قسمة على صفر
```

وتبقى `؟` ظاهرة في الشيفرة: فبقراءة `متوسط_مرتين` ترى بالضبط أي الاستدعاءات قد تنهي الدالة مبكرا.

ولـ `؟` قاعدتان. لا تُستخدم إلا في دالة ترجع هي نفسها `نتيجة`، إذ قد ترجع واحدة. ويجب أن يتطابق نوعا الخطأ: فـ `؟` على
`نتيجة عدد, نص` تعمل في دالة نوع خطئها `نص` أيضا. وهذه `؟` في دالة ترجع `عدد`:

```sultan fail
عرف اقسم(أ: عدد, ب: عدد): نتيجة عدد, نص {
    إذا (ب == 0) {
        أرجع نتيجة.خطأ("قسمة على صفر");
    };
    أرجع نتيجة.نجح(أ / ب);
}

عرف الرئيسية(): عدد {
    دع النصف: عدد = اقسم(10, 2)?;
    أرجع النصف;
}
```

```text
خطأ[SULTANC-TYPE-RETURN-MISMATCH]: نوع الإرجاع غير مطابق — نوع الإرجاع المتوقع هو ⁨`عدد`⁩، لكن نوع الإرجاع الفعلي هو ⁨`نتيجة عدد, نص`⁩. نوع التعبير المعاد لا يطابق نوع إرجاع الدالة.
  --> main.sn:9:32..9:33
   |
 9 |     دع النصف: عدد = اقسم(10, 2)?;
   |                                ^
   |
```

تشير الرسالة إلى `؟`: فعند الخطأ سترجع `نتيجة عدد, نص` من `الرئيسية` التي ترجع `عدد`. فعالج الخطأ هناك بـ `طابق`، أو اجعل
الدالة ترجع `نتيجة`.

وتعمل `؟` على `اختياري` أيضا، في دالة ترجع `اختياري`: تعطي القيمة، أو ترجع `لا_شيء` فورا.

## نوع الخطأ القياسي

البرنامج المبني من مكتبات كثيرة يحتاج إلى نوع خطأ واحد يفهمه كل جزء. وتقدمه المكتبة القياسية: `فشل` في
`المكتبة.أخطاء.فشل`. ولـ `فشل` رسالة، ويمكن أن يحمل هوية (مجالا ونوعا، للشيفرة التي يجب أن تقرر ماذا تفعل)، وسببا،
وملاحظات.

```sultan
استورد المكتبة.دخ.اطبع_سطر;
استورد المكتبة.نصوص.أعداد;
استورد المكتبة.أخطاء.فشل;

عرف حلل_العمر(النص: &نص): نتيجة عدد, فشل {
    طابق حلل_عدد(النص) مع
    | نتيجة.نجح(ن) -> {
        إذا (ن < 0) {
            أرجع نتيجة.خطأ(فشل_من("العمر لا يكون سالبا"));
        };
        أرجع نتيجة.نجح(ن);
    }
    | نتيجة.خطأ(_) -> {
        أرجع نتيجة.خطأ(فشل_من("يجب أن يكون العمر عددا"));
    };
}

عرف الرئيسية(): عدد {
    طابق حلل_العمر(&"31") مع
    | نتيجة.نجح(العمر) -> { اطبع_سطر(عدد_إلى_نص(العمر)); }
    | نتيجة.خطأ(المشكلة) -> { اطبع_سطر(صف_فشل(&المشكلة)); };
    طابق حلل_العمر(&"ثلاثون") مع
    | نتيجة.نجح(العمر) -> { اطبع_سطر(عدد_إلى_نص(العمر)); }
    | نتيجة.خطأ(المشكلة) -> { اطبع_سطر(صف_فشل(&المشكلة)); };
    أرجع 0;
}
```

```text
31
يجب أن يكون العمر عددا
```

تصنع `فشل_من` خطأ من رسالة، وتعطي `صف_فشل` وصفه الكامل مع أسبابه. ويغطي [الأخطاء](../reference/errors.md) في المرجع
الهويات والأسباب والملاحظات والرسائل بعدة لغات.

## `الرئيسية` قد ترجع `نتيجة`

يجوز أن ترجع `الرئيسية` النوع `نتيجة عدد, فشل` بدلا من `عدد`. فتعمل `؟` في `الرئيسية` أيضا. وحين ترجع `الرئيسية` خطأ،
يطبعه البرنامج في الخطأ القياسي ويخرج بالحالة 1:

```sultan exit=1
استورد المكتبة.دخ.اطبع_سطر;
استورد المكتبة.نصوص.أعداد;
استورد المكتبة.أخطاء.فشل;

عرف حلل_العمر(النص: &نص): نتيجة عدد, فشل {
    طابق حلل_عدد(النص) مع
    | نتيجة.نجح(ن) -> { أرجع نتيجة.نجح(ن); }
    | نتيجة.خطأ(_) -> { أرجع نتيجة.خطأ(فشل_من("يجب أن يكون العمر عددا")); };
}

عرف الرئيسية(): نتيجة عدد, فشل {
    دع الأول: عدد = حلل_العمر(&"31")?;
    اطبع_سطر(عدد_إلى_نص(الأول));
    دع الثاني: عدد = حلل_العمر(&"ثلاثون")?;
    اطبع_سطر(عدد_إلى_نص(الثاني));
    أرجع نتيجة.نجح(0);
}
```

في الخرج القياسي العمر الأول:

```text
31
```

وفي الخطأ القياسي الخطأ:

```text stderr
خطأ[SULTANC-RUNTIME-PROGRAM-ERROR]: انتهى البرنامج بخطأ
يجب أن يكون العمر عددا
```

العدد في `نتيجة.نجح(0)` هو حالة الخروج عند النجاح. ويجب أن يكون نوع خطأ `الرئيسية` هو `فشل`: فإن رجعت `الرئيسية`
`نتيجة عدد, نص` رُفضت، وتعلّم الرسالة `نص`، ومعها إصلاح يكتب `فشل` مكانه.
