# القنوات

بدلا من تشارك قيمة، تستطيع الخيوط أن ترسل قيما إلى بعضها. و*القناة* (channel) لها طرفان: تدخل القيم من المرسل وتخرج من
المستلم، بالترتيب. وكل قيمة تنتقل من خيط إلى آخر، فلا يملكها في أي وقت إلا خيط واحد.

تصنع `مستلم_قناة<ق>()` من `المكتبة.تزامن.قناة` قناة وترجع طرف استلامها، وتصنع `مرسل_لمستلم(&المستلم)` مرسلا لها. وتضع
`أرسل(&المرسل, القيمة)` قيمة فيها، وتنتظر `استقبل(&المستلم)` القيمة التالية:

```sultan
استورد المكتبة.دخ.اطبع_سطر;
استورد المكتبة.نصوص.أعداد;
استورد المكتبة.خيوط.خيط;
استورد المكتبة.تزامن.قناة;

عرف أنتج(الصادر: &مرسل<عدد>): فراغ {
    لكل (ليكن ع: متغير عدد = 1; ع <= 5; ع := ع + 1) {
        طابق أرسل(الصادر, ع * ع) مع
        | نتيجة.نجح(_) -> { }
        | نتيجة.خطأ(_) -> { };
    }
}

عرف الرئيسية(): عدد {
    ليكن الوارد: مستلم<عدد> = مستلم_قناة<عدد>();
    ليكن الصادر: مرسل<عدد> = مرسل_لمستلم(&الوارد);
    ليكن العامل: متغير مقبض_خيط;
    طابق أطلق(دالة(): فراغ -> أنتج(&الصادر)) مع
    | نتيجة.نجح(م) -> { العامل := م; }
    | نتيجة.خطأ(_) -> { أرجع 1; };
    ليكن انتهى: متغير منطقي = خطأ;
    طالما (!انتهى) {
        طابق استقبل(&الوارد) مع
        | نتيجة.نجح(القيمة) -> { اطبع_سطر(عدد_إلى_نص(القيمة)); }
        | نتيجة.خطأ(_) -> { انتهى := صواب; };
    }
    انضم(&متغير العامل);
    أرجع 0;
}
```

```text
1
4
9
16
25
```

يملك الخيط العامل المرسل، فقد التقطه الـ closure الخاص به. وحين ينتهي الخيط يُحرَّر الـ closure والمرسل، فلا يبقى للقناة مرسلون،
فترجع `استقبل` خطأ بدلا من الانتظار إلى الأبد. وبهذا تعرف `الرئيسية` أن لا شيء آخر سيأتي.

وتصنع `قناة<ق>()` الطرفين معا، في قيمة واحدة من `طرفا_قناة<ق>`. وتستعير `مرسل_الطرفين(&الطرفان)` و`مستلم_الطرفين(&الطرفان)`
كل طرف منهما، كما في `أرسل(مرسل_الطرفين(&الطرفان), 7)`. ولتعطي كل طرف مالكا خاصا به، كما يفعل البرنامج أعلاه، اصنعهما واحدا
بعد الآخر بـ `مستلم_قناة` و`مرسل_لمستلم`.

وتصنع `استنسخ_مرسل` مرسلا آخر للقناة نفسها، فترسل عدة خيوط إلى مستلم واحد. وفي مجلد `examples/ar/sync` من المستودع برنامج لكل
أداة في `المكتبة.تزامن`: العمليات الذرية، وأقفال القراءة والكتابة، ومتغيرات الشرط، والطوابير المحدودة.

## الخلاصة

- تطلق `أطلق_بقيمة(د)` خيطا، وتنتظره `انضم_بقيمة(&متغير م)` وترجع ناتجه.
- يملك الـ closure المرسل إلى خيط ما يلتقطه، ولا يجوز أن يلتقط مرجعا.
- يتشارك `مشترك<ق>` قيمة واحدة بين مالكين، ويعطي `قفل<ق>` الوصول إليها لخيط واحد في كل وقت، عبر `نفذ_مع_القفل`.
- تنقل القناة القيم من خيط إلى خيط، وتفشل `استقبل` حين يزول كل المرسلين.
- يفحص المترجم هذه القواعد: فالبرنامج الذي يترجم لا سباق بيانات فيه.
