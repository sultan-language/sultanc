# التعامل مع نظام التشغيل

يعيش البرنامج داخل نظام تشغيل يملك الملفات، والبيئة، والبرامج الأخرى، والساعة. وتصل المكتبة القياسية إلى كل منها عبر وحدات
تعمل بالطريقة نفسها على كل نظام يدعمه السلطان:

| الوحدة | ما فيها |
| --- | --- |
| `المكتبة.ملفات.قراءة_ملف` و `المكتبة.ملفات.كتابة_ملف` | الملف كله نصا |
| `المكتبة.ملفات.تعديل` | `أعد_تسمية` و `أزل_ملفا` و `أنشئ_دليلا` و `أزل_دليلا` |
| `المكتبة.ملفات.اجتياز` | `أنشئ_مسار_الدليل` و `احذف_الشجرة` و `اجتز_الشجرة` |
| `المكتبة.ملفات.مجلد` | `اقرأ_مدخلات_الدليل` و `حاول_وجود_المسار` و `حاول_مسار_ملف` و `حاول_مسار_دليل` |
| `المكتبة.بيئة.بيئة_العمل` | `متغير_بيئة` و `دليل_العمل` و `الدليل_المؤقت` |
| `المكتبة.عمليات.الوسائط` | `الوسائط`: سطر الأوامر متجها |
| `المكتبة.عمليات.أمر` | تشغيل برامج أخرى |
| `المكتبة.وقت.الوقت` | الساعة، والنوم |
| `المكتبة.وقت.تقويم` | الأيام والشهور والسنوات الكبيسة |

وكل شيء هنا قد يفشل لأسباب خارج البرنامج، فأغلب الدوال ترجع `نتيجة`. وأخطاء دوال الملفات رموز خطأ نظام التشغيل، من النوع
`عدد`.
