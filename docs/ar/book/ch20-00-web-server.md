# المشروع الأخير: بناء خادم ويب متعدد الخيوط

ينتهي الكتاب بمشروع يجمع كثيرا من فصوله: خادم ويب. يطلب منه المتصفح صفحة، فيجيبه بها عبر الشبكة، بالبروتوكول HTTP.

والخطة:

1. الاستماع للاتصالات على منفذ TCP.
2. قراءة الطلب الذي يرسله المتصفح.
3. إرسال رد: سطر الحالة، والترويسات، وصفحة HTML.
4. خدمة طلبات كثيرة في وقت واحد، بمجموعة من الخيوط العاملة.
5. التوقف بنظام، مع ترك العمال ينهون ما بدؤوه.

وهذا الخادم صغير، مكتوب ليبيّن كيف تعمل الأجزاء. أما الخادم الحقيقي، بالتوجيه وتحليل الطلبات وحدود الأمان وغيرها كثير، فعمل
مكتبة: وفي فهرس الحزم نهر، إطار ويب مكتوب بالسلطان.
