# الملفات والمجلدات

## كتابة ملف وقراءته

تنشئ `اكتب_الملف(&المسار, &النص)` ملفا بالنص المعطى، أو تستبدله. وتقرأ `اقرأ_الملف(&المسار)` الملف كله نصا. وتقسم `أسطر_النص`
من `المكتبة.نصوص.تحويل` النص إلى أسطره:

```sultan
استورد المكتبة.دخ.اطبع_سطر;
استورد المكتبة.نصوص.أعداد;
استورد المكتبة.نصوص.تحويل;
استورد المكتبة.ملفات.كتابة_ملف;
استورد المكتبة.ملفات.قراءة_ملف;
استورد المكتبة.ملفات.تعديل;

عرف الرئيسية(): عدد {
    دع المسار: نص = "shopping.txt";
    دع القائمة: نص = "خبز\nحليب\nتمر\n";
    طابق اكتب_الملف(&المسار, &القائمة) مع
    | نتيجة.خطأ(الرمز) -> { أرجع الرمز; }
    | نتيجة.نجح(_) -> { };
    طابق اقرأ_الملف(&المسار) مع
    | نتيجة.نجح(النص) -> {
        دع الأصناف: متجه نص = أسطر_النص(&النص);
        لكل (دع ع: متغير عدد = 0; ع < الطول(الأصناف); ع := ع + 1) {
            اطبع_سطر(صل_ثلاثة_نصوص(&عدد_إلى_نص(ع + 1), &". ", &الأصناف[ع]));
        }
    }
    | نتيجة.خطأ(الرمز) -> { أرجع الرمز; };
    طابق أزل_ملفا(&المسار) مع
    | نتيجة.نجح(_) -> { }
    | نتيجة.خطأ(الرمز) -> { أرجع الرمز; };
    أرجع 0;
}
```

```text
1. خبز
2. حليب
3. تمر
```

عند الخطأ يرجع هذا البرنامج رمز خطأ نظام التشغيل حالةَ خروج له، وهي طريقة سريعة للإبلاغ عنه في أداة صغيرة.

والمسار النسبي مثل `shopping.txt` نسبي إلى *دليل العمل* (current directory): المجلد الذي بدأ منه البرنامج، لا مجلد ملف
البرنامج.

## المجلدات

تنشئ `أنشئ_مسار_الدليل` مجلدا مع أي مجلدات ناقصة فوقه. وتقول `حاول_وجود_المسار` هل المسار موجود، وتنقل `أعد_تسمية` ملفا أو مجلدا
أو تعيد تسميته، وتحذف `احذف_الشجرة` مجلدا بكل ما فيه:

```sultan
استورد المكتبة.دخ.اطبع_سطر;
استورد المكتبة.نصوص.أعداد;
استورد المكتبة.ملفات.اجتياز;
استورد المكتبة.ملفات.مجلد;
استورد المكتبة.ملفات.كتابة_ملف;
استورد المكتبة.ملفات.تعديل;

عرف الرئيسية(): عدد {
    دع المجلد: نص = "reports/2026";
    طابق أنشئ_مسار_الدليل(&المجلد) مع
    | نتيجة.خطأ(الرمز) -> { أرجع الرمز; }
    | نتيجة.نجح(_) -> { };
    دع المسودة: نص = "reports/2026/draft.txt";
    دع النهائي: نص = "reports/2026/final.txt";
    دع النص: نص = "المجموع: 42\n";
    طابق اكتب_الملف(&المسودة, &النص) مع
    | نتيجة.خطأ(الرمز) -> { أرجع الرمز; }
    | نتيجة.نجح(_) -> { };
    طابق أعد_تسمية(&المسودة, &النهائي) مع
    | نتيجة.خطأ(الرمز) -> { أرجع الرمز; }
    | نتيجة.نجح(_) -> { };
    طابق حاول_وجود_المسار(&المسودة) مع
    | نتيجة.نجح(صواب) -> { اطبع_سطر("المسودة ما زالت هناك"); }
    | نتيجة.نجح(خطأ) -> { اطبع_سطر("أُعيدت تسمية المسودة"); }
    | نتيجة.خطأ(الرمز) -> { أرجع الرمز; };
    طابق اقرأ_مدخلات_الدليل(&المجلد) مع
    | نتيجة.نجح(المدخلات) -> { اطبع_سطر(عدد_إلى_نص(الطول(المدخلات))); }
    | نتيجة.خطأ(الرمز) -> { أرجع الرمز; };
    دع الأعلى: نص = "reports";
    طابق احذف_الشجرة(&الأعلى) مع
    | نتيجة.نجح(_) -> { اطبع_سطر("حُذف"); }
    | نتيجة.خطأ(الرمز) -> { أرجع الرمز; };
    أرجع 0;
}
```

```text
أُعيدت تسمية المسودة
1
حُذف
```

ترجع `اقرأ_مدخلات_الدليل` مدخلات مجلد واحد، وترجع `اجتز_الشجرة` مدخلات مجلد وكل ما تحته.

وفي `المكتبة.ملفات` المزيد: معلومات الملف مثل حجمه ووقت تعديله، والصلاحيات، والوصلات، والملفات المؤقتة، وأقفال الملفات. وفي
مجلد `examples/ar/fs` من المستودع برنامج لكل منها.
