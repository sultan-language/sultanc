# `Supax.lock` والبناء القابل للتكرار

المتطلب مثل `"1.2"` يسمح بإصدارات كثيرة. فلو أخذ كل بناء أحدثها لبُني المشروع غدا بشكل مختلف عن اليوم، أو على جهاز زميلك بشكل
مختلف عن جهازك، دون أي تغيير في شيفرته. ولمنع ذلك يكتب أول بناء `Supax.lock`.

## ملف القفل

يسجل `Supax.lock` لكل حزمة في البناء الشيفرة التي استُخدمت بالضبط:

```toml
[[package]]
name = "nahr"
version = "0.1.0-dev"
source = "registry"
registry = "https://github.com/sultan-language/index"
git = "https://github.com/supax0/nahr.git"
commit = "52953e2f953ff8061b686bf0e29b9eabf28dfb8d"
checksum = "sha256:02107f24d2d6b4d362aff7be8e7ce99d54d5f3e4c03eb41537ae359fe629e01c"
```

يسمّي الـ *commit* النسخة الدقيقة من الشيفرة، و*البصمة* (checksum) أثر يدل على محتواها: فلو تغير بايت واحد في الحزمة لما
طابقت البصمة، ولرفضها سوباكس. والبناءات اللاحقة تستخدم ما يقوله ملف القفل، أيا كانت الإصدارات الأحدث.

احفظ `Supax.lock` في git مع شيفرتك. فسوباكس يكتبه، ولا تعدّله بيدك.

## التحديث عن قصد

لا تتغير الاعتماديات إلا حين تطلب. فيعيد `supax update` حل كل المتطلبات، ويأخذ أحدث الإصدارات التي تسمح بها، ويعيد كتابة ملف
القفل، ويفعل `supax update الاسم` ذلك لحزمة واحدة. راجع التغيير، وشغّل الاختبارات، واحفظ ملف القفل الجديد.

## البناء دون شبكة

كل ما يجلبه سوباكس يُحفظ في مخبأ (cache)، في `.supax/git` داخل مجلد المستخدم. وبعد أول جلب لا يحتاج البناء إلى شبكة:

| الخيار | أثره |
| --- | --- |
| `--offline` | لا يستخدم الشبكة أبدا، بل المخبأ وحده |
| `--locked` | يفشل إن احتاج `Supax.lock` إلى تغيير |
| `--frozen` | الاثنان معا: البناء الذي ينبغي أن يشغّله خادم البناء |

ويفحص `supax verify`، دون شبكة، أن المخبأ يحوي بالضبط ما يسجله ملف القفل:

```console
$ supax verify
سليم: حزمة واحدة تطابق Supax.lock والمخبأ
```

ويعرض `supax cache info` مكان المخبأ وحجمه، ويحذفه `supax cache clean`، ويُجلب ما يُحتاج من جديد في البناء التالي.

## ما لا يفعله سوباكس

الحزمة شيفرة كتبها غيرك، فيعاملها سوباكس بحذر. فلا يشغّل أبدا شيئا يأتي من حزمة جلبها: فلا سكربتات بناء، ولا تعمل خطافات git
(hooks). وكل نسخة مسحوبة للقراءة فقط، وتُفحص بصمتها قبل كل استخدام. ولا تستطيع اعتمادية `path` داخل حزمة مجلوبة أن تصل إلى
خارج مستودعها. وتُرفض أسماء الحزم التي تبدو متطابقة للقارئ وتختلف في محارف مخفية.
