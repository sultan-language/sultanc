# ما الملكية؟

## نوعان من القيم

بعض القيم حجمها صغير وثابت ومعروف وقت الترجمة: فـ `عدد` دائما 8 بايتات، و `منطقي` بايت واحد. والمتغير من هذه الأنواع يحمل
القيمة نفسها، ونسخها رخيص كنسخ عدد. ويسمي السلطان هذه القيم *بسيطة* (plain). والأعداد و `منطقي` و `حرف`، والسجلات
والصفوف المكونة من قيم بسيطة فقط، كلها بسيطة.

وقيم أخرى يمكن أن تكبر أثناء عمل البرنامج. فقد يحمل `نص` محرفا واحدا أو كتابا كاملا، وقد يحمل `متجه` ثلاثة عناصر أو ثلاثة
ملايين. ومحتواها يعيش في منطقة منفصلة من الذاكرة اسمها *الكومة* (heap)، تُحجز عند الحاجة. ولا يحمل المتغير إلا وصفا صغيرا:
أين المحتوى، وكم حجمه. فهذه القيم *تملك* ذاكرتها، ويسميها السلطان *مالكة* (owning). و `نص` و `متجه` وكل سجل أو صف أو
تعداد يحتوي أحدهما، كلها مالكة.

والقيم البسيطة لا تحتاج إلى قواعد: فحين ينتهي متغير بسيط لا يوجد ما يُعاد. فقواعد الملكية تخص القيم المالكة، التي يجب أن
تُحرَّر ذاكرتها مرة واحدة بالضبط.

## قواعد الملكية

1. لكل قيمة مالكة متغير واحد يملكها، هو *مالكها*.
2. لا يوجد إلا مالك واحد في كل وقت.
3. حين يخرج المالك من نطاقه، تُحرَّر ذاكرة القيمة.

رأيت النطاق في الفصل الثالث: يعيش المتغير من تصريحه إلى نهاية كتلته. والقاعدة الثالثة تقول إن هناك أيضا تعود ذاكرته:

```sultan
استورد المكتبة.دخ.اطبع_سطر;

عرف الرئيسية(): عدد {
    ليكن التحية: نص = "أهلا";
    اطبع_سطر("النص موجود");
    أرجع 0;
}
```

```text
النص موجود
```

حين تنتهي `الرئيسية` يخرج `التحية` من نطاقه، وقد وضع المترجم هناك الشيفرة التي تحرر نصه. ولا شيء في شيفرتك يقول ذلك،
ولا حاجة إليه.

## النقل

القاعدة الثانية، مالك واحد في كل وقت، تحدد ما يحدث حين تسند قيمة مالكة إلى متغير آخر:

```sultan fail
استورد المكتبة.دخ.اطبع_سطر;

عرف الرئيسية(): عدد {
    ليكن ن1: نص = "مرحبا";
    ليكن ن2: نص = ن1;
    اطبع_سطر(ن1);
    أرجع 0;
}
```

```text
خطأ[SULTANC-OWNERSHIP-USE-AFTER-MOVE]: استخدام بعد النقل — القيمة المستخدمة بعد نقل ملكيتها هي ⁨`ن1`⁩. تُستخدم القيمة بعد نقل ملكيتها.
  --> main.sn:6:14..6:16
   |
 6 |     اطبع_سطر(ن1);
   |              ^^ الاستخدام غير الصالح
   |
  ::: main.sn:4:5..4:25
   |
 4 |     ليكن ن1: نص = "مرحبا";
   |     ^^^^^^^^^^^^^^^^^^^^ المالك الأصلي
   |
  ::: main.sn:5:17..5:19
   |
 5 |     ليكن ن2: نص = ن1;
   |                 ^^ نقلت القيمة هنا
   |
```

تعرض الرسالة ثلاثة مواضع: حيث كان `ن1` *المالك الأصلي*، وحيث *نُقلت القيمة* إلى `ن2`، و*الاستخدام غير الصالح* لـ `ن1`
بعد ذلك.

فلم تنسخ `ليكن ن2: نص = ن1;` النص، بل *نقلته* (move): صار `ن2` المالك، ولم يعد `ن1` يملك شيئا. ولو ملك `ن1` و `ن2` النص
نفسه لحرره كلاهما في نهاية `الرئيسية`، ولأفسد التحرير الثاني الذاكرة. فالنقل بدلا من النسخ يبقي مالكا واحدا، فيُحرَّر النص
مرة واحدة.

والنقل سريع أيضا: فلا ينتقل إلا الوصف الصغير، لا المحتوى أبدا، مهما كبر.

أما القيم البسيطة فلا تُنقل، بل تُنسخ، وتبقى النسختان صالحتين:

```sultan
استورد المكتبة.دخ.اطبع_سطر;
استورد المكتبة.نصوص.أعداد;

عرف الرئيسية(): عدد {
    ليكن أ: عدد = 5;
    ليكن ب: عدد = أ;
    اطبع_سطر(عدد_إلى_نص(أ + ب));
    أرجع 0;
}
```

```text
10
```

والمتغير الذي نُقلت قيمته يمكن أن يأخذ قيمة جديدة إن كان `متغير`، فيملك القيمة الجديدة:

```sultan
استورد المكتبة.دخ.اطبع_سطر;

عرف الرئيسية(): عدد {
    ليكن ن1: متغير نص = "الأول";
    ليكن ن2: نص = ن1;
    ن1 := "الثاني";
    اطبع_سطر(ن1);
    اطبع_سطر(ن2);
    أرجع 0;
}
```

```text
الثاني
الأول
```

## الملكية والدوال

تمرير قيمة إلى دالة يشبه إسنادها إلى معامل الدالة: فالقيمة المالكة تنتقل إلى الدالة. ولذلك لا يترجم هذا البرنامج الذي
يبدو بريئا:

```sultan fail
عرف عد(القيم: متجه عدد): عدد {
    أرجع الطول(القيم);
}

عرف الرئيسية(): عدد {
    ليكن الأعداد: متجه عدد = [1, 2, 3];
    ليكن ن: عدد = عد(الأعداد);
    أرجع الطول(الأعداد) + ن;
}
```

```text
خطأ[SULTANC-OWNERSHIP-USE-AFTER-MOVE]: استخدام بعد النقل — القيمة المستخدمة بعد نقل ملكيتها هي ⁨`الأعداد`⁩. تُستخدم القيمة بعد نقل ملكيتها.
  --> main.sn:8:16..8:23
   |
 8 |     أرجع الطول(الأعداد) + ن;
   |                ^^^^^^^ الاستخدام غير الصالح
   |
  ::: main.sn:6:5..6:38
   |
 6 |     ليكن الأعداد: متجه عدد = [1, 2, 3];
   |     ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^ المالك الأصلي
   |
  ::: main.sn:7:20..7:27
   |
 7 |     ليكن ن: عدد = عد(الأعداد);
   |                    ^^^^^^^ نقلت القيمة هنا
   |
```

صارت `عد` مالكة المتجه، وحررته حين رجعت. ويعرض القسم التالي طريقتين لتجاوز ذلك: الاستعارة، وصنع نسخة.

أما `اطبع_سطر` فلا تقع في هذا: تستطيع أن تطبع النص نفسه مرتين، لأنها تستعير نصها فقط، كما يشرح القسم التالي.

## الإرجاع ينقل القيم إلى الخارج

ترجع الدالة قيمة بنقلها إلى المستدعي. والدالة التي تبني قيمة وترجعها هي الطريقة المعتادة لإنشاء القيم المالكة:

```sultan
استورد المكتبة.دخ.اطبع_سطر;
استورد المكتبة.نصوص.تحويل;

عرف اصنع_تحية(الاسم: &نص): نص {
    ليكن التحية: نص = صل_ثلاثة_نصوص(&"أهلا يا ", الاسم, &"!");
    أرجع التحية;
}

عرف الرئيسية(): عدد {
    ليكن الرسالة: نص = اصنع_تحية(&"نور");
    اطبع_سطر(الرسالة);
    أرجع 0;
}
```

```text
أهلا يا نور!
```

يُنشأ `التحية` داخل `اصنع_تحية`، وتنقله `أرجع` إلى المستدعي، فيصير `الرسالة` مالكه. لا شيء يُنسخ، ولا شيء يُحرَّر حتى يخرج
`الرسالة` من نطاقه في نهاية `الرئيسية`.

ونقل القيمة إلى الدالة واستعادتها في كل مرة سيكون مملا. وأغلب الدوال تحتاج إلى النظر في القيمة لا إلى امتلاكها، ولذلك في
السلطان المراجع.
