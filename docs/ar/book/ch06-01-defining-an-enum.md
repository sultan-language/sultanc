# تعريف التعداد

يسرد التعداد حالاته، كلا منها بعد `|`:

```sultan ignore
نوع إشارة = | أحمر | أصفر | أخضر;
```

وتُسمّى الحالة عبر نوعها: `إشارة.أخضر`. ولصنع قيمة من حالة استدعها كدالة بقوسين فارغين:

```sultan
استورد المكتبة.دخ.اطبع_سطر;

نوع إشارة = | أحمر | أصفر | أخضر;

عرف الفعل(الإشارة: إشارة): نص {
    طابق الإشارة مع
    | إشارة.أحمر -> { أرجع "قف"; }
    | إشارة.أصفر -> { أرجع "انتظر"; }
    | إشارة.أخضر -> { أرجع "انطلق"; };
}

عرف الرئيسية(): عدد {
    ليكن الآن: إشارة = إشارة.أخضر();
    اطبع_سطر(الفعل(الآن));
    اطبع_سطر(الفعل(إشارة.أحمر()));
    أرجع 0;
}
```

```text
انطلق
قف
```

تصنع `إشارة.أخضر()` قيمة، وفي نمط `طابق` تُكتب `إشارة.أخضر` بلا أقواس. وتأخذ `الفعل` أي `إشارة` أيا كانت حالتها: فالحالات
قيم من نوع واحد.

## حالات تحمل بيانات

يجوز أن تحمل الحالة قيمة، يُصرَّح بها بـ `بنوع`. وقد تحمل كل حالة نوعا مختلفا، أو لا شيء:

```sultan ignore
نوع شكل = | دائرة بنوع عدد | مربع بنوع عدد | نقطة;
```

تحمل `دائرة` نصف قطرها، و `مربع` ضلعه، و `نقطة` لا شيء. وتُعطى القيمة حين تُصنع الحالة، `شكل.دائرة(2)`، وتُخرج في `طابق`:

```sultan
استورد المكتبة.دخ.اطبع_سطر;
استورد المكتبة.نصوص.أعداد;

نوع شكل = | دائرة بنوع عدد | مربع بنوع عدد | نقطة;

عرف المساحة(الشكل: &شكل): عدد {
    طابق *الشكل مع
    | شكل.دائرة(نصف_القطر) -> { أرجع 3 * نصف_القطر * نصف_القطر; }
    | شكل.مربع(الضلع) -> { أرجع الضلع * الضلع; }
    | شكل.نقطة -> { أرجع 0; };
}

عرف الرئيسية(): عدد {
    ليكن الأشكال: متجه شكل = [شكل.دائرة(2), شكل.مربع(5), شكل.نقطة()];
    لكل (ليكن ع: متغير عدد = 0; ع < الطول(الأشكال); ع := ع + 1) {
        اطبع_سطر(عدد_إلى_نص(المساحة(&الأشكال[ع])));
    }
    أرجع 0;
}
```

```text
12
25
0
```

يطابق النمط `شكل.دائرة(نصف_القطر)` الدائرة، ويسمي القيمة التي تحملها `نصف_القطر` ليستخدمها الفرع. فتختار `طابق` واحدة
الحالة وتُخرج بياناتها.

وتأخذ `المساحة` النوع `&شكل` وتطابق `*الشكل`، أي الشكل الذي يشير إليه المرجع.

وقارن هذا بالبديل: سجل فيه حقل `النوع` وحقول منفصلة لنصف القطر والضلع، أغلبها غير مستخدم في كل شكل. ولا شيء يمنع البرنامج
حينها من قراءة نصف قطر مربع. أما مع التعداد فنصف القطر لا يوجد إلا داخل الدائرة، والطريق الوحيد إليه هو النمط الذي تحقق
من أنها دائرة.

## الحالة تحمل قيمة واحدة

تحمل كل حالة قيمة واحدة. فإن احتاجت إلى أكثر فاجعل تلك القيمة سجلا أو صفا:

```sultan
استورد المكتبة.دخ.اطبع_سطر;
استورد المكتبة.نصوص.أعداد;

نوع مقاس = { العرض: عدد, الارتفاع: عدد };
نوع شكل = | دائرة بنوع عدد | مستطيل بنوع مقاس;

عرف المساحة(الشكل: &شكل): عدد {
    طابق *الشكل مع
    | شكل.دائرة(نصف_القطر) -> { أرجع 3 * نصف_القطر * نصف_القطر; }
    | شكل.مستطيل({ العرض: عر, الارتفاع: ار }) -> { أرجع عر * ار; };
}

عرف الرئيسية(): عدد {
    ليكن الغرفة: شكل = شكل.مستطيل({ العرض: 3, الارتفاع: 4 });
    اطبع_سطر(عدد_إلى_نص(المساحة(&الغرفة)));
    أرجع 0;
}
```

```text
12
```

يذهب النمط `شكل.مستطيل({ العرض: عر, الارتفاع: ار })` خطوة أبعد مما سبق: يفكك السجل أيضا، ويسمي حقليه `عر` و `ار`.

## التعدادات للحالات المتتابعة

التعدادات هي الطريقة الطبيعية لوصف شيء يمر بحالات. فكل حالة فرع من التعداد، ودالة تقرر الحالة التالية:

```sultan
استورد المكتبة.دخ.اطبع_سطر;

نوع طلب = | مسجل | مدفوع | مشحون | سُلّم;

عرف التالي(الطلب: طلب): طلب {
    طابق الطلب مع
    | طلب.مسجل -> { أرجع طلب.مدفوع(); }
    | طلب.مدفوع -> { أرجع طلب.مشحون(); }
    | طلب.مشحون -> { أرجع طلب.سُلّم(); }
    | طلب.سُلّم -> { أرجع طلب.سُلّم(); };
}

عرف الاسم(الطلب: &طلب): نص {
    طابق *الطلب مع
    | طلب.مسجل -> { أرجع "مسجل"; }
    | طلب.مدفوع -> { أرجع "مدفوع"; }
    | طلب.مشحون -> { أرجع "مشحون"; }
    | طلب.سُلّم -> { أرجع "سُلّم"; };
}

عرف الرئيسية(): عدد {
    ليكن الطلب: متغير طلب = طلب.مسجل();
    لكل (ليكن الخطوة: متغير عدد = 0; الخطوة < 4; الخطوة := الخطوة + 1) {
        اطبع_سطر(الاسم(&الطلب));
        الطلب := التالي(الطلب);
    }
    أرجع 0;
}
```

```text
مسجل
مدفوع
مشحون
سُلّم
```

والتعداد بسيط أو مالك بقاعدة السجل نفسها: فـ `طلب` و `إشارة` لا تحملان شيئا مالكا، فهما بسيطتان وتُنسخان. أما التعداد
الذي تحمل إحدى حالاته `نص` فمالك، ويُنقل.
