# أنواع البيانات العامة

## الدوال العامة

يُصرَّح بمعامل النوع بين قوسين زاويين بعد اسم الدالة، ثم يُستخدم كأي نوع:

```sultan
استورد المكتبة.دخ.اطبع_سطر;
استورد المكتبة.نصوص.أعداد;

عرف الأول_أو<T>(القيم: &متجه T, البديل: T): T {
    إذا (الطول(*القيم) == 0) {
        أرجع البديل;
    };
    أرجع استنسخ(&(*القيم)[0]);
}

عرف الرئيسية(): عدد {
    دع الأعداد: متجه عدد = [7, 8, 9];
    دع فارغ: متجه عدد = [];
    دع الأسماء: متجه نص = ["هدى", "زيد"];
    اطبع_سطر(عدد_إلى_نص(الأول_أو(&الأعداد, 0)));
    اطبع_سطر(عدد_إلى_نص(الأول_أو(&فارغ, -1)));
    اطبع_سطر(الأول_أو(&الأسماء, "لا أحد"));
    أرجع 0;
}
```

```text
7
-1
هدى
```

اقرأ `عرف الأول_أو<T>(القيم: &متجه T, البديل: T): T` هكذا: لأي نوع `T`، تأخذ `الأول_أو` متجها مستعارا من `T` وبديلا من
`T`، وترجع `T`.

ولا يكتب المستدعي ما هو `T`: فالمترجم يستنتجه من الوسائط. فمع `&الأعداد` يكون `T` هو `عدد`، ومع `&الأسماء` يكون `نص`.

و `استنسخ` موجودة لأن `T` قد يكون نوعا مالكا مثل `نص`، ولا تُنقل قيمة من متجه مستعار. فالشيفرة العامة يجب أن تصح لكل نوع
قد تُستخدم معه.

ويجوز أن يكون للدالة عدة معاملات أنواع بينها فواصل: `عرف بدّل<A, B>(الزوج: (A, B)): (B, A)`.

## السجلات العامة

تأخذ الأنواع معاملات أنواع أيضا. وهذا مكدس يعمل مع أي نوع عناصر:

```sultan
استورد المكتبة.دخ.اطبع_سطر;
استورد المكتبة.نصوص.أعداد;

نوع مكدس<T> = { العناصر: متجه T };

عرف أنشئ_مكدسا<T>(): مكدس<T> {
    دع فارغ: متجه T = [];
    دع المكدس: مكدس<T> = { العناصر: فارغ };
    أرجع المكدس;
}

عرف ادفع<T>(المكدس: &متغير مكدس<T>, العنصر: T): فراغ {
    ألحق((*المكدس).العناصر, العنصر);
}

عرف الحجم<T>(المكدس: &مكدس<T>): عدد {
    أرجع الطول((*المكدس).العناصر);
}

عرف القمة<T>(المكدس: &مكدس<T>): اختياري T {
    دع العدد: عدد = الحجم(المكدس);
    إذا (العدد == 0) {
        أرجع اختياري.لا_شيء();
    };
    أرجع اختياري.موجود(استنسخ(&(*المكدس).العناصر[العدد - 1]));
}

عرف الرئيسية(): عدد {
    دع الأعداد: متغير مكدس<عدد> = أنشئ_مكدسا();
    ادفع(&متغير الأعداد, 10);
    ادفع(&متغير الأعداد, 20);
    اطبع_سطر(عدد_إلى_نص(الحجم(&الأعداد)));
    طابق القمة(&الأعداد) مع
    | اختياري.موجود(القيمة) -> { اطبع_سطر(عدد_إلى_نص(القيمة)); }
    | اختياري.لا_شيء -> { اطبع_سطر("فارغ"); };
    دع الكلمات: متغير مكدس<نص> = أنشئ_مكدسا();
    ادفع(&متغير الكلمات, "الأول");
    ادفع(&متغير الكلمات, "الثاني");
    طابق القمة(&الكلمات) مع
    | اختياري.موجود(الكلمة) -> { اطبع_سطر(الكلمة); }
    | اختياري.لا_شيء -> { اطبع_سطر("فارغ"); };
    أرجع 0;
}
```

```text
2
20
الثاني
```

`مكدس<عدد>` و `مكدس<نص>` نوعان مختلفان مصنوعان من تعريف واحد. والأنواع المبنية التي استخدمتها عامة بالطريقة نفسها:
`متجه T` و `اختياري T` و `نتيجة T, E`.

## التعدادات العامة

ويأخذ التعداد معاملات أنواع أيضا. فـ `اختياري` مبنية في اللغة، لكن الشكل نفسه يمكن أن يُكتب مباشرة:

```sultan
استورد المكتبة.دخ.اطبع_سطر;
استورد المكتبة.نصوص.أعداد;

نوع ربما<T> = | عدم | قيمة بنوع T;

عرف القيمة_أو<T>(القيمة: ربما<T>, البديل: T): T {
    طابق القيمة مع
    | ربما.عدم -> { أرجع البديل; }
    | ربما.قيمة(العنصر) -> { أرجع العنصر; };
}

عرف الرئيسية(): عدد {
    دع حاضر: ربما<عدد> = ربما.قيمة(42);
    دع غائب: ربما<عدد> = ربما.عدم();
    اطبع_سطر(عدد_إلى_نص(القيمة_أو(حاضر, 0)));
    اطبع_سطر(عدد_إلى_نص(القيمة_أو(غائب, -1)));
    أرجع 0;
}
```

```text
42
-1
```

## الشيفرة العامة لا تكلّف شيئا وقت التشغيل

يفحص المترجم الشيفرة العامة حين تُستخدم مع نوع، وينتج نسخة منفصلة من الدالة لكل نوع تُستخدم معه: `الأول_أو` لـ `عدد`، وأخرى
لـ `نص`. فتعمل الشيفرة العامة بسرعة الشيفرة المكتوبة لنوع واحد تماما. والثمن قليل من الشيفرة المترجمة الإضافية، نسخة لكل نوع.

ابدأ بأنواع محددة. وحين تجد نفسك تكتب الدالة نفسها مرة ثانية لنوع آخر، فاجعلها عامة.
