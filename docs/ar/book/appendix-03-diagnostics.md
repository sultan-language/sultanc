# ج. رسائل التشخيص

لكل رسالة يكتبها المترجم هوية بالشكل `SULTANC-المجال-الاسم`، لا تتغير بين الإصدارات، وهي نفسها في اللغتين. وقد بيّن الفصل
الأول كيف تُقرأ الرسالة.

ويطبع `sultanc explain الهوية` شرح هوية واحدة، باللغة التي يختارها `--lang`:

```console
$ sultanc explain SULTANC-OWNERSHIP-USE-AFTER-MOVE
SULTANC-OWNERSHIP-USE-AFTER-MOVE

استُخدمت القيمة بعد نقل ملكيتها. راجع موضع النقل المرتبط.
```

ويكتب `--diagnostic-format=json` كل رسالة كائن JSON، للمحررات وغيرها من الأدوات، ويكتبها `--diagnostic-format=short` سطرا
واحدا. ويسرد الجدول أدناه كل هوية مع شرحها، كما يعطيه `sultanc explain`، مجمّعة بحسب جزء المترجم الذي يبلّغ عنها.
