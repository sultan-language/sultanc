# برنامج مثال بالسجلات

لترى كيف تساعد السجلات، لنكتب برنامجا يحسب مساحة مستطيل، ونحسّنه في ثلاث خطوات.

أنشئ مشروعا جديدا اسمه `rectangles`:

```console
$ supax new rectangles
$ cd rectangles
```

## النسخة الأولى: متغيران

<sub>القائمة 5-1: المساحة من عرض وارتفاع منفصلين. الملف: src/main.sn</sub>

```sultan
استورد المكتبة.دخ.اطبع_سطر;
استورد المكتبة.نصوص.أعداد;
استورد المكتبة.نصوص.تحويل;

عرف المساحة(العرض: عدد, الارتفاع: عدد): عدد {
    أرجع العرض * الارتفاع;
}

عرف الرئيسية(): عدد {
    دع العرض: عدد = 30;
    دع الارتفاع: عدد = 50;
    اطبع_سطر(صل_ثلاثة_نصوص(&"مساحة المستطيل ", &عدد_إلى_نص(المساحة(العرض, الارتفاع)), &" بكسل مربع."));
    أرجع 0;
}
```

```text
مساحة المستطيل 1500 بكسل مربع.
```

يعمل البرنامج، لكن لـ `المساحة` معاملين مترابطين ولا شيء في البرنامج يقول ذلك. هل الأول العرض أم الارتفاع؟ يجب أن يصيب كل
استدعاء الترتيب، ولا يستطيع المترجم المساعدة، لأن كليهما `عدد`.

## النسخة الثانية: صف

<sub>القائمة 5-2: العرض والارتفاع في صف واحد. الملف: src/main.sn</sub>

```sultan
استورد المكتبة.دخ.اطبع_سطر;
استورد المكتبة.نصوص.أعداد;
استورد المكتبة.نصوص.تحويل;

عرف المساحة(الأبعاد: (عدد, عدد)): عدد {
    طابق الأبعاد مع
    | (العرض, الارتفاع) -> { أرجع العرض * الارتفاع; };
}

عرف الرئيسية(): عدد {
    دع المستطيل: (عدد, عدد) = (30, 50);
    اطبع_سطر(صل_ثلاثة_نصوص(&"مساحة المستطيل ", &عدد_إلى_نص(المساحة(المستطيل)), &" بكسل مربع."));
    أرجع 0;
}
```

```text
مساحة المستطيل 1500 بكسل مربع.
```

أفضل من جهة: فالعددان يسيران معا قيمةً واحدة. وأسوأ من جهة أخرى: فالأجزاء بلا أسماء. فعلى البرنامج أن يتذكر أن الأول هو
العرض، ومن يقرأ `(30, 50)` عليه أن يخمّن.

## النسخة الثالثة: سجل

<sub>القائمة 5-3: سجل `مستطيل`. الملف: src/main.sn</sub>

```sultan
استورد المكتبة.دخ.اطبع_سطر;
استورد المكتبة.نصوص.أعداد;
استورد المكتبة.نصوص.تحويل;

نوع مستطيل = { العرض: عدد, الارتفاع: عدد };

عرف المساحة(المستطيل_المعار: &مستطيل): عدد {
    أرجع المستطيل_المعار.العرض * المستطيل_المعار.الارتفاع;
}

عرف الرئيسية(): عدد {
    دع المستطيل: مستطيل = { العرض: 30, الارتفاع: 50 };
    اطبع_سطر(صل_ثلاثة_نصوص(&"مساحة المستطيل ", &عدد_إلى_نص(المساحة(&المستطيل)), &" بكسل مربع."));
    أرجع 0;
}
```

```text
مساحة المستطيل 1500 بكسل مربع.
```

صار النوع يقول ما هي القيمة، ولكل جزء اسم، وتقول `المساحة` في توقيعها إنها تحسب مساحة `مستطيل`. ولا يستطيع أحد أن يمرر
العرض والارتفاع بالترتيب الخاطئ، لأن أحدا لا يمررهما منفصلين.

وتأخذ `المساحة` النوع `&مستطيل`: فهي تقرأ المستطيل فقط، فتستعيره، وتحتفظ به `الرئيسية`. وفي داخلها تصل
`المستطيل_المعار.العرض` إلى الحقل عبر المرجع، ويشرح القسم التالي كيف.

وتصل `صل_ثلاثة_نصوص` من `المكتبة.نصوص.تحويل` ثلاثة نصوص، كما تصل `صل_نصين` نصين.

## طباعة مستطيل

لا يمكن تمرير `مستطيل` إلى `اطبع_سطر`، فهي لا تطبع إلا النصوص. ولعرضه اكتب دالة تبني نصه:

<sub>القائمة 5-4: دالة تصف `مستطيل`. الملف: src/main.sn</sub>

```sultan
استورد المكتبة.دخ.اطبع_سطر;
استورد المكتبة.نصوص.أعداد;
استورد المكتبة.نصوص.تحويل;

نوع مستطيل = { العرض: عدد, الارتفاع: عدد };

عرف صف(المستطيل_المعار: &مستطيل): نص {
    دع النص: نص = صل_ثلاثة_نصوص(&عدد_إلى_نص(المستطيل_المعار.العرض), &" × ", &عدد_إلى_نص(المستطيل_المعار.الارتفاع));
    أرجع النص;
}

عرف الرئيسية(): عدد {
    دع المستطيل: مستطيل = { العرض: 30, الارتفاع: 50 };
    اطبع_سطر(صف(&المستطيل));
    أرجع 0;
}
```

```text
30 × 50
```

والدوال مثل `صف` و `المساحة`، التي تأخذ سجلا وتعمل بحقوله، موضوع القسم التالي.
