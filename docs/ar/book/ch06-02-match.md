# جملة `طابق`

تقارن `طابق` قيمة بقائمة أنماط، وتنفّذ فرع أول نمط يطابقها. وقد رأيتها مع الأعداد والنصوص والنتائج والتعدادات، ويجمع هذا
القسم ما تستطيعه الأنماط.

## ما يكون النمط

| النمط | يطابق |
| --- | --- |
| `5` و `'a'` و `"نعم"` | تلك القيمة بالضبط |
| `مدى 1..9`، `مدى 'أ'..'ي'` | أي قيمة من 1 إلى 9 (من `'أ'` إلى `'ي'`)، والطرفان داخلان |
| `مدى 100..`، `مدى ..0` | أي قيمة من 100 فما فوقها، وأي قيمة حتى 0 |
| `الاسم` | أي شيء، ويسميه للفرع |
| `_` | أي شيء، دون تسمية |
| `أ \| ب` | أي شيء يطابقه أحد النمطين `أ` و`ب`؛ ويربط كلاهما الأسماء نفسها |
| `شكل.دائرة(نصف_القطر)` | تلك الحالة من التعداد، ويسمي ما تحمله |
| `موجود(س)` و`لا_شيء` و`نجح(س)` و`خطأ(خ)` | حالات `اختياري` و`نتيجة`، مكتوبة دون نوعها |
| `(س, 0)` | صفّا، جزءا جزءا |
| `(أ \| ب)` | النمط الذي داخلها: الأقواس تجمع |
| `{ العرض: عر, الارتفاع: ار }` | سجلا، حقلا حقلا؛ والحقول المتروكة تطابق أي شيء |
| `{ العرض }` | سجلا: `العرض` يربط الحقل الذي بهذا الاسم؛ والحقول الأخرى تطابق أي شيء |
| `[]` و `[أ، ب]` | متجها أو شريحة فيها هذا العدد من العناصر بالضبط |
| `[الأول، بقية _]` و `[بقية _، الأخير]` و `[الأول، بقية الذيل]` | متجها أو شريحة فيها هذا العدد من العناصر على الأقل؛ و`بقية` تنوب عن غيرها |
| `نمط مثل اسم` | ما يطابقه `نمط`، ويسمي القيمة كلها |

وبعد النمط قد يكون للذراع حارس: `| نمط إذا شرط -> { … }`.

والأنماط تتداخل: فكل ما داخل حالة أو صف أو سجل نمط هو أيضا. وهذه `طابق` تنظر في صف من عدد و `اختياري`، وداخل `اختياري` في
مدى:

```sultan
استورد المكتبة.دخ.اطبع_سطر;

عرف صف(الزوج: (عدد, اختياري عدد)): نص {
    طابق الزوج مع
    | (0, لا_شيء) -> { أرجع "صفر ولا شيء"; }
    | (_, موجود(مدى 1..9)) -> { أرجع "عدد صغير"; }
    | (_, موجود(_)) -> { أرجع "عدد آخر"; }
    | (_, لا_شيء) -> { أرجع "لا شيء"; };
}

عرف الرئيسية(): عدد {
    ليكن أ: (عدد, اختياري عدد) = (0, لا_شيء);
    ليكن ب: (عدد, اختياري عدد) = (3, موجود(4));
    ليكن ج: (عدد, اختياري عدد) = (3, موجود(40));
    اطبع_سطر(صف(أ));
    اطبع_سطر(صف(ب));
    اطبع_سطر(صف(ج));
    أرجع 0;
}
```

```text
صفر ولا شيء
عدد صغير
عدد آخر
```

تُجرَّب الفروع بالترتيب. والصف `(3, موجود(4))` يطابق النمطين الثاني والثالث، والثاني أولا فيفوز. فضع الأنماط
المحددة قبل العامة.

## `موجود` و`لا_شيء` و`نجح` و`خطأ`

تُكتب حالات `اختياري` و`نتيجة` دون نوعها، في القيم وفي الأنماط: `موجود(س)` و`لا_شيء` و`نجح(س)` و`خطأ(خ)` (وبالإنجليزية
`some(x)` و`none` و`ok(x)` و`err(e)`). والنوع المنتظر هناك (معامل، أو متغير مصرح بنوعه، أو نوع ناتج الدالة، أو القيمة المطابَقة)
يبين أي `اختياري` أو `نتيجة` هي. و`لا_شيء` لا تحتاج `()`؛ و`لا_شيء()` والصيغ المؤهلة (`اختياري.موجود(س)`، `نتيجة.خطأ(خ)`)
تعمل كما كانت. أما حالات التعدادات الأخرى فتبقى بنوعها: `شكل.دائرة(ن)`.

وحيث لا يُنتظر نوع، كالقيمة التي تنظر فيها `طابق`، تقول `موجود(س)` نوعها بنفسها: فهي `اختياري` نوع `س`، فتعمل
`طابق موجود(5) مع | موجود(ن) -> … | لا_شيء -> …`. أما `لا_شيء` و`نجح(س)` و`خطأ(خ)` فلا تقول النوع كله (أي قيمة تنقص
`لا_شيء`، وأي خطأ كان يمكن أن يكون مع `نجح`)، فهي هناك خطأ (`SULTANC-TYPE-PRELUDE-CONSTRUCTOR-UNTYPED`): أعط القيمة نوعا
أولا، كما في `ليكن الموجود: اختياري عدد = لا_شيء;`.

والتصريح بأحد هذه الأسماء يحجبه في التعابير: فبعد `ليكن لا_شيء: عدد = 0;` تكون `لا_شيء` ذلك المتغير، والدالة المسماة `موجود`
تُستدعى كما كُتبت. وفي النمط تكون الصيغ المجردة دائما حالات `اختياري` و`نتيجة`، لا أسماء جديدة. و`خطأ` وحدها هي القيمة
المنطقية؛ و`خطأ(خ)` حالة الخطأ.

## البدائل

يطابق `أ | ب` ما يطابقه أحد البديلين. والبدائل أنماط من أي صنف، في رأس الذراع أو داخل نمط آخر:

```sultan
استورد المكتبة.دخ.اطبع_سطر;
استورد المكتبة.نصوص.أعداد;

نوع شكل = | دائرة بنوع عدد | مربع بنوع عدد | نقطة;

عرف الحجم(الشكل: شكل): عدد {
    طابق الشكل مع
    | شكل.دائرة(0) | شكل.نقطة -> { أرجع 0; }
    | شكل.دائرة(ن) | شكل.مربع(ن) -> { أرجع ن; };
}

عرف على_محور(النقطة: (عدد, عدد)): عدد {
    طابق النقطة مع
    | (0, ق) | (ق, 0) -> { أرجع ق; }
    | _ -> { أرجع -1; };
}

عرف الرئيسية(): عدد {
    اطبع_سطر(عدد_إلى_نص(الحجم(شكل.نقطة())));
    اطبع_سطر(عدد_إلى_نص(الحجم(شكل.مربع(4))));
    اطبع_سطر(عدد_إلى_نص(على_محور((0, 7))));
    أرجع 0;
}
```

```text
0
4
7
```

وأيا كان البديل المطابق يرى الفرع الأسماء نفسها، فيجب أن يربط كل بديل الأسماء نفسها، لكل منها النوع نفسه. فـ
`| (0, س) | (ص, 0)` هو `SULTANC-PATTERN-ALTERNATIVE-BINDINGS` (`س` غير مربوط في كل بديل)، و
`| قيمة.رقم(س) | قيمة.كلمة(س)` مع حمولة `عدد` وحمولة `نص` هو `SULTANC-PATTERN-ALTERNATIVE-TYPES`. والبديل الذي تغطيه
الأذرع التي قبله والبدائل التي قبله لا يطابق أبدا؛ ويُبلَّغ عنه بتحذير كالذراع التي لا تُنفذ (`SULTANC-PATTERN-UNREACHABLE`).
والنمط البديل المتداخل داخل نمط يُفحص على بدائله السابقة: ففي `| (1 | 2 | 1, ص)` يُبلَّغ عن `1` الثانية. ولا يُفحص هل تغطي
الأذرع السابقة بديلا متداخلا (فبعد `| موجود(1)` لا يُبلَّغ عن `1` في `| موجود(1 | 2)`).

## الحراس

قد يضيف الذراع شرطا بعد نمطه: `| نمط إذا شرط -> { … }`. ولا يُختار الذراع إلا إذا طابق النمط وصح الشرط؛ وإلا تابعت
المطابقة بالذراع التالي. ويرى الشرط أسماء النمط، وينطبق الحارس على كل بدائل نمط الذراع:

```sultan
استورد المكتبة.دخ.اطبع_سطر;

عرف صنف(القيمة: عدد): نص {
    طابق القيمة مع
    | س إذا س > 100 -> { أرجع "كبير"; }
    | س إذا س > 5 -> { أرجع "متوسط"; }
    | 0 -> { أرجع "صفر"; }
    | _ -> { أرجع "صغير"; };
}

عرف الرئيسية(): عدد {
    اطبع_سطر(صنف(500));
    اطبع_سطر(صنف(9));
    اطبع_سطر(صنف(2));
    أرجع 0;
}
```

```text
كبير
متوسط
صغير
```

لا يستطيع المترجم أن يعرف متى يصح الشرط، فلا يُحتسب الذراع المحروس في الشمول: يجب أن تغطي الأذرع التي بعده كل قيمة.
وهنا يغطيها الذراعان الأخيران.

وما دام الحارس يجري فأسماء النمط مستعارة: يقرؤها الحارس ولا يستطيع نقلها (نقل أحدها هو
`SULTANC-OWNERSHIP-MOVE-OUT-OF-REFERENCE`). ولم يخرج شيء من القيمة المطابَقة بعد، فإذا كان الحارس خطأ رأى الذراع التالي
القيمة كلها؛ ولا تنتقل الأجزاء المملوكة إلى الأسماء إلا حين يُختار الذراع.

ولا يستطيع الحارس أن يرجع مبكرا: فلا يُقبل `؟` إلا في آخر الطرف الأيمن من عبارة، فـ `| ق إذا افحص(ق)؟ ->` هو
`SULTANC-PARSE-SYNTAX` عند `؟`. احسب القيمة في عبارة أولا، أو طابق عليها.

## تسمية القيمة كلها: `مثل`

يطابق `نمط مثل اسم` ما يطابقه `نمط` ويسمي القيمة كلها أيضا. و`مثل` أضعف ارتباطا، فـ `يد.حجر | يد.ورق مثل ي` يسمي
القيمة أيا كان البديل المطابق؛ والأقواس تجمع النمط، `(شكل.دائرة(_) مثل د, ن)`:

```sultan
استورد المكتبة.دخ.اطبع_سطر;
استورد المكتبة.نصوص.أعداد;

نوع شكل = | دائرة بنوع عدد | مربع بنوع عدد;

عرف المساحة(الشكل: شكل): عدد {
    طابق الشكل مع
    | شكل.دائرة(نق) -> { أرجع 3 * نق * نق; }
    | شكل.مربع(ن) -> { أرجع ن * ن; };
}

عرف صف(الشكل: شكل): عدد {
    طابق الشكل مع
    | شكل.دائرة(نق) مثل الدائرة -> { أرجع نق + المساحة(الدائرة); }
    | شكل.مربع(_) مثل المربع -> { أرجع المساحة(المربع); };
}

عرف الرئيسية(): عدد {
    اطبع_سطر(عدد_إلى_نص(صف(شكل.دائرة(2))));
    أرجع 0;
}
```

```text
14
```

وحين تملك القيمة ذاكرة، يملكها كلَّها الاسمُ الذي يسميها كلها. فإن ربط النمط الذي داخله أيضا جزءا يملك ذاكرة
(`| مسمى.اثنان(أ, _) مثل الكل`)، ملك الاسمان التخزين نفسه. فيستعير هذا الذراع القيمة المطابَقة بدلا من ذلك: كل اسم فيه
يملك نوعه ذاكرة عرض مستعار، ولا يخرج شيء من القيمة، فيحتفظ بها مالكها. ويستطيع الذراع قراءة الأسماء؛ ونقل أحدها هو
`SULTANC-OWNERSHIP-MOVE-OUT-OF-REFERENCE`. وتُنسخ الأجزاء العادية (الأعداد والمحارف والقيم المنطقية) دائما.

## السجلات: الحقول التي تحتاجها وحدها

يسمي نمط السجل الحقول التي ينظر فيها؛ والحقول التي يتركها تطابق أي شيء. والحقل المكتوب وحده يربط اسما يُكتب مثل الحقل:
`{ العرض، الارتفاع }` هو `{ العرض: العرض، الارتفاع: الارتفاع }`، وتختلط الصيغتان، `{ العرض، الارتفاع: 0 }`:

```sultan
استورد المكتبة.دخ.اطبع_سطر;
استورد المكتبة.نصوص.أعداد;

نوع مقاس = { العرض: عدد، الارتفاع: عدد، العمق: عدد };

عرف المساحة(المقاس: مقاس): عدد {
    طابق المقاس مع
    | { العرض، الارتفاع: 0 } -> { أرجع العرض; }
    | { العرض، الارتفاع } -> { أرجع العرض * الارتفاع; };
}

عرف الرئيسية(): عدد {
    ليكن العلبة: مقاس = { العرض: 3، الارتفاع: 4، العمق: 5 };
    اطبع_سطر(عدد_إلى_نص(المساحة(العلبة)));
    أرجع 0;
}
```

```text
12
```

## المتجهات والشرائح

يطابق النمط الذي بين قوسين مربعين متجها أو شريحة بطوله وعناصره. فـ `[]` يطابق الفارغ، و`[أ، ب]` عنصرين بالضبط. وداخل
القوسين تنوب الكلمة `بقية` متبوعةً باسم أو `_` عن العناصر التي بين المكتوبة، مرة واحدة على الأكثر:

| النمط | يطابق |
| --- | --- |
| `[الأول، بقية _]` | عنصرا أو أكثر؛ ويسمي الأول |
| `[بقية _، الأخير]` | عنصرا أو أكثر؛ ويسمي الأخير |
| `[الأول، بقية _، الأخير]` | عنصرين أو أكثر؛ ويسمي الطرفين |
| `[الأول، بقية الذيل]` | عنصرا أو أكثر؛ و`الذيل` شريحة الباقي |
| `[أ، بقية الوسط، ب]` | عنصرين أو أكثر؛ و`الوسط` شريحة ما بين الطرفين |
| `[أ، ب، بقية _]` | عنصرين أو أكثر |

والبقية المسماة هي الشريحة التي يعطيها تعبير التقطيع للعناصر نفسها: ففي `[الأول، بقية الذيل]` يكون `الذيل` هو `م[1..]`
([8.1](ch08-01-vectors.md)). و`بقية` كلمة في هذا الموضع وحده: فـ `[بقية]` و`[بقية، س]` يربطان اسما `بقية`، ويجوز أن يُسمى متغير `بقية`. و`بقية` ثانية في
النمط نفسه هي `SULTANC-PARSE-PATTERN`.

```sultan
استورد المكتبة.دخ.اطبع_سطر;
استورد المكتبة.نصوص.أعداد;

عرف مجموع(القيم: [] عدد): عدد {
    طابق القيم مع
    | [] -> { أرجع 0; }
    | [الأول، بقية الذيل] -> { أرجع الأول + مجموع(الذيل); };
}

عرف متناظر(النص: [] ط8): منطقي {
    طابق النص مع
    | [أ، بقية الوسط، ب] -> { أرجع أ == ب && متناظر(الوسط); }
    | _ -> { أرجع صواب; };
}

عرف الرئيسية(): عدد {
    ليكن الأعداد: متجه عدد = [1، 2، 3];
    اطبع_سطر(عدد_إلى_نص(مجموع(الأعداد)));
    أرجع 0;
}
```

```text
6
```

والبقية المسماة شريحة `[] T` من عناصر القيمة المطابَقة نفسها: لا يُنسخ شيء أيا كانت العناصر (نصوصا أو سجلات أو متجهات)،
وهي على الشريحة شريحة أضيق من الذاكرة نفسها. ويختبر كل ذراع الطول مرة واحدة ويقرأ العناصر التي يسميها في مواضع ثابتة
(فـ `[بقية _، الأخير]` يقرأ العنصر `الطول - 1`)، دون حلقة ودون فحص للحدود.

ويَعُدّ الشمولُ الأطوالَ: فـ `[]` و`[_، بقية _]` معا يغطيان كل متجه، والذراع `[أ]` بعد `[_، بقية _]` لا يُنفذ أبدا. والمطابقة
التي يفوتها طول تسمي أقصره في تشخيصها، مثل `[_، _، بقية _]` لـ"عنصرين فأكثر" (`SULTANC-PATTERN-NON-EXHAUSTIVE`).

والعناصر المربوطة من متجه عروض مستعارة منه حين تملك ذاكرة: فالمتجه يملك عناصره جملة، فالذراع الذي يربط عناصر مالكة
يستعير المتجه، كما يفعل الذراع ذو `مثل` أعلاه. والبقية المسماة تستعير المتجه المطابَق كما تفعل الشريحة التي تُعطى متجها:
فلا يُنقل المتجه ولا يُغيَّر ما دامت البقية مستعملة، ولا تُقرأ شريحة أخذت قيمة البقية بعد إتلاف المتجه
(`SULTANC-BORROW-REFERENCE-ESCAPE`). وحين تكون القيمة المطابَقة مؤقتة (ناتج نداء) يحتفظ بها الذراع حتى ينتهي، فتصح البقية
في الذراع كله.

والبقية المسماة عرض للقراءة فقط. وللكتابة عبرها طابِق المتجه بـ`&متغير` كما في كل تغيير عبر استعارة: فتحت
`طابق &متغير م مع` تكون البقية المسماة عرضا قابلا للكتابة لعناصر م من النوع `متغير [] T`، وتبقى العناصر المربوطة بأسمائها
قيما للقراءة فقط (والإسناد إلى أحدها `SULTANC-MUTABILITY-WRITE-TO-IMMUTABLE`). وتستعير البقية م حصرا ما دامت مستعملة.

```sultan
عرف املأ_الذيل(م: &متغير متجه عدد): عدد {
    طابق &متغير *م مع
    | [الأول، بقية الذيل] -> {
        ليكن ف: متغير عدد = 0;
        طالما (ف < الطول(الذيل)) { الذيل[ف] := الأول; ف := ف + 1; }
        أرجع الطول(الذيل);
    }
    | [] -> { أرجع 0; };
}

عرف الرئيسية(): عدد {
    ليكن ع: متغير متجه عدد = [9، 8، 7];
    إذا (املأ_الذيل(&متغير ع) != 2 || ع[2] != 9) { أرجع 1; };
    أرجع 0;
}
```

## كل حالة يجب أن تُعالَج

يجب أن يكون في `طابق` فرع لكل قيمة ممكنة، وفي التعداد يعني ذلك كل حالة:

```sultan fail
نوع ضوء = | أحمر | أصفر | أخضر;

عرف الرمز(الضوء: ضوء): عدد {
    طابق الضوء مع
    | ضوء.أحمر -> { أرجع 1; }
    | ضوء.أخضر -> { أرجع 3; };
}

عرف الرئيسية(): عدد {
    أرجع الرمز(ضوء.أصفر());
}
```

```text
خطأ[SULTANC-PATTERN-NON-EXHAUSTIVE]: نمط غير شامل: لا تغطي الأذرع ⁨`ضوء.أصفر`⁩ — يجب أن تطابق كل قيمة من النوع المطابَق إحدى الأذرع.
  --> main.sn:4:10..4:15
   |
 4 |     طابق الضوء مع
   |          ^^^^^
   |
  = مساعدة: أضف ذراعًا لكل حالة غير مغطاة
```

ليس لـ `ضوء.أصفر` فرع، والرسالة تقول ذلك.

والمطابقة التي تفوت أذرعها حالةً هي `SULTANC-PATTERN-NON-EXHAUSTIVE`، وتُعلَّم عند القيمة المطابَقة.
ويسمّي عنوانها الحالات التي لا تغطيها الأذرع، حتى ثلاث، ثم عدد ما بقي (`` نمط غير شامل: لا تغطي الأذرع `شكل.نقطة_فقط` ``)؛
وتُكتب حالات الاختياري والنتيجة والمنطقي بلغة المخرجات، ويقوم `_` مقام قيمة من نوع لا مجموعة مغلقة لحالاته (عدد أو نص). ويضيف
الإصلاح ذراعًا `| شكل.نقطة_فقط -> { }` لكل حالة ناقصة بعد الذراع الأخيرة، بلغة المصدر.

وهذا الفحص هو ما يجعل تغيير التعدادات آمنا. فحين تضيف حالة إلى تعداد، تتوقف عن الترجمة كل `طابق` عليه لا تعالج الحالة
الجديدة، وكل منها موضع في برنامجك يحتاج إلى قرار بشأن الحالة الجديدة.

ويستطيع `_` أن يلتقط كل الحالات الباقية في فرع واحد. استخدمه حين تكون الحالات الباقية كلها سواء عندك حقا. وإن لم تكن،
فاسردها: فـ `_` سيلتقط أيضا حالة تُضاف لاحقا، بصمت، دون أن يشير إليها المترجم.

## المطابقة عبر مرجع

لتطابق القيمة التي يشير إليها مرجع، طابق `*المرجع`. وهذه الطريقة المعتادة للنظر في قيمة مستعارة:

```sultan
استورد المكتبة.دخ.اطبع_سطر;
استورد المكتبة.نصوص.أعداد;
استورد المكتبة.نصوص.تحويل;

نوع شكل = | دائرة بنوع عدد | مربع بنوع عدد;

عرف صف(الشكل: &شكل): نص {
    طابق *الشكل مع
    | شكل.دائرة(نق) -> { أرجع صل_نصين(&"دائرة نصف قطرها ", &عدد_إلى_نص(نق)); }
    | شكل.مربع(ض) -> { أرجع صل_نصين(&"مربع ضلعه ", &عدد_إلى_نص(ض)); };
}

عرف الرئيسية(): عدد {
    ليكن ض: شكل = شكل.دائرة(3);
    اطبع_سطر(صف(&ض));
    أرجع 0;
}
```

```text
دائرة نصف قطرها 3
```

## الفرع كتلة

ينفّذ كل فرع من فروع جملة `طابق` كتلة من الجمل. وحين لا يكون للفرع ما يفعله تكون كتلته فارغة، `{ }`.

## مطابقة تعطي قيمة

و`إذا (ش) أ وإلا ب` المستعملة قيمةً ([3.5](ch03-05-control-flow.md)) مطابقة من هذا النوع على الشرط.

ويمكن أن تقف `طابق` حيث تُنتظر قيمة: بعد `=` في `ليكن`، وبعد `:=`، وبعد `أرجع`، وحجةً، وطرفا لعامل، وفي شرط، وفي جسم
إغلاق. وقيمتها قيمة الفرع الذي يطابق، ويكون الفرع عندئذ `| نمط -> قيمة`:

```sultan
استورد المكتبة.دخ.اطبع_سطر;
استورد المكتبة.نصوص.أعداد;

نوع ضوء = | أحمر | أصفر | أخضر;

عرف وصف(الضوء: ضوء): نص {
    أرجع طابق الضوء مع
    | ضوء.أحمر -> "قف"
    | ضوء.أصفر -> "انتظر"
    | ضوء.أخضر -> "سر";
}

عرف الرئيسية(): عدد {
    اطبع_سطر(وصف(ضوء.أصفر()));
    ليكن الثواني: عدد = 10 * طابق ضوء.أحمر() مع | ضوء.أخضر -> 0 | _ -> 3;
    اطبع_سطر(عدد_إلى_نص(الثواني));
    أرجع 0;
}
```

```text
انتظر
30
```

والفرع الذي يحتاج جملا يكتبها أولا بين معقوفين، والتعبير الذي في آخرهما، بلا `؛` بعده، هو قيمة الفرع:

```sultan
استورد المكتبة.دخ.اطبع_سطر;
استورد المكتبة.نصوص.أعداد;

عرف علامة(الكلمة: نص): عدد {
    أرجع طابق الطول(الكلمة) مع
    | 0 -> 0
    | ن -> {
        ليكن الحجم: عدد = ن مثل عدد;
        الحجم * الحجم
    };
}

عرف الرئيسية(): عدد {
    اطبع_سطر(عدد_إلى_نص(علامة("four")));
    أرجع 0;
}
```

```text
16
```

والفرع الذي لا يكتمل لا يحتاج قيمة: فكتلته ترجع، أو تخرج من حلقة أو تتابعها، أو تنهار.

```sultan
استورد المكتبة.دخ.اطبع_سطر;
استورد المكتبة.نصوص.أعداد;

عرف ضعف_أو_صفر(القيمة: اختياري عدد): عدد {
    ليكن الموجود: عدد = طابق القيمة مع
    | موجود(ق) -> ق
    | لا_شيء -> { أرجع 0; };
    أرجع الموجود * 2;
}

عرف الرئيسية(): عدد {
    اطبع_سطر(عدد_إلى_نص(ضعف_أو_صفر(موجود(21))));
    اطبع_سطر(عدد_إلى_نص(ضعف_أو_صفر(لا_شيء)));
    أرجع 0;
}
```

```text
42
0
```

وقواعد `طابق` التي تعطي قيمة:

- تعطي الفروع كلها قيمة من نوع واحد. فإن انتظر موضعُ `طابق` نوعا (نوع `ليكن`، أو نوع المعامل، أو نوع ناتج الدالة) فهو
  النوع، وتأخذه منه `لا_شيء` والأعداد الحرفية وحرفيات السجلات والمتجهات في الفروع كما تأخذه هناك. وإلا قرر
  النوعَ أولُ فرع يعطي قيمة، والفرع اللاحق من نوع آخر هو `SULTANC-TYPE-MISMATCH` عند ذلك الفرع.
- يعطي فرع واحد على الأقل قيمة (`SULTANC-TYPE-MATCH-WITHOUT-VALUE`). والفرع الذي لا قيمة له ويمكن أن يبلغ نهايته هو
  `SULTANC-FLOW-MATCH-ARM-WITHOUT-VALUE`، ويُعلَّم عند الفرع.
- تُعالَج كل حالة كما في الجملة (`SULTANC-PATTERN-NON-EXHAUSTIVE`).
- نمط الفرع أي نمط تقبله الجملة، ومعه حارس أيضا: `| شكل.دائرة(نق) إذا نق > 10 -> 3`. ويستعير الحارس أسماء النمط كما
  في الجملة.
- تنتقل قيمة الفرع إلى قيمة `طابق`. والجزء من القيمة المطابَقة الذي يسميه النمط ينتقل منها كما في الجملة، والقيمة التي
  تنتقل في فرع واحد فقط تبقى مع مالكها على المسارات الأخرى.
- تعمل `طابق` حيث يضعها المصدر: ما قبلها في التعبير يعمل أولا، وما بعدها يعمل بعد الفرع.
- تنتهي قيمة الفرع عند `|` التالية: فاكتب `(أ | ب)` لـ«أو» البتية، وضع الإغلاق أو `طابق` أخرى بين قوسين ما لم تكن في الفرع
  الأخير.
- لا يُستعمل `؟` داخل الفروع. و`؟` بعد الفرع الأخير يعم قيمة `طابق` كلها.
- الجملة التي تبدأ بـ `طابق` هي جملة `طابق` وفروعها كتل. و`إذا … وإلا` جملة فقط.
