# التحكم في تشغيل الاختبارات

## كل اختبار يعمل وحده

يشغّل `sultanc test` كل اختبار في عملية (process) خاصة به. فالاختبار الذي ينهار، أو يدور إلى الأبد، أو ينهي البرنامج مبكرا لا
يؤثر في غيره، وترتيب تشغيل الاختبارات لا يغيّر نتائجها.

## تشغيل بعض الاختبارات

حين تعمل على جزء من البرنامج قد تريد تشغيل اختباراته فقط. فيشغّل `--filter=نص` الاختبارات التي تحوي أسماؤها `نص` فقط، ويعدّ
التقرير الباقي *مستبعدا*:

```console
$ sultanc test calc.sn --filter=الصفر
```

```text
نجح جمع_الصفر_لا_يغير_شيئا

نتيجة الاختبارات: ناجحة. نجح: 1؛ فشل: 0؛ استُبعد: 1
```

ويطبع `--list` أسماء الاختبارات دون تشغيلها:

```console
$ sultanc test --list calc.sn
الجمع_يعمل
جمع_الصفر_لا_يغير_شيئا
```

## الاختبارات في حزمة

في الحزمة يشغّل `supax test` كل اختباراتها: اختبارات المكتبة، وكل برنامج، وكل ملف في المجلد `tests`. ويقبل الاختيارات نفسها:

| الأمر | يشغّل |
| --- | --- |
| `supax test` | كل اختبارات الحزمة |
| `supax test نص` | الاختبارات التي تحوي أسماؤها `نص` |
| `supax test --lib` | اختبارات المكتبة فقط |
| `supax test --bin الاسم` | اختبارات البرنامج `الاسم` فقط |
| `supax test --test الاسم` | الاختبارات في `tests/الاسم.sn` فقط |
| `supax test --list` | يسرد الاختبارات دون تشغيلها |
| `supax test --no-fail-fast` | يكمل بعد ملف فشلت اختباراته |

ويعرض القسم التالي حزمة فيها اختبارات في كل هذه الأماكن.
