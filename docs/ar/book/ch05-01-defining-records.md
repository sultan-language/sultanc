# تعريف السجلات

تصرّح `نوع` بنوع جديد. ويسرد نوع السجل *حقوله* (fields) بين معقوفين، لكل منها اسم ونوع:

```sultan ignore
نوع مستخدم = {
    الاسم: نص,
    البريد: نص,
    عدد_الدخول: عدد,
    نشط: منطقي
};
```

وقيمة السجل تُكتب بالطريقة نفسها، مع قيمة لكل حقل. ويُقرأ الحقل بنقطة:

```sultan
استورد المكتبة.دخ.اطبع_سطر;
استورد المكتبة.نصوص.أعداد;

نوع مستخدم = {
    الاسم: نص,
    البريد: نص,
    عدد_الدخول: عدد,
    نشط: منطقي
};

عرف الرئيسية(): عدد {
    دع المستخدم: مستخدم = {
        الاسم: "ليلى",
        البريد: "layla@example.com",
        عدد_الدخول: 1,
        نشط: صواب
    };
    اطبع_سطر(المستخدم.البريد);
    اطبع_سطر(عدد_إلى_نص(المستخدم.عدد_الدخول));
    أرجع 0;
}
```

```text
layla@example.com
1
```

يجوز إعطاء حقول القيمة بأي ترتيب، فالأسماء تحدد مكان كل قيمة. لكن كل حقل يجب أن يُعطى، فلا يكون السجل نصف ممتلئ أبدا:

```sultan fail
نوع نقطة = { س: عدد, ص: عدد };

عرف الرئيسية(): عدد {
    دع ن: نقطة = { س: 1 };
    أرجع ن.س;
}
```

```text
خطأ[SULTANC-TYPE-MISSING-RECORD-FIELD]: حقل سجل مطلوب مفقود — حقل السجل المفقود هو ⁨`ص`⁩.
  --> main.sn:4:5..4:27
   |
 4 |     دع ن: نقطة = { س: 1 };
   |     ^^^^^^^^^^^^^^^^^^^^^^
   |
```

## تغيير حقل

إن كان المتغير `متغير` جاز تغيير حقوله بـ `:=`. والسجل كله إما قابل للتغيير أو لا، فلا توجد حقول قابلة للتغيير وحدها:

```sultan
استورد المكتبة.دخ.اطبع_سطر;
استورد المكتبة.نصوص.أعداد;

نوع عداد = { التسمية: نص, العدد: عدد };

عرف الرئيسية(): عدد {
    دع الزيارات: متغير عداد = { التسمية: "الزيارات", العدد: 0 };
    الزيارات.العدد := الزيارات.العدد + 1;
    الزيارات.العدد := الزيارات.العدد + 1;
    اطبع_سطر(الزيارات.التسمية);
    اطبع_سطر(عدد_إلى_نص(الزيارات.العدد));
    أرجع 0;
}
```

```text
الزيارات
2
```

## سجلات داخل سجلات

يجوز أن يكون الحقل من أي نوع: عدد، أو نص، أو متجه، أو سجل آخر:

```sultan
استورد المكتبة.دخ.اطبع_سطر;
استورد المكتبة.نصوص.أعداد;

نوع نقطة = { س: عدد, ص: عدد };
نوع خط = { البداية: نقطة, النهاية: نقطة, التسميات: متجه نص };

عرف الرئيسية(): عدد {
    دع الخط: خط = {
        البداية: { س: 0, ص: 0 },
        النهاية: { س: 6, ص: 8 },
        التسميات: ["شمال", "شرق"]
    };
    اطبع_سطر(عدد_إلى_نص(الخط.النهاية.س - الخط.البداية.س));
    اطبع_سطر(الخط.التسميات[1]);
    أرجع 0;
}
```

```text
6
شرق
```

تُقرأ `الخط.النهاية.س` بالترتيب: الحقل `النهاية` من `الخط`، ثم حقله `س`.

## السجلات والملكية

يملك السجل حقوله. فإن كانت كلها بسيطة كان السجل بسيطا ويُنسخ، كما رأيت في الفصل الرابع. وإن كان أي حقل مالكا، مثل حقلي
النص في `مستخدم`، كان السجل مالكا: فإسناده ينقله، وحين يخرج مالكه من نطاقه تُحرَّر حقوله كلها معه.

و`اطبع_سطر(المستخدم.البريد)` في المثال السابق تستعير الحقل فقط، لأن `اطبع_سطر` تأخذ `&نص`، فيبقى `المستخدم` كاملا. أما نقل
حقل مالك منه، كما في `دع البريد: نص = المستخدم.البريد;`، فمرفوض: لأنه يترك في السجل ثغرة. فاستنسخه بـ `استنسخ(&المستخدم.البريد)`
حين تحتاج إلى نص تملكه. أما قراءة حقل بسيط مثل `المستخدم.عدد_الدخول` فتنسخه ولا تحتاج إلى شيء خاص.

## اسم آخر لنوع

تستطيع `نوع` أيضا أن تعطي نوعا موجودا اسما ثانيا. والاسم الجديد هو النوع نفسه، لكنه يقول فيمَ تُستخدم القيمة:

```sultan
استورد المكتبة.دخ.اطبع_سطر;
استورد المكتبة.نصوص.أعداد;

نوع مئوية = عدد;
نوع شبكة = متجه متجه عدد;

عرف الرئيسية(): عدد {
    دع التجمد: مئوية = 0;
    دع الغليان: مئوية = 100;
    اطبع_سطر(عدد_إلى_نص(الغليان - التجمد));
    دع الشبكة: شبكة = [[1, 2, 3], [4, 5, 6]];
    اطبع_سطر(عدد_إلى_نص(الشبكة[1][2]));
    أرجع 0;
}
```

```text
100
6
```

ولأن `مئوية` اسم آخر لـ `عدد` فقط، تختلط `مئوية` و `عدد` بحرية. فالاسم هنا يوثّق ولا يحمي. ولتصنع نوعا لا يختلط بغيره،
غلّفه في سجل: `نوع مئوية = { الدرجات: عدد };`.

## التسمية

والعرف في أمثلة هذا الكتاب أن تُسمّى أنواعها الخاصة بأسماء مفردة (`مستخدم` و `نقطة`)، والحقول بأسماء كأسماء المتغيرات.
