# برمجة لعبة تخمين

يبني هذا الفصل برنامجا كاملا دفعة واحدة. يختار البرنامج عددا صحيحا بين 1 و 100 ويطلب منك تخمينه. وبعد كل تخمين يخبرك هل
هو أصغر من اللازم أم أكبر، وينتهي حين تخمّن العدد الصحيح.

وفي الطريق تقابل `ليكن` و `طابق` و `نتيجة` و `اختياري` والمراجع والحلقات والمكتبة القياسية. ولكل منها هنا شرح قصير فقط،
وتغطيها الفصول التالية كاملة. والهدف من هذا الفصل أن ترى كيف تعمل هذه الأجزاء معا في برنامج حقيقي، وأن تتمرن على قراءة ما
يقوله المترجم.

## إعداد المشروع

أنشئ مشروعا بسوباكس في مجلد `projects`:

```console
$ supax new لعبة_التخمين
أُنشئت الحزمة "لعبة_التخمين"
$ cd لعبة_التخمين
```

كتب سوباكس برنامج البداية نفسه الذي في الفصل الأول. شغّله لتتأكد أن كل شيء يعمل:


## قراءة التخمين

الجزء الأول من اللعبة يطلب تخمينا، ويقرؤه، ويطبعه. ضع القائمة 2-1 مكان محتوى `src/main.sn`.

<sub>القائمة 2-1: قراءة تخمين من المستخدم وطباعته. الملف: src/main.sn</sub>

```sultan stdin=42\n
استورد المكتبة.دخ.اطبع_سطر;
استورد المكتبة.دخ.اقرأ_سطر;
استورد المكتبة.نصوص.تحويل;

عرف الرئيسية(): عدد {
    اطبع_سطر("خمّن العدد!");
    اطبع_سطر("أدخل تخمينك.");

    ليكن التخمين: نص;
    طابق اقرأ_السطر() مع
    | نتيجة.نجح(السطر) -> { التخمين := قص_النص(&السطر); }
    | نتيجة.خطأ(_) -> {
        اطبع_سطر("تعذرت قراءة السطر");
        أرجع 1;
    };

    اطبع_سطر(صل_نصين(&"خمّنت: ", &التخمين));
    أرجع 0;
}
```

شغّله، واكتب `42` ثم اضغط Enter:

```console
$ supax run

       انتهى في 0.18 ث → build/bin/لعبة_التخمين
       يشغّل build/bin/لعبة_التخمين
خمّن العدد!
أدخل تخمينك.
42
خمّنت: 42
```

في هذه الأسطر أشياء كثيرة، فلنمرّ عليها.

### الاستيراد

```sultan ignore
استورد المكتبة.دخ.اطبع_سطر;
استورد المكتبة.دخ.اقرأ_سطر;
استورد المكتبة.نصوص.تحويل;
```

يستخدم البرنامج ثلاث وحدات من المكتبة القياسية: `اطبع_سطر` للطباعة، و `اقرأ_سطر` التي تقدّم الدالة `اقرأ_السطر` لقراءة
سطر يكتبه المستخدم، و `المكتبة.نصوص.تحويل` التي فيها `قص_النص` و `صل_نصين`، وهما دالتان تعملان على النصوص.

### حفظ قيمة: `ليكن`

```sultan ignore
    ليكن التخمين: نص;
```

تنشئ `ليكن` متغيرا: اسما لقيمة. وهذا السطر ينشئ متغيرا اسمه `التخمين` من النوع `نص`. وفي السلطان يُكتب نوع المتغير دائما،
بعد النقطتين.

وليس لهذا المتغير قيمة بعد، فقيمته تأتي بعد أسطر قليلة، مما يكتبه المستخدم. ويتحقق المترجم من أن كل طريق في البرنامج يعطي
`التخمين` قيمة قبل استخدامه، ومن أنه يأخذ قيمة مرة واحدة فقط. فالمتغير الذي لا تتغير قيمته هو الأصل في السلطان، ويبيّن
الفصل الثالث كيف تنشئ متغيرا تتغير قيمته.

### قراءة سطر، والتعامل مع الفشل

```sultan ignore
    طابق اقرأ_السطر() مع
    | نتيجة.نجح(السطر) -> { التخمين := قص_النص(&السطر); }
    | نتيجة.خطأ(_) -> {
        اطبع_سطر("تعذرت قراءة السطر");
        أرجع 1;
    };
```

تقرأ `اقرأ_السطر()` سطرا واحدا من مدخلات البرنامج، وهي هنا لوحة المفاتيح. وقد تفشل القراءة، كأن تكون المدخلات قد أُغلقت.
لذلك لا ترجع `اقرأ_السطر` النص مباشرة، بل ترجع `نتيجة`: قيمة تكون أحد شيئين:

- `نتيجة.نجح(…)` وفيها النص، إن نجحت القراءة؛
- `نتيجة.خطأ(…)` وفيها وصف الخطأ، إن لم تنجح.

تنظر `طابق` في قيمة وتنفّذ الفرع الذي يناسبها. ويبدأ كل فرع بـ `|`، ثم نمط (pattern)، ثم `->` والشيفرة التي تُنفَّذ.

- النمط `نتيجة.نجح(السطر)` يطابق القراءة الناجحة، ويسمّي النص الذي فيها `السطر`. ويعطي الفرع `التخمين` قيمة بـ `:=`.
- والنمط `نتيجة.خطأ(_)` يطابق الفشل، و `_` تعني "أي قيمة، لا أحتاجها". وهذا الفرع يطبع رسالة ويرجع 1 من `الرئيسية`،
  فينتهي البرنامج بحالة تعني الفشل.

ولا يسمح لك المترجم بنسيان الفرع الثاني: فيجب أن تعالج `طابق` كل قيمة ممكنة، فلا يمر فشل دون أن يُلاحظ. وتنتهي `طابق` كلها
بـ `;` مثل كل جملة.

### حذف السطر الجديد: `قص_النص` و `&`

حين تضغط Enter، ينتهي ما كتبته بمحرف السطر الجديد، وتبقيه `اقرأ_السطر`: فالنص الذي أرجعته لـ `42` هو `"42\n"`، و `\n`
هي طريقة كتابة السطر الجديد داخل نص. وترجع `قص_النص` النص دون المسافات والأسطر الجديدة التي في أوله وآخره، فيكون في
`التخمين` النص `"42"`.

ولاحظ أن `قص_النص(&السطر)` تمرر `&السطر` لا `السطر`. فـ `&` تصنع مرجعا (reference): يسمح لـ `قص_النص` بقراءة `السطر`
دون أن تأخذه. ويشرح الفصل الرابع أهمية ذلك: ففي السلطان لكل قيمة مالك واحد، والمرجع يتيح لدالة أن تستخدم قيمة ما زالت
ملكا لغيرها.

### طباعة التخمين

```sultan ignore
    اطبع_سطر(صل_نصين(&"خمّنت: ", &التخمين));
```

تصل `صل_نصين` نصين في نص جديد. والوسيطان كلاهما مرجعان، لأن `صل_نصين` تقرؤهما فقط. ويذهب النص الجديد مباشرة إلى
`اطبع_سطر`.

## توليد العدد السري

تحتاج اللعبة بعد ذلك إلى عدد يُخمَّن، ومختلف في كل مرة. والبرنامج الذي يختار أعدادا "عشوائية" يستخدم مولّد أعداد شبه
عشوائية (pseudorandom number generator): حسابا ينتج سلسلة أعداد تبدو عشوائية. وتعتمد السلسلة على قيمة بداية تسمى seed.
والـ seed نفسه يعطي دائما السلسلة نفسها، فيحتاج البرنامج إلى seed يتغير في كل تشغيل، والوقت الحالي بالنانوثانية يفي بذلك.

وتضيف القائمة 2-2 الأمرين.

<sub>القائمة 2-2: توليد عدد سري. الملف: src/main.sn</sub>

```sultan stdin=50\n
استورد المكتبة.دخ.اطبع_سطر;
استورد المكتبة.دخ.اقرأ_سطر;
استورد المكتبة.نصوص.أعداد;
استورد المكتبة.نصوص.تحويل;
استورد المكتبة.عشوائي.مولد;
استورد المكتبة.وقت.الوقت;

عرف الرئيسية(): عدد {
    اطبع_سطر("خمّن العدد!");

    ليكن البذرة: طبيعي;
    طابق وقت_نظام_نانو() مع
    | نتيجة.نجح(النانوثواني) -> { البذرة := النانوثواني مثل طبيعي; }
    | نتيجة.خطأ(_) -> { البذرة := 1; };
    ليكن المولد: متغير مولد_عشوائي = أنشئ_مولد_عشوائي(البذرة);
    ليكن العدد_السري: طبيعي;
    طابق عشوائي_بين(&متغير المولد, 1, 101) مع
    | اختياري.موجود(ع) -> { العدد_السري := ع; }
    | اختياري.لا_شيء -> { أرجع 1; };

    اطبع_سطر(صل_نصين(&"العدد السري: ", &طبيعي_إلى_نص(العدد_السري)));

    اطبع_سطر("أدخل تخمينك.");
    ليكن التخمين: نص;
    طابق اقرأ_السطر() مع
    | نتيجة.نجح(السطر) -> { التخمين := قص_النص(&السطر); }
    | نتيجة.خطأ(_) -> {
        اطبع_سطر("تعذرت قراءة السطر");
        أرجع 1;
    };

    اطبع_سطر(صل_نصين(&"خمّنت: ", &التخمين));
    أرجع 0;
}
```

شغّله عدة مرات، وستجد العدد السري يتغير في كل مرة:

```console

       يشغّل build/bin/لعبة_التخمين

أدخل تخمينك.
50
```

### الـ seed

```sultan ignore
    ليكن البذرة: طبيعي;
    طابق وقت_نظام_نانو() مع
    | نتيجة.نجح(النانوثواني) -> { البذرة := النانوثواني مثل طبيعي; }
    | نتيجة.خطأ(_) -> { البذرة := 1; };
```

ترجع `وقت_نظام_نانو()` من `المكتبة.وقت.الوقت` الوقت الحالي، بعدد النانوثواني منذ 1 يناير 1970. وقد يفشل طلب الوقت من
النظام، فهي ترجع `نتيجة` أيضا. وإن فشلت استخدم البرنامج 1 قيمةً للـ seed: فتعمل اللعبة، والعدد السري نفسه في كل مرة.

و `النانوثواني` من النوع `عدد`، وقد يكون سالبا. والمولّد يريد `طبيعي`: عددا صحيحا بلا إشارة، لا يكون سالبا أبدا. و
`مثل طبيعي` تحوّل الأول إلى الثاني. ولا يحوّل السلطان بين أنواع الأعداد وحده أبدا، بل تكتب التحويل دائما.

### المولّد

```sultan ignore
    ليكن المولد: متغير مولد_عشوائي = أنشئ_مولد_عشوائي(البذرة);
```

تنشئ `أنشئ_مولد_عشوائي` من `المكتبة.عشوائي.مولد` مولّدا من النوع `مولد_عشوائي` من الـ seed. ويُكتب النوع
`متغير مولد_عشوائي` لأن المولّد يتغير في كل مرة ينتج فيها عددا: ينتقل إلى العدد التالي في سلسلته. ولا يتغير متغير إلا إذا
كان نوعه `متغير`.

وهذا المولّد مناسب للألعاب والمحاكاة، ولا يصلح لكلمات المرور ومفاتيح التشفير، لأن من يعرف الـ seed يستطيع حساب أعداده.

### اختيار العدد

```sultan ignore
    ليكن العدد_السري: طبيعي;
    طابق عشوائي_بين(&متغير المولد, 1, 101) مع
    | اختياري.موجود(ع) -> { العدد_السري := ع; }
    | اختياري.لا_شيء -> { أرجع 1; };
```

تنتج `عشوائي_بين(&متغير المولد, 1, 101)` عددا من 1 إلى ما قبل 101، أي من 1 إلى 100. وتأخذ `&متغير المولد`، وهو مرجع مسموح
له بتغيير ما يشير إليه. وكتابة `&متغير` في الاستدعاء تُظهر لقارئ الشيفرة أن هذا الاستدعاء يغيّر `المولد`.

وترجع الدالة `اختياري`: `اختياري.موجود(ع)` وفيها العدد، و `اختياري.لا_شيء` تعني أنه لا عدد. ولا يحدث ذلك إلا إذا كان
المدى فارغا، مثل `عشوائي_بين(&متغير المولد, 5, 5)`. وهو لا يحدث هنا، لكن `طابق` تطلب الفرع مع ذلك، وإرجاع 1 جواب معقول.

و `نتيجة` و `اختياري` متشابهتان: استخدم `نتيجة` حين يمكن أن يفشل شيء وللفشل سبب، و `اختياري` حين قد لا توجد القيمة
أصلا.

ويطبع البرنامج العدد السري الآن لتختبره، ولن تطبعه النسخة الأخيرة.

### تحويل النص إلى عدد

```sultan ignore
    ليكن التخمين: طبيعي;
    طابق حلل_طبيعي(&قص_النص(&السطر)) مع
    | نتيجة.نجح(ع) -> { التخمين := ع; }
    | نتيجة.خطأ(_) -> {
        اطبع_سطر("اكتب عددا!");
        أرجع 1;
    };
```

تقرأ `حلل_طبيعي` من `المكتبة.نصوص.أعداد` قيمة `طبيعي` من نص. والمستخدم قد يكتب أي شيء، و `"مرحبا"` ليست عددا، فترجع
`حلل_طبيعي` أيضا `نتيجة`: `نتيجة.نجح(ع)` وفيها العدد، أو `نتيجة.خطأ(…)` إن لم يكن النص عددا.

وصار اسم السطر المقروء `السطر`، و `التخمين` هو العدد. وتنتج `قص_النص(&السطر)` النص المقصوص، وتمرر `&` مرجعا إليه إلى
`حلل_طبيعي`.

ولطباعة التخمين تحوّل `طبيعي_إلى_نص` العدد إلى نص من جديد.

### المقارنة

```sultan ignore
    إذا (التخمين < العدد_السري) {
        اطبع_سطر("أصغر من اللازم!");
    } وإلا إذا (التخمين > العدد_السري) {
        اطبع_سطر("أكبر من اللازم!");
    } وإلا {
        اطبع_سطر("فزت!");
    };
```

تنفّذ `إذا` كتلتها حين يكون الشرط الذي بين القوسين صحيحا. وتجرّب `وإلا إذا` شرطا آخر حين يكون الأول خاطئا، وتنفَّذ `وإلا`
حين لا يصح أي شرط. فتُطبع رسالة واحدة بالضبط من الثلاث. ومثل `طابق`، فإن `إذا` كلها جملة تنتهي بـ `;`.

## الخلاصة

استخدم هذا الفصل، باختصار، كثيرا مما يتكون منه برنامج السلطان:

- تنشئ `ليكن الاسم: النوع` متغيرا مع كتابة نوعه. ويأخذ المتغير قيمة واحدة، وقد تأتي بعد `ليكن`، والنوع `متغير` يسمح بتغييرها.
- الدوال التي قد تفشل ترجع `نتيجة`، والتي قد لا يكون لها قيمة ترجع `اختياري`. وتعالج `طابق` كل الحالات، ويتحقق المترجم
  من أنه لا حالة ناقصة.
- تمرر `&` مرجعا، فتستخدم الدالة القيمة دون أن تأخذها، و `&متغير` تسمح لها بتغييرها.
- لا تتحول أنواع الأعداد وحدها: `مثل طبيعي` تحوّل، و `حلل_طبيعي` تقرأ عددا من نص، و `طبيعي_إلى_نص` تكتبه نصا.
- تختار `إذا` و `وإلا إذا` و `وإلا`، وتكرر `طالما`، وتخرج `اخرج_من_حلقة` من الحلقة، وتبدأ `تابع_حلقة` دورتها التالية.

وتأخذ الفصول التالية هذه الأشياء واحدا واحدا، ويبدأ الفصل الثالث بالمتغيرات والأنواع والدوال.

1. عُدّ التخمينات، واطبع عدد المحاولات بعد `فزت!`. ستحتاج إلى متغير من النوع `متغير طبيعي`، تغيّره بـ

3. اطبع `خارج المدى!` حين يكون التخمين أصغر من 1 أو أكبر من 100، دون أن يُحسب.
