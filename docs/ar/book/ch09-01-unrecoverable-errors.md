# أخطاء لا رجعة منها بـ `إنهيار`

يصل البرنامج أحيانا إلى حالة كان ينبغي أن تستحيل. وحينها فالتصرف الأمين أن يتوقف، ويقول أين ولماذا.

## `إنهيار`

توقف `إنهيار(الرسالة)` من `المكتبة.عمليات.انهيار` البرنامج برسالة:

```sultan exit=1
استورد المكتبة.دخ.اطبع_سطر;
استورد المكتبة.عمليات.انهيار;

عرف الرئيسية(): عدد {
    اطبع_سطر("بدأ البرنامج");
    إنهيار("الإعدادات مفقودة");
    اطبع_سطر("لا يُنفَّذ هذا السطر أبدا");
    أرجع 0;
}
```

يطبع البرنامج ما طبعه قبل الانهيار في الخرج القياسي:

```text
بدأ البرنامج
```

والسبب في *الخطأ القياسي* (standard error)، وهو الخرج المنفصل للمشكلات، ثم يخرج بالحالة 1:

```text stderr
خطأ[SULTANC-RUNTIME-PROGRAM-STOPPED]: توقف البرنامج
الإعدادات مفقودة
```

السطر الأول تكتبه المكتبة القياسية، بلغة البيئة التي يعمل فيها البرنامج. والثاني رسالتك. ولأنها تذهب إلى الخطأ القياسي، فالمستخدم
الذي يحوّل خرج البرنامج إلى ملف يراها مع ذلك.

## التأكيدات

توقف `تأكد(الشرط)` من `المكتبة.تصحيح.تأكد` البرنامج حين يكون الشرط خاطئا. وتفعل `تأكد_برسالة(الشرط, &الرسالة)` الشيء نفسه
مع شرحك. فالتأكيد يذكر شيئا يجب أن يكون صحيحا، ويفحصه في كل مرة يعمل فيها البرنامج:

```sultan
استورد المكتبة.دخ.اطبع_سطر;
استورد المكتبة.تصحيح.تأكد;

عرف المضروب(ن: عدد): عدد {
    إذا (ن <= 1) {
        أرجع 1;
    };
    أرجع ن * المضروب(ن - 1);
}

عرف الرئيسية(): عدد {
    تأكد(المضروب(5) == 120);
    دع الرسالة: نص = "يجب أن يكون المضروب(6) هو 720";
    تأكد_برسالة(المضروب(6) == 720, &الرسالة);
    اطبع_سطر("نجحت كل الفحوص");
    أرجع 0;
}
```

```text
نجحت كل الفحوص
```

وحين يفشل أحدها يتوقف البرنامج ويقول أين:

```sultan exit=1
استورد المكتبة.تصحيح.تأكد;

عرف الرئيسية(): عدد {
    دع الرصيد: عدد = -5;
    تأكد(الرصيد >= 0);
    أرجع 0;
}
```

```text stderr
خطأ[SULTANC-RUNTIME-PROGRAM-STOPPED]: توقف البرنامج — فشل تأكيد.
  --> main.sn:5:5
```

`main.sn:5:5` هو الملف والسطر والعمود للتأكيد الذي فشل.

## توقفات لم تكتبها

قابلت نوعا ثالثا في الفصل الثالث: تجاوز الحد، والقسمة على صفر، والموضع الذي بعد نهاية المتجه، كلها توقف البرنامج أيضا. فهذه
فحوص تجريها اللغة على كل عملية من هذا النوع، لأن الاستمرار بعدد خاطئ أو بذاكرة ليست لك ليس صحيحا أبدا. وهي توقف البرنامج كما
توقفه `إنهيار`، برسالة تقول ما الخطأ وأين وقع:

```sultan exit=1
استورد المكتبة.دخ.اطبع_سطر;
استورد المكتبة.نصوص.أعداد;

عرف المتوسط(المجموع: عدد, الكمية: عدد): عدد {
    أرجع المجموع / الكمية;
}

عرف الرئيسية(): عدد {
    اطبع_سطر(عدد_إلى_نص(المتوسط(10, 0)));
    أرجع 0;
}
```

```text stderr
خطأ[SULTANC-RUNTIME-PROGRAM-STOPPED]: توقف البرنامج
قسمة على صفر عند main.sn:5:10
```

و`main.sn:5:10` هو حيث تبدأ `المجموع / الكمية`. ونص تجاوز الحد `تجاوز العدد الصحيح حدود نوعه عند …`، ونص الموضع الذي بعد
النهاية `الفهرس 5 خارج المدى للطول 3 عند …`.
