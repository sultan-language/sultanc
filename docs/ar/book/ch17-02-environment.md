# البيئة

يبدأ كل برنامج ببيئة (environment): سطر أوامره، ومجموعة متغيرات مسماة، ودليل عمل. واستخدم الفصل الثاني عشر الأولين، وهنا
تجتمع.

## سطر الأوامر

ترجع `الوسائط()` من `المكتبة.عمليات.الوسائط` سطر الأوامر كله متجه نصوص، والبرنامج نفسه في الموضع 0. وقد كتب الفصل الثاني عشر
الدالة نفسها بيده من `وسيطة` و `عدد_الوسائط`:

```sultan
استورد المكتبة.دخ.اطبع_سطر;
استورد المكتبة.نصوص.أعداد;
استورد المكتبة.عمليات.الوسائط;

عرف الرئيسية(): عدد {
    ليكن الكل: متجه نص = الوسائط();
    اطبع_سطر(عدد_إلى_نص(الطول(الكل) - 1));
    أرجع 0;
}
```

```text
0
```

وحين يبدأ بلا وسائط يطبع البرنامج 0.

## المتغيرات

تقرأ `متغير_بيئة(&الاسم)` متغيرا. وترجع `نتيجة اختياري نص`: خطأ إن تعذرت قراءة البيئة، و `لا_شيء` إن لم يكن المتغير مضبوطا، و
`موجود(القيمة)` فيما عدا ذلك:

```sultan
استورد المكتبة.دخ.اطبع_سطر;
استورد المكتبة.بيئة.بيئة_العمل;

عرف الرئيسية(): عدد {
    طابق متغير_بيئة(&"PATH") مع
    | نتيجة.نجح(اختياري.موجود(_)) -> { اطبع_سطر("PATH مضبوط"); }
    | نتيجة.نجح(اختياري.لا_شيء) -> { اطبع_سطر("PATH غير مضبوط"); }
    | نتيجة.خطأ(_) -> { اطبع_سطر("تعذرت قراءة البيئة"); };
    أرجع 0;
}
```

```text
PATH مضبوط
```

والمتغيرات الطريقة المعتادة لإعطاء البرنامج إعدادات لا ينبغي أن تُكتب في كل سطر أوامر: أين يحفظ بياناته، وبأي لغة يتكلم، وهل
يطبع تفاصيل أكثر.

## دليل العمل

ترجع `دليل_العمل()` المجلد الذي تُحل منه المسارات النسبية، وترجع `الدليل_المؤقت()` مجلد النظام للملفات المؤقتة. وكلتاهما ترجع
`نتيجة`:

```sultan
استورد المكتبة.دخ.اطبع_سطر;
استورد المكتبة.بيئة.بيئة_العمل;

عرف الرئيسية(): عدد {
    طابق دليل_العمل() مع
    | نتيجة.نجح(_) -> { اطبع_سطر("دليل العمل معروف"); }
    | نتيجة.خطأ(الرمز) -> { أرجع الرمز; };
    أرجع 0;
}
```

```text
دليل العمل معروف
```
