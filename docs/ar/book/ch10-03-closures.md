# الـ closures

كتابة دالة مسماة لكل مقارنة صغيرة تصير مملة. فيجوز أن تُكتب الدالة حيث تُحتاج، بلا اسم:

```sultan ignore
دالة(س: عدد): عدد -> س * 2
```

هذه *دالة مجهولة* (anonymous function): `دالة`، ثم المعاملات بأنواعها، ثم نوع القيمة، ثم `->` وتعبير واحد ترجع الدالة قيمته.

```sultan
استورد المكتبة.دخ.اطبع_سطر;
استورد المكتبة.نصوص.تحويل;
استورد المكتبة.مجموعات.ترتيب;

عرف الرئيسية(): عدد {
    دع الكلمات: متغير متجه نص = ["برتقال", "تين", "تفاح"];
    رتب_بالمقارنة(&متغير الكلمات, دالة(أ: &نص, ب: &نص): عدد -> الطول(*أ) - الطول(*ب));
    اطبع_سطر(صل_النصوص(&الكلمات, &"، "));
    أرجع 0;
}
```

```text
تين، تفاح، برتقال
```

جسم الدالة المجهولة تعبير واحد. فحين يحتاج العمل إلى جمل، أو حلقة، أو `طابق`، فاكتب دالة مسماة ومرر اسمها.

## التقاط القيم

تستطيع الدالة المجهولة أن تستخدم المتغيرات المحيطة بالمكان الذي كُتبت فيه. فهي *تلتقطها* (capture)، وتحتفظ بها حتى بعد أن
ترجع الدالة التي أنشأتها:

```sultan
استورد المكتبة.دخ.اطبع_سطر;
استورد المكتبة.نصوص.أعداد;

عرف اصنع_جامعا(المقدار: عدد): دالة(عدد): عدد {
    أرجع دالة(القيمة: عدد): عدد -> القيمة + المقدار;
}

عرف الرئيسية(): عدد {
    دع أضف_عشرة: دالة(عدد): عدد = اصنع_جامعا(10);
    دع أضف_اثنين: دالة(عدد): عدد = اصنع_جامعا(2);
    اطبع_سطر(عدد_إلى_نص(أضف_عشرة(5)));
    اطبع_سطر(عدد_إلى_نص(أضف_اثنين(أضف_عشرة(30))));
    أرجع 0;
}
```

```text
15
42
```

كل استدعاء لـ `اصنع_جامعا` ينتج دالة جديدة لها `المقدار` الخاص بها. والدالة التي تحمل معها قيما ملتقطة تسمى *closure*.

ويستطيع الـ closure أن يلتقط قيما مالكة أيضا. فتنتقل القيمة إليه، فيملكها، ويحررها حين يزول هو:

```sultan
استورد المكتبة.دخ.اطبع_سطر;
استورد المكتبة.نصوص.تحويل;

عرف اصنع_محييا(التحية: نص): دالة(&نص): نص {
    أرجع دالة(الاسم: &نص): نص -> صل_ثلاثة_نصوص(&التحية, &" ", الاسم);
}

عرف الرئيسية(): عدد {
    دع أهلا: دالة(&نص): نص = اصنع_محييا("أهلا");
    اطبع_سطر(أهلا(&"نور"));
    اطبع_سطر(أهلا(&"آدم"));
    أرجع 0;
}
```

```text
أهلا نور
أهلا آدم
```

## دوال عامة قليلة بدلا من حلقات كثيرة

بالمعاملات من نوع دالة، تغطي دوال عامة قليلة حلقات كثيرة. فتُبقي `أبق` القيم التي تجتاز شرطا، وتدمج `اطو` كل القيم في قيمة
واحدة:

```sultan
استورد المكتبة.دخ.اطبع_سطر;
استورد المكتبة.نصوص.أعداد;

عرف أبق(القيم: &متجه عدد, الشرط: دالة(عدد): منطقي): متجه عدد {
    دع الناتج: متغير متجه عدد = [];
    لكل (دع ع: متغير عدد = 0; ع < الطول(*القيم); ع := ع + 1) {
        إذا (الشرط((*القيم)[ع])) {
            ألحق(الناتج, (*القيم)[ع]);
        };
    }
    أرجع الناتج;
}

عرف اطو(القيم: &متجه عدد, البداية: عدد, ادمج: دالة(عدد, عدد): عدد): عدد {
    دع المجموع: متغير عدد = البداية;
    لكل (دع ع: متغير عدد = 0; ع < الطول(*القيم); ع := ع + 1) {
        المجموع := ادمج(المجموع, (*القيم)[ع]);
    }
    أرجع المجموع;
}

عرف الرئيسية(): عدد {
    دع الأعداد: متجه عدد = [1, 2, 3, 4, 5, 6];
    دع الزوجية: متجه عدد = أبق(&الأعداد, دالة(ن: عدد): منطقي -> ن % 2 == 0);
    اطبع_سطر(عدد_إلى_نص(اطو(&الزوجية, 0, دالة(أ: عدد, ب: عدد): عدد -> أ + ب)));
    اطبع_سطر(عدد_إلى_نص(اطو(&الأعداد, 1, دالة(أ: عدد, ب: عدد): عدد -> أ * ب)));
    أرجع 0;
}
```

```text
12
720
```

مجموع الأعداد الزوجية وحاصل ضرب كل الأعداد سطران، والحلقات مكتوبة مرة واحدة.

## الخلاصة

- يصرّح `عرف الاسم<T>(…)` و `نوع الاسم<T> = …;` بدوال وأنواع عامة، ويستنتج المترجم `T` في كل استدعاء، ويصنع نسخة لكل نوع.
- `دالة(أ, ب): ر` نوع دالة، واسم الدالة المسماة قيمة من ذلك النوع.
- `دالة(س: T): ر -> تعبير` دالة مجهولة جسمها تعبير واحد.
- تلتقط الدالة المجهولة المتغيرات التي تستخدمها وتحتفظ بها: فهي closure.
- لا توجد traits: الشيفرة العامة تأخذ دالة لمقارنة قيم من معامل نوع أو دمجها.
