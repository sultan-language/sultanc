# التعليقات

التعليق ملاحظة لمن يقرأ الشيفرة، ويتجاهله المترجم.

يبدأ التعليق بـ `//` ويمتد إلى آخر السطر:

```sultan
استورد المكتبة.دخ.اطبع_سطر;

// يطبع مواعيد عمل المتجر.
عرف الرئيسية(): عدد {
    اطبع_سطر("مفتوح من 9 إلى 5"); // أيام العمل فقط
    أرجع 0;
}
```

```text
مفتوح من 9 إلى 5
```

يجوز أن يكون التعليق في سطر وحده، وعادة فوق الشيفرة التي يشرحها، أو بعد الشيفرة في السطر نفسه. والتعليق الأطول من سطر عدة
أسطر يبدأ كل منها بـ `//`:

```sultan ignore
// تُحسب الضريبة على السعر بعد الخصم،
// كما يشترط قانون بلد البيع.
```

والتعليق الجيد يقول *لماذا* كُتبت الشيفرة هكذا: سبب اختيار، أو قاعدة تتبعها، أو حالة تحمي منها. أما ما تفعله الشيفرة
فينبغي أن تقوله الشيفرة نفسها، بأسماء واضحة.

وليس في السلطان إلا تعليقات السطر، فلا توجد صيغة تبدأ وتنتهي داخل سطر.
