# النصوص والبايتات والمحارف

يحمل `نص` كتابة بأي طول، وبأي خط. والنص يبدو بسيطا وليس كذلك: فعلى البرنامج أن يعرف ما المحرف، وكيف يُخزَّن، وكم بايتا
يشغل. ويبين هذا القسم كيف يجيب السلطان عن هذه الأسئلة، والدوال اليومية للعمل مع النصوص.

والدوال من وحدات تحت `المكتبة.نصوص`:

| الوحدة | ما فيها |
| --- | --- |
| `المكتبة.نصوص.تحويل` | `صل_نصين` و `صل_ثلاثة_نصوص` و `صل_النصوص` و `قسم_النص` و `قص_النص` و `استبدل_في_النص` و `أسطر_النص` |
| `المكتبة.نصوص.أعداد` | `عدد_إلى_نص` و `طبيعي_إلى_نص` و `حلل_عدد` و `حلل_طبيعي` |
| `المكتبة.نصوص.عشري` | `ع64_إلى_نص` و `حلل_ع64` |
| `المكتبة.نصوص.بحث` | `يحتوي_نصا` و `يبدأ_بـ` و `ينتهي_بـ` و `ابحث_نصا` و `نص_فارغ` و `عدد_محارف_النص` |
| `المكتبة.نصوص.مقارنة` | `نصان_متساويان` و `قارن_نصين_معجميا` |
| `المكتبة.نصوص.مقطع` | `مقطع_نص` |
| `المكتبة.نصوص.باني` | `باني_نص`، لبناء نص طويل قطعة قطعة |

## كتابة النصوص

يُكتب النص الحرفي بين علامتي تنصيص مزدوجتين. وداخله تبدأ الشرطة المائلة العكسية *تهريبا* (escape)، وهو طريقة لكتابة محرف لا
يُكتب مباشرة:

| التهريب | معناه |
| --- | --- |
| `\n` | سطر جديد |
| `\t` | مسافة جدولة (tab) |
| `\"` | علامة تنصيص مزدوجة |
| `\\` | شرطة مائلة عكسية |

ويجوز أيضا أن يُكتب النص بين `«` و `»`. فلا شيء داخلهما تهريب، ولا تحتاج `"` إلى شيء، وهذا يناسب نصا مليئا بعلامات التنصيص
أو الشرطات المائلة:

```sultan
استورد المكتبة.دخ.اطبع_سطر;

عرف الرئيسية(): عدد {
    اطبع_سطر("السطر الأول\nالسطر الثاني");
    اطبع_سطر("كلمة \"مقتبسة\"، وشرطة مائلة: \\");
    اطبع_سطر(«لا تهريب هنا: \t و"علامات التنصيص" تبقى كما هي»);
    أرجع 0;
}
```

```text
السطر الأول
السطر الثاني
كلمة "مقتبسة"، وشرطة مائلة: \
لا تهريب هنا: \t و"علامات التنصيص" تبقى كما هي
```

## النص يملك محتواه

النص قيمة مالكة: محارفه تعيش في الكومة. وكل ما في الفصل الرابع ينطبق عليه. فتمرير نص إلى دالة تأخذ `نص` ينقله، ولذلك تأخذ
الدوال التي تقرأ نصا فقط `&نص`. و`اطبع_سطر` منها: فالـ `نص` المُمرَّر حيث يُنتظر `&نص` يُستعار للاستدعاء، فتُبقي
`اطبع_سطر(التحية)` المتغير `التحية` صالحا للاستخدام.

## وصل النصوص

`+` تجمع الأعداد فقط. ولوصل النصوص استخدم `صل_نصين` لقطعتين، و `صل_ثلاثة_نصوص` لثلاث، و `صل_النصوص` لمتجه قطع بينها فاصل:

```sultan
استورد المكتبة.دخ.اطبع_سطر;
استورد المكتبة.نصوص.تحويل;

عرف الرئيسية(): عدد {
    دع الأول: نص = "ليلى";
    دع الأخير: نص = "حسن";
    اطبع_سطر(صل_ثلاثة_نصوص(&الأول, &" ", &الأخير));
    دع الكلمات: متجه نص = ["أحمر", "أخضر", "أزرق"];
    اطبع_سطر(صل_النصوص(&الكلمات, &", "));
    اطبع_سطر(الأول);
    أرجع 0;
}
```

```text
ليلى حسن
أحمر, أخضر, أزرق
ليلى
```

تأخذ هذه الدوال وسائطها بالمرجع وترجع نصا جديدا، فيبقى `الأول` و `الأخير` صالحين بعدها.

## الأعداد في النصوص، والنصوص في الأعداد

تكتب `عدد_إلى_نص` و `طبيعي_إلى_نص` العدد نصا عشريا، وتكتب `ع64_إلى_نص` العدد العائم. وفي الاتجاه الآخر تقرأ `حلل_عدد`
عددا من نص. وليس كل نص عددا، فترجع `نتيجة`:

```sultan
استورد المكتبة.دخ.اطبع_سطر;
استورد المكتبة.نصوص.أعداد;

عرف الرئيسية(): عدد {
    طابق حلل_عدد(&"-42") مع
    | نتيجة.نجح(العدد_المقروء) -> { اطبع_سطر(عدد_إلى_نص(العدد_المقروء * 2)); }
    | نتيجة.خطأ(_) -> { اطبع_سطر("ليس عددا"); };
    طابق حلل_عدد(&"4x2") مع
    | نتيجة.نجح(العدد_المقروء) -> { اطبع_سطر(عدد_إلى_نص(العدد_المقروء)); }
    | نتيجة.خطأ(_) -> { اطبع_سطر("ليس عددا"); };
    أرجع 0;
}
```

```text
-84
ليس عددا
```

## مقارنة النصوص

يقارن `==` و`!=` نصين بمحتواهما: فهما متساويان حين يحملان المحارف نفسها. ولا يُنقل أي من الطرفين، فيبقى النص صالحا بعد
المقارنة. أما ترتيبهما المعجمي فتعطيه `قارن_نصين_معجميا` من `المكتبة.نصوص.مقارنة`: عددا سالبا إن جاء الأول أولا، وصفرا إن
تساويا، وعددا موجبا فيما عدا ذلك. ولا تُعرَّف `<` و`>` للنصوص:

```sultan
استورد المكتبة.دخ.اطبع_سطر;
استورد المكتبة.نصوص.مقارنة;

عرف الرئيسية(): عدد {
    دع الجواب: نص = "نعم";
    إذا (الجواب == "نعم") {
        اطبع_سطر("تم التأكيد");
    };
    إذا (قارن_نصين_معجميا(&"تفاح", &"موز") < 0) {
        اطبع_سطر("التفاح أولا");
    };
    أرجع 0;
}
```

```text
تم التأكيد
التفاح أولا
```

وفي `المكتبة.نصوص.مقارنة` أيضا `نصان_متساويان(&أ, &ب)`، وهي اختبار `==` نفسه مكتوبا دالة، للشيفرة التي تحتاج المقارنة قيمةً
دالية.

وتقارن `طابق` على نص، كما في الفصل الثالث، النصوص أيضا.

## البايتات والمحارف

كم طول `"سلطان"`؟ يعتمد على ما تعدّه.

يخزّن السلطان النصوص بترميز *UTF-8*، وهو الترميز الذي يستخدمه الويب وأغلب الأنظمة. وفي UTF-8 يشغل الحرف اللاتيني بايتا
واحدا، والحرف العربي بايتين، وبعض المحارف، مثل كثير من الرموز التعبيرية، أربعة. فتعدّ `الطول` البايتات، أي المساحة التي
يشغلها النص، وتعدّ `عدد_محارف_النص` المحارف:

```sultan
استورد المكتبة.دخ.اطبع_سطر;
استورد المكتبة.نصوص.أعداد;
استورد المكتبة.نصوص.بحث;

عرف الرئيسية(): عدد {
    دع لاتيني: نص = "Sultan";
    دع عربي: نص = "سلطان";
    اطبع_سطر(عدد_إلى_نص(الطول(لاتيني)));
    اطبع_سطر(عدد_إلى_نص(الطول(عربي)));
    اطبع_سطر(طبيعي_إلى_نص(عدد_محارف_النص(&عربي)));
    أرجع 0;
}
```

```text
6
10
5
```

والمواضع في النص مواضع بايتات أيضا. فـ `النص[0]` هو البايت الأول، من النوع `ط8`، لا المحرف الأول:

```sultan
استورد المكتبة.دخ.اطبع_سطر;
استورد المكتبة.نصوص.أعداد;

عرف الرئيسية(): عدد {
    دع عربي: نص = "سلطان";
    دع الأول: ط8 = عربي[0];
    اطبع_سطر(طبيعي_إلى_نص(الأول مثل طبيعي));
    أرجع 0;
}
```

```text
216
```

216 هي أول بايتي `س`، وليست محرفا أصلا. ولهذا لا يعطي السلطان مواضع النص محارف: فإيجاد المحرف العاشر يعني قراءة التسعة قبله،
إذ قد يختلف عرض كل منها، فيكلّف موضعٌ يبدو رخيصا المرورَ على النص بصمت. أما مواضع البايتات فرخيصة دائما، والدوال التي تعمل
بالمحارف، مثل `عدد_محارف_النص`، تقول ذلك في أسمائها.

## البحث

```sultan
استورد المكتبة.دخ.اطبع_سطر;
استورد المكتبة.نصوص.أعداد;
استورد المكتبة.نصوص.بحث;

عرف الرئيسية(): عدد {
    دع الجملة: نص = "الثعلب البني السريع";
    إذا (يحتوي_نصا(&الجملة, &"البني")) { اطبع_سطر("فيه البني"); };
    إذا (يبدأ_بـ(&الجملة, &"الثعلب")) { اطبع_سطر("يبدأ بالثعلب"); };
    إذا (ينتهي_بـ(&الجملة, &"السريع")) { اطبع_سطر("ينتهي بالسريع"); };
    طابق ابحث_نصا(&الجملة, &"السريع") مع
    | اختياري.موجود(الموضع) -> { اطبع_سطر(طبيعي_إلى_نص(الموضع)); }
    | اختياري.لا_شيء -> { اطبع_سطر("غير موجود"); };
    أرجع 0;
}
```

```text
فيه البني
يبدأ بالثعلب
ينتهي بالسريع
24
```

ترجع `ابحث_نصا` القيمة `موجود` مع موضع البايت لأول تطابق، أو `لا_شيء`.

## تقطيع النص

تحذف `قص_النص` المسافات البيضاء من الطرفين: المسافات، والجدولة، والأسطر الجديدة، وباقي محارف المسافة في يونيكود. وتقطع
`قسم_النص` النص عند كل فاصل وترجع متجها بالقطع. وتستبدل `استبدل_في_النص` كل ظهور لنص بنص آخر. وتأخذ `مقطع_نص` الجزء الذي
يبدأ عند موضع بايت وله طول بالبايتات، وترجع `اختياري` يكون فارغا حين يتجاوز المدى النهاية:

```sultan
استورد المكتبة.دخ.اطبع_سطر;
استورد المكتبة.نصوص.أعداد;
استورد المكتبة.نصوص.تحويل;
استورد المكتبة.نصوص.مقطع;

عرف الرئيسية(): عدد {
    دع السطر: نص = "  أحمر, أخضر, أزرق  ";
    دع النظيف: نص = قص_النص(&السطر);
    دع الألوان: متجه نص = قسم_النص(&النظيف, &", ");
    اطبع_سطر(عدد_إلى_نص(الطول(الألوان)));
    اطبع_سطر(الألوان[1]);
    اطبع_سطر(استبدل_في_النص(&النظيف, &"أخضر", &"ذهبي"));
    طابق مقطع_نص(&النظيف, 10, 8) مع
    | اختياري.موجود(الجزء) -> { اطبع_سطر(الجزء); }
    | اختياري.لا_شيء -> { اطبع_سطر("خارج المدى"); };
    أرجع 0;
}
```

```text
3
أخضر
أحمر, ذهبي, أزرق
أخضر
```

## بناء نص طويل

وصل القطع واحدة واحدة بـ `صل_نصين` ينسخ كل ما جُمع حتى الآن في كل خطوة. وللنص المبني من قطع كثيرة استخدم *باني النص*، الذي
يجمع القطع ويصنع نصا واحدا في النهاية:

```sultan
استورد المكتبة.دخ.اطبع_سطر;
استورد المكتبة.نصوص.باني;
استورد المكتبة.نصوص.أعداد;

عرف الرئيسية(): عدد {
    دع الباني: متغير باني_نص = أنشئ_باني_نص();
    لكل (دع ع: متغير عدد = 1; ع <= 5; ع := ع + 1) {
        دع أضيف: منطقي = ألحق_نصا_بباني_النص(&متغير الباني, &عدد_إلى_نص(ع));
        إذا (ع < 5) {
            دع الفاصلة: منطقي = ألحق_نصا_بباني_النص(&متغير الباني, &", ");
        };
    }
    اطبع_سطر(نص_باني_النص(&الباني));
    أرجع 0;
}
```

```text
1, 2, 3, 4, 5
```

وترجع دوال الإلحاق `خطأ` إن نفدت الذاكرة، ويتجاهل هذا المثال ذلك بتخزين أجوبتها في متغيرات لا يستخدمها.
