# الوقت

## ساعتان

في `المكتبة.وقت.الوقت` ساعتان لسؤالين مختلفين:

- تجيب `وقت_نظام_نانو()` عن *كم الساعة؟*: عدد النانوثواني منذ 1 يناير 1970 (UTC). وهي التي استخدمها الفصل الثاني seed.
  وقد تقفز: فقد يضبط المستخدم أو الشبكة الساعة.
- وتجيب `وقت_رتيب_نانو()` عن *كم استغرق ذلك؟*: نانوثوان منذ لحظة ثابتة. ولا تتقدم إلا إلى الأمام، فالفرق بين قراءتين مدة
  حقيقية.

وتوقف `نم_نانو(ن)` الخيط ما لا يقل عن `ن` نانوثانية. وهنا يقيس البرنامج توقفا:

```sultan
استورد المكتبة.دخ.اطبع_سطر;
استورد المكتبة.وقت.الوقت;

عرف الآن(): عدد {
    طابق وقت_رتيب_نانو() مع
    | نتيجة.نجح(نانو) -> { أرجع نانو; }
    | نتيجة.خطأ(_) -> { أرجع 0; };
}

عرف الرئيسية(): عدد {
    ليكن البداية: عدد = الآن();
    طابق نم_نانو(50000000) مع
    | نتيجة.نجح(_) -> { }
    | نتيجة.خطأ(_) -> { أرجع 1; };
    ليكن المنقضي_مللي: عدد = (الآن() - البداية) / 1000000;
    إذا (المنقضي_مللي >= 50) {
        اطبع_سطر("نام 50 مللي ثانية على الأقل");
    };
    أرجع 0;
}
```

```text
نام 50 مللي ثانية على الأقل
```

قس المدد بالساعة الرتيبة، لا بساعة النظام أبدا: فإن أُرجعت ساعة النظام ساعة إلى الوراء وأنت تقيس، صار الفرق سالبا.

## التواريخ

تجيب `المكتبة.وقت.تقويم` عن أسئلة التقويم:

```sultan
استورد المكتبة.دخ.اطبع_سطر;
استورد المكتبة.نصوص.أعداد;
استورد المكتبة.وقت.تقويم;

عرف الرئيسية(): عدد {
    اطبع_سطر(طبيعي_إلى_نص(أيام_في_الشهر(2028, 2)));
    إذا (سنة_كبيسة(2028)) {
        اطبع_سطر("2028 سنة كبيسة");
    };
    أرجع 0;
}
```

```text
29
2028 سنة كبيسة
```

وفي `المكتبة.وقت` أيضا المدد، والتواريخ، وأوقات اليوم، والمناطق الزمنية، ونصوص ISO 8601، وفي مجلد `examples/ar/time` برنامج
لكل منها.

## الخلاصة

- الملفات: `اكتب_الملف` و `اقرأ_الملف` و `أعد_تسمية` و `أزل_ملفا`، والمجلدات: `أنشئ_مسار_الدليل` و `اقرأ_مدخلات_الدليل` و
  `احذف_الشجرة`. والمسارات النسبية تبدأ من دليل العمل.
- البيئة: `الوسائط()` و `متغير_بيئة` و `دليل_العمل`.
- البرامج الأخرى: `أنشئ_أمرا` و `أضف_وسيطة_للأمر` و `شغل_الأمر`، والوسائط تمر دون shell.
- الوقت: `وقت_نظام_نانو` للتاريخ، و `وقت_رتيب_نانو` للمدد، و `نم_نانو` للانتظار.
