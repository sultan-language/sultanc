# كتابة الأخطاء إلى الخطأ القياسي

للبرنامج خرجان. *الخرج القياسي* (standard output) لنتائجه، و*الخطأ القياسي* (standard error) لرسائل المشكلات. وحين يرسل
المستخدم النتائج إلى ملف بـ `>`، لا يذهب إليه إلا الخرج القياسي، وتبقى الرسائل ظاهرة على الشاشة.

يطبع `باحث` رسائل الخطأ بـ `اطبع_سطر` في الخرج القياسي. أرسل الخرج إلى ملف، مع ملف غير موجود:

```console
$ supax run -- الحجر missing.txt > found.txt
$ cat found.txt
تعذرت قراءة missing.txt
```

ذهبت الرسالة إلى الملف، حيث توقع المستخدم نتائج البحث، ولم يظهر شيء على الشاشة. والإصلاح `اطبع_سطر_خطأ` من
`المكتبة.دخ.اطبع_سطر` مثل `اطبع_سطر`، التي تطبع سطرا في الخطأ القياسي. وهذه `main.sn` الأخيرة:

<sub>القائمة 12-9: البرنامج الأخير. الملف: src/main.sn</sub>

```sultan ignore
استورد المكتبة.دخ.اطبع_سطر;
استورد المكتبة.عمليات.وسيطة;
استورد المكتبة.عمليات.عدد_الوسائط;
استورد المكتبة.ملفات.قراءة_ملف;
استورد المكتبة.بيئة.بيئة_العمل;
استورد المكتبة.نصوص.تحويل;
استورد باحث.البحث;

عرف الوسائط_كلها(): متجه نص {
    دع الكل: متغير متجه نص = [];
    لكل (دع ع: متغير طبيعي = 0; ع < عدد_الوسائط(); ع := ع + 1) {
        طابق وسيطة(ع) مع
        | اختياري.موجود(النص) -> { ألحق(الكل, النص); }
        | اختياري.لا_شيء -> { };
    }
    أرجع الكل;
}

عرف طُلب_تجاهل_الحالة(): منطقي {
    طابق متغير_بيئة(&"IGNORE_CASE") مع
    | نتيجة.نجح(اختياري.موجود(_)) -> { أرجع صواب; }
    | نتيجة.نجح(اختياري.لا_شيء) -> { أرجع خطأ; }
    | نتيجة.خطأ(_) -> { أرجع خطأ; };
}

عرف شغل(الإعدادات: &إعدادات): نتيجة عدد, نص {
    دع المحتوى: نص;
    طابق اقرأ_الملف(&الإعدادات.مسار_الملف) مع
    | نتيجة.نجح(النص) -> { المحتوى := النص; }
    | نتيجة.خطأ(_) -> { أرجع نتيجة.خطأ(صل_نصين(&"تعذرت قراءة ", &الإعدادات.مسار_الملف)); };
    دع الموجود: متجه نص;
    إذا (الإعدادات.تجاهل_الحالة) {
        الموجود := ابحث_دون_مراعاة_الحالة(&الإعدادات.المطلوب, &المحتوى);
    } وإلا {
        الموجود := ابحث(&الإعدادات.المطلوب, &المحتوى);
    };
    لكل (دع ع: متغير عدد = 0; ع < الطول(الموجود); ع := ع + 1) {
        اطبع_سطر(الموجود[ع]);
    }
    أرجع نتيجة.نجح(0);
}

عرف الرئيسية(): عدد {
    دع الوسائط: متجه نص = الوسائط_كلها();
    دع الإعدادات: إعدادات;
    طابق ابن_الإعدادات(&الوسائط, طُلب_تجاهل_الحالة()) مع
    | نتيجة.نجح(المبنية) -> { الإعدادات := المبنية; }
    | نتيجة.خطأ(الرسالة) -> {
        اطبع_سطر_خطأ(الرسالة);
        أرجع 2;
    };
    طابق شغل(&الإعدادات) مع
    | نتيجة.نجح(_) -> { أرجع 0; }
    | نتيجة.خطأ(الرسالة) -> {
        اطبع_سطر_خطأ(الرسالة);
        أرجع 1;
    };
}
```

```console
$ supax run -- الحجر missing.txt > found.txt
تعذرت قراءة missing.txt
$ cat found.txt
$ supax run -- الحجر poem.txt > found.txt
$ cat found.txt
النهر لا يسأل الحجر
اسأل الحجر، فلن يقول شيئا.
```

صار الخطأ يظهر على الشاشة ويبقى الملف فارغا، والنتائج تذهب إلى الملف.

## الخلاصة

استخدم هذا الفصل أفكارا من الكتاب كله حتى الآن: السجلات، و `نتيجة`، والملكية، والوحدات، والاختبارات، ووحدات النصوص والملفات
والعمليات والبيئة في المكتبة القياسية. وعرض بنية تصلح لأغلب برامج سطر الأوامر:

- تعمل المكتبة العمل، في دوال تأخذ قيما وترجع قيما، وتُختبر؛
- وتجمع `الرئيسية` المدخلات، وتستدعي المكتبة، وتحوّل الأخطاء إلى رسائل في الخطأ القياسي وحالة خروج؛
- وكل دالة قد تفشل ترجع `نتيجة`، وتُعالج الإخفاقات في مكان واحد.

ويجعل الفصل التالي الخرج يظهر كما ينبغي: أعداد بعدد محدد من الأرقام، وأعمدة متحاذية، ونص مبني من قالب.
