# إعادة الهيكلة لتحسين التقسيم ومعالجة الأخطاء

في القائمة 12-2 أربعة أشياء ستعيق نمو البرنامج:

1. `الرئيسية` تفعل العمل كله. وقراءة الوسائط وقراءة الملف والطباعة أعمال منفصلة، والدالة التي تعمل عملا واحدا أسهل في القراءة
   والتغيير.
2. `المطلوب` و `مسار_الملف` متغيران منفصلان، مع أنهما إعدادات البرنامج وينتميان إلى بعضهما.
3. يُعالج كل فشل في مكانه، برسالته و `أرجع` الخاصة به، وسط العمل.
4. لا شيء يمكن اختباره: فلا يستدعي الاختبار `الرئيسية`، وهي تقرأ سطر الأوامر الحقيقي.

والبنية المعتادة لبرنامج سطر الأوامر تعالج الأربعة:

- يعيش العمل في **مكتبة**، في دوال تأخذ قيما وترجع قيما، فتستدعيها الاختبارات؛
- وتبقى `الرئيسية` صغيرة: تجمع الوسائط، وتستدعي المكتبة، وتحوّل الأخطاء إلى رسائل وحالات خروج.

## سجل للإعدادات

تصير الإعدادات سجلا، تبنيه دالة تفحص الوسائط وترجع `نتيجة`. ويذهب في المكتبة، في الملف `src/search.sn`:

<sub>القائمة 12-3: الإعدادات وفحصها. الملف: src/search.sn</sub>

```sultan ignore
عام نوع إعدادات = { المطلوب: نص, مسار_الملف: نص };

عام عرف ابن_الإعدادات(الوسائط: &متجه نص): نتيجة إعدادات, نص {
    إذا (الطول(*الوسائط) < 3) {
        أرجع نتيجة.خطأ("الاستخدام: باحث المطلوب الملف");
    };
    دع الإعدادات: إعدادات = { المطلوب: استنسخ(&(*الوسائط)[1]), مسار_الملف: استنسخ(&(*الوسائط)[2]) };
    أرجع نتيجة.نجح(الإعدادات);
}
```

تأخذ `ابن_الإعدادات` الوسائط متجه نصوص مستعارا، فيستطيع الاختبار أن يمرر أي متجه يريد. وتنسخ النصين اللذين تحتاجهما بـ
`استنسخ`، لأن المتجه ملك المستدعي.

اجعل `src` مكتبة في `Supax.toml`، وأعطها ملف جذر يسمّي الوحدة بالعربية ويستوردها، كما في الفصلين السابع والحادي عشر:

<sub>الملف: Supax.toml</sub>

```toml
[package]
name = "باحث"
version = "0.1.0"

[lib]
path = "src"

[dependencies]
```

<sub>الملف: src/باحث.sn</sub>

```sultan ignore
وحدة search { ar: البحث };

استورد باحث.البحث;
```

## `الرئيسية` صغيرة

صارت لـ `الرئيسية` ثلاث خطوات: جمع الوسائط في متجه، وبناء الإعدادات، والتشغيل. وترجع `شغل` قيمة `نتيجة` أيضا، فتعالج
`الرئيسية` كل فشل في مكان واحد، في النهاية:

<sub>القائمة 12-4: `الرئيسية` بعد إعادة الهيكلة. الملف: src/main.sn</sub>

```sultan ignore
استورد المكتبة.دخ.اطبع_سطر;
استورد المكتبة.عمليات.وسيطة;
استورد المكتبة.عمليات.عدد_الوسائط;
استورد المكتبة.ملفات.قراءة_ملف;
استورد المكتبة.نصوص.تحويل;
استورد باحث.البحث;

عرف الوسائط_كلها(): متجه نص {
    دع الكل: متغير متجه نص = [];
    لكل (دع ع: متغير طبيعي = 0; ع < عدد_الوسائط(); ع := ع + 1) {
        طابق وسيطة(ع) مع
        | اختياري.موجود(النص) -> { ألحق(الكل, النص); }
        | اختياري.لا_شيء -> { };
    }
    أرجع الكل;
}

عرف شغل(الإعدادات: &إعدادات): نتيجة عدد, نص {
    طابق اقرأ_الملف(&(*الإعدادات).مسار_الملف) مع
    | نتيجة.نجح(المحتوى) -> {
        اطبع_سطر(المحتوى);
        أرجع نتيجة.نجح(0);
    }
    | نتيجة.خطأ(_) -> { أرجع نتيجة.خطأ(صل_نصين(&"تعذرت قراءة ", &(*الإعدادات).مسار_الملف)); };
}

عرف الرئيسية(): عدد {
    دع الوسائط: متجه نص = الوسائط_كلها();
    دع الإعدادات: إعدادات;
    طابق ابن_الإعدادات(&الوسائط) مع
    | نتيجة.نجح(المبنية) -> { الإعدادات := المبنية; }
    | نتيجة.خطأ(الرسالة) -> {
        اطبع_سطر(الرسالة);
        أرجع 2;
    };
    طابق شغل(&الإعدادات) مع
    | نتيجة.نجح(_) -> { أرجع 0; }
    | نتيجة.خطأ(الرسالة) -> {
        اطبع_سطر(الرسالة);
        أرجع 1;
    };
}
```

تقرأ `شغل` الملف في `المحتوى`، وترجع خطأ برسالة حين لا تستطيع. وهي تطبع النص كله الآن، ويجعلها القسم التالي تبحث.

يفعل البرنامج ما كان يفعله بالضبط، لكن صار لكل جزء عمل واحد، والجزء الأهم، البحث، سيعيش حيث تصل إليه الاختبارات.
