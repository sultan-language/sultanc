# تنسيق الخرج

وصل النصوص بـ `صل_نصين` و`عدد_إلى_نص` يعمل، كما فعل الفصل الثاني عشر، لكن السطر الذي يمزج الكلمات بالأعداد أسهل كتابة
في قالب واحد فيه مواضع للقيم. وتقدم `المكتبة.تنسيق` هذه القوالب، وتسمى *سلاسل التنسيق* (format strings). وهي تتحكم أيضا في
شكل الخرج: عدد محدد من الأرقام، وأعمدة متحاذية، وأعداد بالنظام الست عشري.

## أول سلسلة تنسيق

```sultan
استورد المكتبة.تنسيق.تنسيق;
استورد المكتبة.دخ.اطبع_منسقا;

عرف الرئيسية(): عدد {
    ليكن الاسم: نص = "سلطان";
    اطبع_سطرا_منسقا("أهلا يا {}! لديك {} رسائل.", [قيمة_تنسيق.نص(&الاسم), قيمة_تنسيق.عدد(3)]);
    أرجع 0;
}
```

```text
أهلا يا سلطان! لديك 3 رسائل.
```

كل `{}` موضع تملؤه الوسيطة التالية. وتُعطى الوسائط متجها، وكل منها يقول نوع قيمته:

| الوسيطة | لقيمة من النوع |
| --- | --- |
| `قيمة_تنسيق.عدد(س)`، `قيمة_تنسيق.طبيعي(س)` | `عدد`، `طبيعي` |
| `قيمة_تنسيق.ص8(س)` … `قيمة_تنسيق.ط64(س)` | الأعداد الصحيحة ذات الأحجام المحددة |
| `قيمة_تنسيق.ع64(س)`، `قيمة_تنسيق.ع32(س)` | الأعداد العائمة |
| `قيمة_تنسيق.منطقي(س)`، `قيمة_تنسيق.حرف(س)` | `منطقي`، `حرف` |
| `قيمة_تنسيق.نص(&س)` | `نص` (مستعار) |
| `قيمة_تنسيق.أعداد(&م)`، `قيمة_تنسيق.نصوص(&م)` | `متجه عدد`، `متجه نص` |

تطبع `اطبع_سطرا_منسقا` الناتج وسطرا جديدا، وتطبع `اطبع_منسقا` دون السطر الجديد. وكلتاهما من `المكتبة.دخ.اطبع_منسقا`،
وأنواع الوسائط من `المكتبة.تنسيق.تنسيق`.

## المترجم يفحص سلسلة التنسيق

حين تكون سلسلة التنسيق مكتوبة في الشيفرة يفحصها المترجم مقابل الوسائط. فالموضع الذي لا وسيطة له لا يُترجَم:

```sultan fail
استورد المكتبة.تنسيق.تنسيق;
استورد المكتبة.دخ.اطبع_منسقا;

عرف الرئيسية(): عدد {
    اطبع_سطرا_منسقا("{} {}", [قيمة_تنسيق.عدد(1)]);
    أرجع 0;
}
```

```text
خطأ[SULTANC-FORMAT-STRING]: سلسلة تنسيق غير صالحة — موضع وسيط التنسيق بدءا من الصفر هو 1. تشير سلسلة التنسيق إلى وسيط لا يمرره النداء.
  --> main.sn:5:25..5:26
   |
 5 |     اطبع_سطرا_منسقا("{} {}", [قيمة_تنسيق.عدد(1)]);
   |                         ^
   |
```

## العرض والمحاذاة والتعبئة

بعد `:` داخل المعقوفين تأتي المواصفة. فالعدد هو العرض الأدنى، و`<` و`^` و`>` تحاذي يسارا ووسطا ويمينا، والمحرف قبل
المحاذاة يملأ الفراغ:

```sultan
استورد المكتبة.تنسيق.تنسيق;
استورد المكتبة.دخ.اطبع_منسقا;

عرف الرئيسية(): عدد {
    ليكن الاسم: نص = "سلطان";
    اطبع_سطرا_منسقا("[{:<10}]", [قيمة_تنسيق.نص(&الاسم)]);
    اطبع_سطرا_منسقا("[{:^10}]", [قيمة_تنسيق.نص(&الاسم)]);
    اطبع_سطرا_منسقا("[{:>10}]", [قيمة_تنسيق.نص(&الاسم)]);
    اطبع_سطرا_منسقا("[{:*^10}]", [قيمة_تنسيق.نص(&الاسم)]);
    أرجع 0;
}
```

```text
[سلطان     ]
[  سلطان   ]
[     سلطان]
[**سلطان***]
```

وبهذا تطبع جداول تصطف أعمدتها. والعرض يُعدّ بالمحارف لا بالبايتات، فيصطف النص العربي كما يصطف اللاتيني:

```sultan
استورد المكتبة.تنسيق.تنسيق;
استورد المكتبة.دخ.اطبع_منسقا;

نوع صنف = { الاسم: نص, السعر: عدد };

عرف الرئيسية(): عدد {
    ليكن الأصناف: متجه صنف = [
        { الاسم: "شاي", السعر: 12 },
        { الاسم: "تمر", السعر: 45 },
        { الاسم: "قهوة", السعر: 30 }
    ];
    لكل (ليكن ع: متغير عدد = 0; ع < الطول(الأصناف); ع := ع + 1) {
        اطبع_سطرا_منسقا("{:<8}{:>5}", [قيمة_تنسيق.نص(&الأصناف[ع].الاسم), قيمة_تنسيق.عدد(الأصناف[ع].السعر)]);
    }
    أرجع 0;
}
```

```text
شاي        12
تمر        45
قهوة       30
```

## الأعداد

| المواصفة | أثرها | `42` تعطي |
| --- | --- | --- |
| `{:+}` | تُظهر الإشارة دائما | `+42` |
| `{:05}` | تملأ بالأصفار حتى العرض 5 | `00042` |
| `{:x}`، `{:X}` | ست عشري | `2a`، `2A` |
| `{:#x}` | ست عشري مع `0x` | `0x2a` |
| `{:b}`، `{:o}` | ثنائي، ثماني | `101010`، `52` |

وفي الأعداد العائمة يحدد `.N` عدد الأرقام بعد الفاصلة، ويستخدم `e` الصيغة الأسية:

```sultan
استورد المكتبة.تنسيق.تنسيق;
استورد المكتبة.دخ.اطبع_منسقا;

عرف الرئيسية(): عدد {
    اطبع_سطرا_منسقا("{:.2}", [قيمة_تنسيق.ع64(3.14159)]);
    اطبع_سطرا_منسقا("{:8.3}|", [قيمة_تنسيق.ع64(2.5)]);
    اطبع_سطرا_منسقا("{:e}", [قيمة_تنسيق.ع64(1234.5)]);
    اطبع_سطرا_منسقا("{:+} {:05} {:#x}", [قيمة_تنسيق.عدد(42), قيمة_تنسيق.عدد(42), قيمة_تنسيق.عدد(42)]);
    أرجع 0;
}
```

```text
3.14
   2.500|
1.2345e3
+42 00042 0x2a
```

## المواضع والمعقوفات

تسمي `{0}` و`{1}`… الوسيطة بموضعها، فتُستخدم الوسيطة الواحدة مرتين. وتطبع `{{` و`}}` معقوفين حرفيين:

```sultan
استورد المكتبة.تنسيق.تنسيق;
استورد المكتبة.دخ.اطبع_منسقا;

عرف الرئيسية(): عدد {
    ليكن الاسم: نص = "نور";
    اطبع_سطرا_منسقا("{0} ثم {0} مرة أخرى؛ {{معقوفان}}", [قيمة_تنسيق.نص(&الاسم)]);
    أرجع 0;
}
```

```text
نور ثم نور مرة أخرى؛ {معقوفان}
```

## التنسيق دون طباعة

ترجع `نسق` النص بدل طباعته، في `نتيجة`: فسلسلة التنسيق المبنية أثناء التشغيل لا تُفحص إلا حينها، والخطأ فيها قيمة خطأ
لا انهيار.

```sultan
استورد المكتبة.تنسيق.تنسيق;
استورد المكتبة.دخ.اطبع_سطر;

عرف الرئيسية(): عدد {
    طابق نسق("{:>6}|", [قيمة_تنسيق.عدد(42)]) مع
    | نتيجة.نجح(النص) -> { اطبع_سطر(النص); }
    | نتيجة.خطأ(_) -> { اطبع_سطر("سلسلة تنسيق خاطئة"); };
    أرجع 0;
}
```

```text
    42|
```

وتحدد صفحة [التنسيق](../reference/formatting.md) في المرجع كل خيار، ومنها المنسقات المخصصة لأنواعك.

## الخلاصة

- تطبع `اطبع_سطرا_منسقا("… {} …", [قيمة_تنسيق.عدد(س), …])` قالبا ملئت مواضعه.
- تُغلَّف كل وسيطة بنوعها: `قيمة_تنسيق.عدد`، و`قيمة_تنسيق.نص(&ن)`، و`قيمة_تنسيق.ع64`….
- تُفحص سلسلة التنسيق المكتوبة في الشيفرة وقت الترجمة.
- تحاذي `{:<10}` و`{:^10}` و`{:>10}`، وتشكّل `{:05}` و`{:x}` و`{:.2}` الأعداد.
- ترجع `نسق` النص في `نتيجة`.
