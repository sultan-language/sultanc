# الاعتماديات

*الاعتمادية* (dependency) حزمة أخرى تستخدم حزمتك مكتبتها. وتُسرد الاعتماديات في القسم `[dependencies]` من `Supax.toml`، وتأتي
من أحد ثلاثة أماكن.

## حزمة في مجلد

أبسط مصدر مجلد على قرصك: حزمة تكتبها بجوار هذه. وهذه حزمة مكتبة صغيرة، `تحية`، فيها وحدة واحدة:

<sub>الملف: ../تحية/src/words.sn</sub>

```sultan ignore
استورد المكتبة.نصوص.تحويل;

عام عرف أهلا(الاسم: &نص): نص {
    أرجع صل_ثلاثة_نصوص(&"أهلا يا ", الاسم, &"!");
}
```

في بيانها `[lib] path = "src"`، وملف جذرها `src/تحية.sn` يسمّي الوحدة ويستوردها، كما في الفصل الحادي عشر:

```sultan ignore
وحدة words { ar: الكلمات };

استورد تحية.الكلمات;
```

وتضيفها حزمة ثانية، `تطبيق`، بـ `supax add`:

```console
$ supax add تحية --path ../تحية
        أضاف "تحية" = { path = "../تحية" }
```

كتب `supax add` الاعتمادية في `Supax.toml`:

```toml
[dependencies]
"تحية" = { path = "../تحية" }
```

ويستورد `تطبيق` الوحدة باسمها الكامل، الذي يبدأ باسم الحزمة:

<sub>الملف: src/main.sn</sub>

```sultan ignore
استورد المكتبة.دخ.اطبع_سطر;
استورد تحية.الكلمات;

عرف الرئيسية(): عدد {
    اطبع_سطر(أهلا(&"نور"));
    أرجع 0;
}
```

```console
$ supax run
        يبني تطبيق v0.1.0 (/projects/تطبيق)
       انتهى في 0.16 ث → build/bin/تطبيق
       يشغّل build/bin/تطبيق
أهلا يا نور!
```

## حزمة من الفهرس

تُسرد الحزم المنشورة في *فهرس الحزم* (package index)، وهو مستودع git في `https://github.com/sultan-language/index`. وكل
إصدار فيه يشير إلى commit في مستودع الحزمة نفسها، وإلى بصمة (checksum) لمحتواها. ويبحث `supax add الاسم@الإصدار` عن الحزمة
ويضيفها، وبدون `@الإصدار` يأخذ أحدث إصدار:

```console
$ supax add nahr@0.1.0-dev
        يجلب https://github.com/sultan-language/index
        أضاف nahr = "0.1.0-dev"
```

ونهر إطار ويب مكتوب بالسلطان، وصارت وحداته تُستورد بـ `nahr.…`.

والإصدار في `Supax.toml` *متطلب* (requirement)، لا إصدار واحد بعينه. فـ `"1.2"` تعني أي إصدار من 1.2.0 إلى ما قبل 2.0.0: أي
الإصدارات التي تضيف ميزات وتصلح أخطاء دون أن تكسر شيفرة كُتبت لـ 1.2، بقواعد *الإصدار الدلالي* (semantic versioning).

## حزمة من git

الحزمة غير الموجودة في الفهرس يمكن أن تأتي مباشرة من مستودع git الخاص بها، عند وسم (tag) أو commit:

```toml
[dependencies]
json = { git = "https://github.com/someone/sn-json", tag = "v1.2.0" }
```

ويكتب `supax add json --git الرابط --tag v1.2.0` السطر نفسه.

## عرض الاعتماديات

يعرض `supax tree` ما تعتمد عليه الحزمة، ومنه اعتماديات الاعتماديات:

```console
$ supax tree
تطبيق v0.1.0
  - تحية v0.2.0 (../تحية)
```

ويحذف `supax remove الاسم` الاعتمادية من جديد.

## عدة حزم في مستودع واحد

كثيرا ما يكون في المشروع الكبير عدة حزم يعتمد بعضها على بعض: مكتبة، وبرنامج، وأداة. و*مساحة العمل* (workspace) تحفظها في مستودع
واحد، بملف قفل واحد ومجلد `build` واحد. ويسرد `Supax.toml` في جذرها الأعضاء:

```toml
[workspace]
members = ["app", "libs/*"]
```

و `"libs/*"` تعني كل مجلد تحت `libs` فيه `Supax.toml`. والأوامر التي تُشغَّل في الجذر تعمل على كل الأعضاء، و `-p الاسم` تختار
واحدا.
