# أ. الكلمات المفتاحية بالعربية والإنجليزية

الكلمات المفتاحية محجوزة: فلا تُسمّى بها المتغيرات ولا الدوال ولا الأنواع. ولكل منها كتابة عربية وكتابة إنجليزية بالمعنى نفسه
تماما، ويجوز للبرنامج أن يستخدم أيهما، وأن يخلط بينهما. وهذه القائمة هي قائمة المترجم نفسه
(`tools/generate/registry/token_registry.def`).

| العربية | الإنجليزية | المعنى |
| --- | --- | --- |
| `وقت_الترجمة` | `comptime` | يقيّم تعبيرا أو كتلة أثناء الترجمة |
| `دالة` | `fn` | نوع دالة، أو دالة مجهولة |
| `بنوع` | `of` | القيمة التي تحملها حالة التعداد |
| `من` | `from` | الاستيراد الانتقائي: `من مجلد استورد أسماء` |
| `خارجي` | `extern` | دالة أو قيمة معرّفة خارج السلطان |
| `استورد` | `import` | يستورد وحدة |
| `وحدة` | `module` | يصرّح بكتابات وحدة في ملف الجذر |
| `استخدم` | `use` | محجوزة |
| `مثل` | `as` | يحوّل نوع عدد، ويسمّي استيرادا |
| `غير_معرف` | `undefined` | محجوزة |
| `عرف` | `def` | يعرّف دالة |
| `مرادف` | `alias` | يصرّح باسم آخر لتصريح |
| `ليكن` | `let` | يصرّح بمتغير أو ثابت |
| `أرجع` | `return` | ينهي الدالة ويرجع قيمة |
| `وإلا` | `else` | فرع `إذا` الذي يُنفَّذ فيما عدا ذلك |
| `إذا` | `if` | ينفّذ كتلة حين يصح شرط |
| `أي` | `any` | نوع مبني: أي نوع |
| `منطقي` | `bool` | نوع مبني: صواب أو خطأ |
| `نص` | `string` | نوع مبني: نص UTF-8 |
| `حرف` | `char` | نوع مبني: محرف يونيكود واحد |
| `عدد` | `int` | نوع مبني: عدد صحيح بإشارة، 64 بت |
| `طبيعي` | `uint` | نوع مبني: عدد صحيح بلا إشارة، 64 بت |
| `عدد_عائم` | `float` | نوع مبني: عدد عائم |
| `فراغ` | `void` | نوع مبني: لا قيمة |
| `تجميع` | `asm` | شيفرة تجميع مضمّنة |
| `غير_آمن` | `unsafe` | كتلة تُسمح فيها عمليات الذاكرة الخام |
| `طالما` | `while` | يكرر كتلة ما دام شرط صحيحا |
| `لكل` | `for` | حلقة عدّ |
| `اخرج_من_حلقة` | `break` | يخرج من الحلقة |
| `تابع_حلقة` | `continue` | يبدأ الدورة التالية من الحلقة |
| `نوع` | `type` | يصرّح بنوع: سجل أو تعداد أو اسم آخر أو نوع معتم |
| `طابق` | `match` | يختار فرعا بالنمط |
| `مع` | `with` | تتبع القيمة في `طابق القيمة مع` |
| `متغير` | `mutable` | يسمح بتغيير متغير أو معامل أو مرجع |
| `عام` | `public` | يجعل التصريح مرئيا خارج وحدته |
| `شريحة` | `slice` | نظرة مستعارة إلى جزء من سلسلة |
| `صندوق` | `box` | قيمة مخزّنة في الكومة |
| `صواب` | `true` | القيمة المنطقية صواب |
| `خطأ` | `false` | القيمة المنطقية خطأ |

## كلمات لها معنى في سياقها

هذه ليست محجوزة، لكن لها معنى حيث تظهر:

| العربية | الإنجليزية | المعنى |
| --- | --- | --- |
| `اختياري` | `option` | قيمة أو لا شيء |
| `نتيجة` | `result` | قيمة أو خطأ |
| `متجه` | `vector` | سلسلة قابلة للنمو |
| `الرئيسية` | `main` | الدالة التي يبدأ منها البرنامج |
| `مدى أ..ب` | `range a..b` | مجال قيم في نمط (`مدى 1..9`) |
| `بقية` | `rest` | سائر العناصر في نمط المتجه (`[الأول، بقية الذيل]`) |
| `@@اختبار` | `@@test` | يعلّم دالة اختبار |
| `معتم` | `opaque` | نوع معروف باسمه فقط، يُستخدم عبر المؤشرات |

وأسماء المكتبة القياسية لها كتابتان أيضا: `اطبع_سطر` و `println` دالة واحدة، و `المكتبة.دخ` و `std.io` وحدة واحدة. وتسرد
[المصطلحات العربية](../reference/arabic-terminology.md) في المرجع المفردات المعتمدة.
