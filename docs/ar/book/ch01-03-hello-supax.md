# أهلا يا سوباكس!

يكفي `sultanc` لملف واحد. أما البرامج الحقيقية ففيها ملفات كثيرة، واختبارات، وحزم كتبها غيرك. وسوباكس يدير كل ذلك، ويستخدمه
باقي هذا الكتاب.

## إنشاء مشروع

ارجع إلى مجلد `projects` وأنشئ مشروعا جديدا:

```console
$ cd ..
$ supax new مرحبا_سوباكس
أُنشئت الحزمة "مرحبا_سوباكس"
$ cd مرحبا_سوباكس
```

يكتب سوباكس رسائله وبرنامج البداية بالعربية افتراضيا. وللإنجليزية أضف `--lang=en` إلى الأمر، أو اضبط متغير البيئة
`SUPAX_LANG=en` مرة واحدة لكل الأوامر.

أنشأ سوباكس مجلدا فيه ثلاثة ملفات:

```text
مرحبا_سوباكس/
├── .gitignore
├── Supax.toml
└── src/
    └── main.sn
```

<sub>الملف: Supax.toml</sub>

```toml
[package]
name = "مرحبا_سوباكس"
version = "0.1.0"

[dependencies]
```

يصف `Supax.toml` المشروع، وهو مكتوب بصيغة TOML، وهي صيغة بسيطة للإعدادات. يحدد `[package]` اسم المشروع وإصداره، ويسرد
`[dependencies]` الحزم التي يستخدمها المشروع، ولا شيء فيه بعد.

<sub>الملف: src/main.sn</sub>

```sultan
استورد المكتبة.دخ.اطبع_سطر;

عرف الرئيسية(): عدد {
    اطبع_سطر("مرحبا من السلطان");
    أرجع 0;
}
```

```text
مرحبا من السلطان
```

تكون الشيفرة في `src`، ويبقى في مجلد المشروع الإعدادات وكل ما ليس شيفرة.

وفي `.gitignore` سطر واحد هو `build/`، حتى لا يخزّن Git الملفات التي ينتجها البناء.

## البناء والتشغيل

```console
$ supax build
        يبني مرحبا_سوباكس v0.1.0 (/projects/مرحبا_سوباكس)
       انتهى في 0.12 ث → build/bin/مرحبا_سوباكس
$ ./build/bin/مرحبا_سوباكس
مرحبا من السلطان
```

يترجم `supax build` المشروع، ويضع البرنامج في `build/bin` باسم المشروع. ويبني `supax run` ويشغّل في خطوة واحدة:

```console
$ supax run
        يبني مرحبا_سوباكس v0.1.0 (/projects/مرحبا_سوباكس)
       انتهى في 0.12 ث → build/bin/مرحبا_سوباكس
       يشغّل build/bin/مرحبا_سوباكس
مرحبا من السلطان
```

ويفحص `supax check` البرنامج دون أن ينتج شيئا، وهو أسرع أثناء الكتابة:

```console
$ supax check
        يفحص مرحبا_سوباكس v0.1.0 (/projects/مرحبا_سوباكس)
       انتهى في 0.04 ث
```

## الخلاصة

- يبني `./build.sh` المترجم من الـ seed الذي في المستودع، ويضع `tools/install.sh` في سوباكس الأمرين `sultanc` و `supax`
  في الـ `PATH`.
- يبدأ البرنامج من `الرئيسية`، والعدد الذي ترجعه هو حالة الخروج.
- يجعل `استورد` أسماء وحدة من المكتبة القياسية متاحة، وكل جملة تنتهي بـ `;`.
- تذكر رسالة الخطأ هويتها وموضعها، وكثيرا ما تذكر الإصلاح.
- يترجم `sultanc file.sn -o name`، ويشغّل `sultanc run file.sn` دون ملف.
- تدير الأوامر `supax new` و `supax build` و `supax run` و `supax check` المشروع.

وفي الفصل التالي تكتب برنامجا كاملا: لعبة.
