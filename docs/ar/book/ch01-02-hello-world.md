# أهلا يا عالم!

أنشئ مجلدا لبرامج هذا الكتاب، وداخله مجلدا لهذا البرنامج:

```console
$ mkdir -p projects/hello_world
$ cd projects/hello_world
```

أنشئ ملفا اسمه `main.sn`، فملفات السلطان تنتهي بـ `.sn`. واكتب فيه هذا البرنامج:

<sub>الملف: main.sn</sub>

```sultan
استورد المكتبة.دخ.اطبع_سطر;

عرف الرئيسية(): عدد {
    اطبع_سطر("أهلا يا عالم!");
    أرجع 0;
}
```

ترجمه، ثم شغّل البرنامج الذي أنتجه المترجم:

```console
$ sultanc main.sn -o hello
$ ./hello
```

```text
أهلا يا عالم!
```

وفي ويندوز سمِّ البرنامج `hello.exe` وشغّله بـ `.\hello.exe`.

إن ظهرت لك `أهلا يا عالم!` فقد كتبت أول برنامج بالسلطان وشغّلته.

## أجزاء البرنامج

```sultan ignore
عرف الرئيسية(): عدد {

}
```

هذا تعريف دالة اسمها `الرئيسية`. تبدأ `عرف` تعريف الدالة. والقوسان الفارغان يعنيان أن الدالة لا تأخذ مدخلات. و `: عدد`
يحدد ما ترجعه الدالة: قيمة من النوع `عدد`، أي عدد صحيح. وجسم الدالة بين القوسين `{` و `}`.

و `الرئيسية` دالة خاصة: منها يبدأ كل برنامج. وحين تنتهي، يصير العدد الذي ترجعه حالة الخروج للبرنامج (exit status). وبها
يخبر البرنامج النظام الذي شغّله هل نجح أم لا: 0 يعني النجاح، وأي عدد آخر يعني أن شيئا لم يتم كما ينبغي.

```sultan ignore
    اطبع_سطر("أهلا يا عالم!");
```

يستدعي هذا السطر الدالة `اطبع_سطر`، التي تطبع نصا ثم سطرا جديدا. والنص هنا نص حرفي (string literal): محارف بين علامتي
تنصيص مزدوجتين. وينتهي السطر بفاصلة منقوطة `;`، فكل جملة في السلطان تنتهي بها.

```sultan ignore
    أرجع 0;
```

تنهي `أرجع` الدالة وترجع قيمة، وهي هنا 0: نجح البرنامج.

```sultan ignore
استورد المكتبة.دخ.اطبع_سطر;
```

ليست `اطبع_سطر` جزءا من اللغة نفسها، بل من المكتبة القياسية `المكتبة`، وهي مجموعة الوحدات التي تأتي مع المترجم. و
`المكتبة.دخ.اطبع_سطر` هي الوحدة التي تقدّمها، و `دخ` تجمع الإدخال والإخراج. وسطر `استورد` يجعل الأسماء العامة في وحدة ما
متاحة في ملفك. وكل برنامج في هذا الكتاب يبدأ بما يحتاجه من استيراد.

## حين يكون في البرنامج خطأ

يفحص المترجم البرنامج كله قبل أن ينتج أي شيء. وإذا وجد خطأ ذكر ما هو، وأين هو، وكثيرا ما يذكر طريقة إصلاحه. احذف
الفاصلة المنقوطة بعد `اطبع_سطر(…)` وترجم من جديد:

```sultan fail
استورد المكتبة.دخ.اطبع_سطر;

عرف الرئيسية(): عدد {
    اطبع_سطر("أهلا يا عالم!")
    أرجع 0;
}
```

```text
خطأ[SULTANC-PARSE-SYNTAX]: خطأ نحوي: المتوقع ⁨`;`⁩، الموجود ⁨`أرجع`⁩ — كان المحلل النحوي يتوقع رمزًا مختلفًا في هذا الموضع.
  --> main.sn:4:30
   |
 4 |     اطبع_سطر("أهلا يا عالم!")
   |                              ^ الموضع المتوقع
   |
  ::: main.sn:5:5..5:9
   |
 5 |     أرجع 0;
   |     ^^^^ اكتشف المحلل المشكلة هنا
   |
  = مساعدة: أضف ⁨`;`⁩ بعد هذا التركيب
```

لكل رسالة الأجزاء نفسها:

- `خطأ`، وبين القوسين المربعين هوية الرسالة `SULTANC-PARSE-SYNTAX`. والهوية ثابتة لا تتغير، فيمكنك البحث بها، ويشرحها
  الأمر `sultanc explain SULTANC-PARSE-SYNTAX`.
- وصف الخطأ، ثم شرطة وشرح أطول.
- `-->` والموضع: الملف والسطر والعمود. فـ `main.sn:4:30` هو السطر 4، العمود 30.
- سطر الشيفرة نفسه، و `^` تحت الموضع بالضبط.
- وأحيانا موضع ثان بعد `:::`، وهو هنا حيث لاحظ المترجم المشكلة: فلم يعرف أن الفاصلة المنقوطة ناقصة إلا حين وصل إلى
  `أرجع`.
- و `مساعدة`، حين يعرف المترجم الإصلاح.

أعد الفاصلة المنقوطة، واحذف سطر `استورد` بدلا منها:

```sultan fail
عرف الرئيسية(): عدد {
    اطبع_سطر("أهلا يا عالم!");
    أرجع 0;
}
```

```text
خطأ[SULTANC-NAME-UNKNOWN]: الاسم ⁨`اطبع_سطر`⁩ غير معروف — الاسم المطلوب مفقود أثناء حل المراجع.
  --> main.sn:2:5..2:13
   |
 2 |     اطبع_سطر("أهلا يا عالم!");
   |     ^^^^^^^^
   |
```

بدون الاستيراد، `اطبع_سطر` اسم لا يعرفه المترجم. و `2:5..2:13` مدى: من السطر 2 العمود 5، إلى السطر 2 العمود 13.

ويكتب المترجم رسائله بالعربية افتراضيا. وللإنجليزية أضف `--lang=en`.

## الترجمة والتشغيل خطوتان

أنتج `sultanc main.sn -o hello` ملفا اسمه `hello` يعمل وحده. ويمكنك إعطاؤه لمن لم يثبّت السلطان، فيعمل على جهازه إن كان
بنظام التشغيل والمعالج نفسيهما. وهذا معنى الترجمة المسبقة (ahead-of-time compilation): يتم الفحص والتحويل كله مرة واحدة،
قبل أن يعمل البرنامج.

ولتجربة برنامج دون إنتاج ملف، استخدم `sultanc run`:

```console
$ sultanc run main.sn
أهلا يا عالم!
```

ينفّذ `sultanc run` البرنامج في مفسِّر المترجم (interpreter). وهو يشغّل البرنامج المفحوص نفسه، فيتصرف كما يتصرف البرنامج
المترجَم.
