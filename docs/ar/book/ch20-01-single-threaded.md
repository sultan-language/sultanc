# خادم بخيط واحد

## بروتوكولان

يعمل الويب على بروتوكولين، أحدهما فوق الآخر. فـ *TCP* ينقل البايتات بين حاسوبين، بموثوقية وبالترتيب: وهو الاتصال. و *HTTP*
يقول ما معنى البايتات: يرسل المتصفح *طلبا* (request)، أسطرا قليلة من النص تسمّي الصفحة التي يريدها، ويرسل الخادم *ردا*
(response): سطر الحالة، وبعض الترويسات، والصفحة نفسها.

يبدأ الطلب بـ *سطر الطلب* مثل هذا، تتبعه ترويسات:

```text
GET / HTTP/1.1
Host: 127.0.0.1:7878
```

`GET` هي الطريقة، و `/` الصفحة المطلوبة، و `HTTP/1.1` إصدار البروتوكول. ويبدو الرد هكذا:

```text
HTTP/1.1 200 OK
Content-Length: 182

<!DOCTYPE html>
...
```

`200 OK` هي الحالة: وُجدت الصفحة. ويقول `Content-Length` كم بايتا في الصفحة. وسطر فارغ ينهي الترويسات، وتتبعه الصفحة. وأسطر
HTTP تنتهي بالمحرفين `\r\n`.

## المشروع

```console
$ supax new hello
$ cd hello
```

ضع صفحتين بجوار `Supax.toml`: واحدة تُخدم، وواحدة للصفحات غير الموجودة.

<sub>الملف: hello.html</sub>

```text
<!DOCTYPE html>
<html lang="ar" dir="rtl">
  <head><meta charset="utf-8"><title>أهلا!</title></head>
  <body><h1>أهلا!</h1><p>تحية من السلطان</p></body>
</html>
```

<sub>الملف: 404.html</sub>

```text
<!DOCTYPE html>
<html lang="ar" dir="rtl">
  <head><meta charset="utf-8"><title>غير موجود</title></head>
  <body><h1>عذرا!</h1><p>لا أعرف ما تطلبه.</p></body>
</html>
```

## الخادم

تحوّل `المكتبة.شبكة.عنوان_مقبس` نصا مثل `"127.0.0.1:7878"` إلى عنوان. وفي `المكتبة.شبكة.تي_سي_بي` الباقي: تبدأ الاستماع على
عنوان، وتنتظر الاتصال التالي وترجعه تدفقا (stream)، وتنقل البايتات قراءة وكتابة، وتنهي الاتصال.

<sub>القائمة 20-1: خادم يجيب اتصالا واحدا في كل مرة. الملف: src/main.sn</sub>

```sultan ignore
استورد المكتبة.دخ.اطبع_سطر;
استورد المكتبة.نصوص.أعداد;
من المكتبة.نصوص استورد صل_نصين, صل_ثلاثة_نصوص, أسطر_النص, قص_النص;
استورد المكتبة.نصوص.من_بايتات;
استورد المكتبة.شبكة.عنوان_مقبس;
استورد المكتبة.شبكة.تي_سي_بي;
استورد المكتبة.ملفات.قراءة_ملف;

عرف عالج_الاتصال(التدفق: تدفق_تي_سي_بي): فراغ {
    دع المخزن: متغير متجه ط8 = [];
    لكل (دع ع: متغير عدد = 0; ع < 1024; ع := ع + 1) {
        ألحق(المخزن, 0 مثل ط8);
    }
    طابق اقرأ_تي_سي_بي(&التدفق, &متغير المخزن, 0, 1024) مع
    | نتيجة.نجح(_) -> { }
    | نتيجة.خطأ(_) -> { أرجع; };
    دع الطلب: نص = من_بايتات(&المخزن);
    دع سطر_الطلب: نص = السطر_الأول(&الطلب);
    اطبع_سطر(سطر_الطلب);

    دع الحالة: نص;
    دع اسم_الملف: نص;
    إذا (سطر_الطلب == "GET / HTTP/1.1") {
        الحالة := "HTTP/1.1 200 OK";
        اسم_الملف := "hello.html";
    } وإلا {
        الحالة := "HTTP/1.1 404 NOT FOUND";
        اسم_الملف := "404.html";
    };
    دع الجسم: نص;
    طابق اقرأ_الملف(&اسم_الملف) مع
    | نتيجة.نجح(النص) -> { الجسم := النص; }
    | نتيجة.خطأ(_) -> { الجسم := ""; };
    دع الرد: نص = صل_ثلاثة_نصوص(
        &صل_نصين(&الحالة, &"\r\n"),
        &صل_ثلاثة_نصوص(&"Content-Length: ", &عدد_إلى_نص(الطول(الجسم)), &"\r\n\r\n"),
        &الجسم
    );
    دع البايتات: متجه ط8 = بايتات_من_نص(الرد);
    طابق اكتب_تي_سي_بي(&التدفق, &البايتات, 0, الطول(البايتات)) مع
    | نتيجة.نجح(_) -> { }
    | نتيجة.خطأ(_) -> { };
    طابق أغلق_تدفق_تي_سي_بي(التدفق) مع
    | نتيجة.نجح(_) -> { }
    | نتيجة.خطأ(_) -> { };
}

عرف السطر_الأول(النص: &نص): نص {
    دع الكل: متجه نص = أسطر_النص(النص);
    إذا (الطول(الكل) == 0) {
        أرجع "";
    };
    أرجع قص_النص(&الكل[0]);
}

عرف الرئيسية(): عدد {
    دع العنوان: عنوان_مقبس;
    طابق حلل_عنوان_مقبس(&"127.0.0.1:7878") مع
    | نتيجة.نجح(ع_م) -> { العنوان := ع_م; }
    | نتيجة.خطأ(_) -> { أرجع 1; };
    دع المستمع: مستمع_تي_سي_بي;
    طابق اربط_مستمع_تي_سي_بي(&العنوان, 128) مع
    | نتيجة.نجح(م) -> { المستمع := م; }
    | نتيجة.خطأ(الرمز) -> { أرجع الرمز; };
    طالما (صواب) {
        طابق اقبل_تي_سي_بي(&المستمع) مع
        | نتيجة.نجح(التدفق) -> { عالج_الاتصال(التدفق); }
        | نتيجة.خطأ(_) -> { };
    }
    أرجع 0;
}
```

اقرأه من `الرئيسية` صعودا:

- تحلل `الرئيسية` العنوان وتبدأ الاستماع. و `127.0.0.1` هو هذا الحاسوب، و 7878 منفذ لا يستخدمه برنامج شائع. و `128` عدد
  الاتصالات التي يجوز أن تنتظر القبول. ثم تقبل الاتصالات إلى الأبد، وتسلّم كلا منها لـ `عالج_الاتصال`.
- تأخذ `عالج_الاتصال` ملكية التدفق. فتقرأ حتى 1024 بايتا من الطلب في مخزن من بايتات صفرية، وتحوّلها إلى نص بـ `من_بايتات`،
  وتحتفظ بالسطر الأول.
- وتختار الحالة والصفحة بسطر الطلب، وتقرأ الصفحة، وتبني الرد مع `Content-Length`. و `الطول(الجسم)` يعدّ البايتات، وهو بالضبط
  ما تحتاجه الترويسة.
- ثم تحوّل الرد إلى بايتات، وتكتبها، وتغلق الاتصال. ولأن `عالج_الاتصال` تملك التدفق، فإغلاقه آخر استخدام له، ولا شيء يستطيع
  استخدام التدفق المغلق بعده.

وتأتي دوال النصوص من سطر واحد، `من المكتبة.نصوص استورد …`، يجلب هذه الأسماء وحدها من وحدات `المكتبة.نصوص`.

## التجربة

```console
$ supax run
```

ينتظر الخادم. افتح `http://127.0.0.1:7878` في المتصفح، أو استخدم `curl` في طرفية أخرى:

```console
$ curl -i http://127.0.0.1:7878/
HTTP/1.1 200 OK
Content-Length: 182

<!DOCTYPE html>
<html lang="ar" dir="rtl">
  <head><meta charset="utf-8"><title>أهلا!</title></head>
  <body><h1>أهلا!</h1><p>تحية من السلطان</p></body>
</html>
$ curl -s -o /dev/null -w '%{http_code}\n' http://127.0.0.1:7878/other
404
```

ويطبع الخادم سطر كل طلب:

```text
GET / HTTP/1.1
GET /other HTTP/1.1
```

واضغط Ctrl-C لإيقافه.
