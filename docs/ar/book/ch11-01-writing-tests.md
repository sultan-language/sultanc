# كيف تكتب اختبارا

## تركيب الاختبار

الاختبار دالة معلّمة بـ `@@اختبار`، لا تأخذ معاملات وترجع `فراغ`. وتفحص ما تتوقعه بـ `تأكد`: فـ*ينجح* الاختبار إن وصل إلى
نهايته، و*يفشل* إن أوقفه تأكيد.

<sub>الملف: calc.sn</sub>

```sultan test
استورد المكتبة.تصحيح.تأكد;

عرف اجمع(أ: عدد, ب: عدد): عدد {
    أرجع أ + ب;
}

@@اختبار
عرف الجمع_يعمل(): فراغ {
    تأكد(اجمع(2, 3) == 5);
    تأكد(اجمع(-1, 1) == 0);
}

@@اختبار
عرف جمع_الصفر_لا_يغير_شيئا(): فراغ {
    تأكد(اجمع(7, 0) == 7);
}

عرف الرئيسية(): عدد {
    أرجع 0;
}
```

يترجم `sultanc test` اختبارات الملف ويشغّلها:

```console
$ sultanc test calc.sn
```

```text
نجح الجمع_يعمل
نجح جمع_الصفر_لا_يغير_شيئا

نتيجة الاختبارات: ناجحة. نجح: 2؛ فشل: 0؛ استُبعد: 0
```

تعيش الاختبارات في الملف نفسه مع الشيفرة التي تفحصها. والبناء العادي، `sultanc calc.sn`، يتركها كليا: فلا تكلّف شيئا في
البرنامج الناتج.

و `@@اختبار` *توصيف* (annotation): كلمة بعد `@@` تخبر المترجم بشيء عن التصريح الذي يليها. وكتابتها الإنجليزية `@@test`.

## حين يفشل اختبار

هذا اختبار بتوقع خاطئ:

```sultan test
استورد المكتبة.تصحيح.تأكد;

عرف اجمع(أ: عدد, ب: عدد): عدد {
    أرجع أ + ب;
}

@@اختبار
عرف الجمع_يعمل(): فراغ {
    تأكد(اجمع(2, 3) == 5);
}

@@اختبار
عرف توقع_خاطئ(): فراغ {
    تأكد(اجمع(2, 2) == 5);
}

عرف الرئيسية(): عدد {
    أرجع 0;
}
```

```text
نجح الجمع_يعمل
فشل توقع_خاطئ: حالة الخروج 1
    --> main.sn:14:5
    ملاحظة: الاختبار مصرح به في main.sn:13:5
    خطأ[SULTANC-RUNTIME-PROGRAM-STOPPED]: توقف البرنامج — فشل تأكيد.

نتيجة الاختبارات: فاشلة. نجح: 1؛ فشل: 1؛ استُبعد: 0
```

يسمّي التقرير الاختبار الفاشل، وسطر التأكيد الذي أوقفه، وموضع التصريح بالاختبار. وحين يفشل أي اختبار يخرج `sultanc test`
بالحالة 1، فيستطيع سكربت أو خادم بناء أن يتوقف عنده.

واكتب الاختبار بحيث يخبرك فشله بشيء. فاختبار لكل سلوك، باسم يقول السلوك، أسهل في التصرف حياله من اختبار كبير يفحص كل شيء.

## اختبار أن الفشل يحدث

اختبر حالات الفشل أيضا، فهي حيث تختبئ الأخطاء. فـ `طابق` فيها `تأكد(خطأ)` في الفرع الذي يجب ألا يحدث تفحص أن الدالة تفشل
حين ينبغي:

```sultan test
استورد المكتبة.تصحيح.تأكد;

عرف اقسم(أ: عدد, ب: عدد): نتيجة عدد, نص {
    إذا (ب == 0) {
        أرجع نتيجة.خطأ("قسمة على صفر");
    };
    أرجع نتيجة.نجح(أ / ب);
}

@@اختبار
عرف القسمة_تعمل(): فراغ {
    طابق اقسم(10, 2) مع
    | نتيجة.نجح(ق) -> { تأكد(ق == 5); }
    | نتيجة.خطأ(_) -> { تأكد(خطأ); };
}

@@اختبار
عرف القسمة_على_صفر_تفشل(): فراغ {
    طابق اقسم(1, 0) مع
    | نتيجة.نجح(_) -> { تأكد(خطأ); }
    | نتيجة.خطأ(_) -> { };
}

عرف الرئيسية(): عدد {
    أرجع 0;
}
```

```text
نجح القسمة_تعمل
نجح القسمة_على_صفر_تفشل

نتيجة الاختبارات: ناجحة. نجح: 2؛ فشل: 0؛ استُبعد: 0
```

## حالات كثيرة في اختبار واحد

حين ينبغي أن تعطي دالة أجوبة معروفة لمدخلات كثيرة، فضع الحالات في متجه سجلات وافحصها في حلقة. فتصير إضافة حالة سطرا واحدا:

```sultan test
استورد المكتبة.تصحيح.تأكد;

عرف سنة_كبيسة(السنة: عدد): منطقي {
    أرجع (السنة % 4 == 0 && السنة % 100 != 0) || السنة % 400 == 0;
}

نوع حالة = { السنة: عدد, كبيسة: منطقي };

@@اختبار
عرف السنوات_الكبيسة(): فراغ {
    دع الحالات: متجه حالة = [
        { السنة: 2024, كبيسة: صواب },
        { السنة: 2023, كبيسة: خطأ },
        { السنة: 1900, كبيسة: خطأ },
        { السنة: 2000, كبيسة: صواب }
    ];
    لكل (دع ع: متغير عدد = 0; ع < الطول(الحالات); ع := ع + 1) {
        تأكد(سنة_كبيسة(الحالات[ع].السنة) == الحالات[ع].كبيسة);
    }
}

عرف الرئيسية(): عدد {
    أرجع 0;
}
```

```text
نجح السنوات_الكبيسة

نتيجة الاختبارات: ناجحة. نجح: 1؛ فشل: 0؛ استُبعد: 0
```
