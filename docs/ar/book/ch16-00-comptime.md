# التقييم وقت الترجمة

بعض القيم لا تتغير بين تشغيل وآخر: جدول مربعات، أو حجم مخزن يُشتق من بضعة ثوابت، أو فحص أن إعدادا ما في مداه. ويستطيع
السلطان حسابها وهو يترجم البرنامج، فلا يحتوي البرنامج النهائي إلا النتائج. ويبيّن هذا الفصل الطرق الثلاث لذلك.

## ثوابت الوحدة

استخدمت الطريقة الأولى من قبل: فـ `دع` خارج أي دالة يُحسب وقت الترجمة ([الفصل الثالث](ch03-01-variables-and-mutability.md)). وإذا فشل حسابه،
بالقسمة على صفر أو بالتجاوز مثلا، فلا يُترجَم البرنامج.

## تعابير `وقت_الترجمة`

ينفّذ `وقت_الترجمة` قبل التعبير ذلك التعبير أثناء الترجمة. ويستطيع استدعاء دوال عادية، بحلقاتها وكل ما فيها، ما دامت
لا تقرأ ولا تكتب شيئا خارجها:

```sultan
استورد المكتبة.دخ.اطبع_سطر;
استورد المكتبة.نصوص.أعداد;

عرف مجموع_المربعات(الحد: عدد): عدد {
    دع المجموع: متغير عدد = 0;
    لكل (دع ع: متغير عدد = 1; ع <= الحد; ع := ع + 1) {
        المجموع := المجموع + ع * ع;
    }
    أرجع المجموع;
}

عرف الرئيسية(): عدد {
    دع حجم_الجدول: عدد = وقت_الترجمة مجموع_المربعات(10);
    اطبع_سطر(عدد_إلى_نص(حجم_الجدول));
    أرجع 0;
}
```

```text
385
```

وحين يعمل البرنامج يكون `حجم_الجدول` ببساطة 385: فقد دارت الحلقة داخل المترجم، مرة واحدة.

وتحسب كتلة `وقت_الترجمة` قيمة بعدة جمل. وقيمتها آخر تعبير فيها، مكتوبا دون فاصلة منقوطة:

```sultan
استورد المكتبة.دخ.اطبع_سطر;
استورد المكتبة.نصوص.أعداد;

عرف الرئيسية(): عدد {
    دع فيبوناتشي_20: عدد = وقت_الترجمة {
        دع أ: متغير عدد = 0;
        دع ب: متغير عدد = 1;
        دع ع: متغير عدد = 0;
        طالما (ع < 20) {
            دع التالي: عدد = أ + ب;
            أ := ب;
            ب := التالي;
            ع := ع + 1;
        }
        أ
    };
    اطبع_سطر(عدد_إلى_نص(فيبوناتشي_20));
    أرجع 0;
}
```

```text
6765
```

## معاملات وقت الترجمة

المعامل الموسوم بـ `وقت_الترجمة` يجب أن يُعطى قيمة معروفة أثناء الترجمة. فتستطيع الدالة فحص تلك القيمة، وتوقف
`فشل_وقت_الترجمة` (من `المكتبة.انعكاس.انعكاس_الأنواع`) البناء برسالة حين تكون خاطئة:

```sultan
استورد المكتبة.دخ.اطبع_سطر;
استورد المكتبة.نصوص.أعداد;
استورد المكتبة.انعكاس.انعكاس_الأنواع;

عرف عرض_مفحوص(وقت_الترجمة البتات: عدد): عدد {
    إذا (البتات > 64) {
        فشل_وقت_الترجمة("يجب ألا يتجاوز العرض 64 بتا");
    };
    أرجع البتات;
}

عرف الرئيسية(): عدد {
    اطبع_سطر(عدد_إلى_نص(عرض_مفحوص(8)));
    أرجع 0;
}
```

```text
8
```

وتغيير `عرض_مفحوص(8)` إلى `عرض_مفحوص(80)` يجعل البرنامج لا يُترجَم، بتلك الرسالة. فالخطأ الذي كان سيكتشفه تشغيل
البرنامج، أو مستخدمه، يكتشفه المترجم.

## الحدود

لا تستطيع شيفرة وقت الترجمة قراءة الملفات، ولا الطباعة، ولا استخدام الشبكة، ولا معرفة شيء عن الجهاز. ويجب أن تكون
نتائجها أعدادا صحيحة، أو قيما منطقية، أو محارف، أو نصوصا، أو متجهات منها. ولها ميزانية من التعليمات ومن عمق الاستدعاء،
فالحلقة التي لا تنتهي تصير خطأ ترجمة بدل مترجم لا ينتهي.

وتغطي صفحة [التقييم وقت الترجمة](../reference/comptime.md) في المرجع الانعكاس والتعليقات التوضيحية والتخصيص.

## الخلاصة

- تُحسب ثوابت الوحدة وقت الترجمة.
- ينفّذ `وقت_الترجمة تعبير` و`وقت_الترجمة { …; القيمة }` الشيفرة أثناء الترجمة.
- تأخذ معاملات `وقت_الترجمة` قيما معروفة وقت الترجمة، وترفض `فشل_وقت_الترجمة` الخاطئ منها أثناء البناء.
- لا تقرأ شيفرة وقت الترجمة ولا تكتب، ولها حد زمني.
