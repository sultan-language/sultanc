# أنواع البيانات

لكل قيمة في السلطان *نوع*، والنوع يحدد ما تحمله القيمة وما يمكنك فعله بها. ويعرف المترجم نوع كل قيمة قبل أن يعمل
البرنامج، ويرفض أي عملية لا تناسب النوع. وبهذا اكتُشفت في الفصل الثاني مقارنة `نص` بـ `طبيعي`.

ويغطي هذا القسم مجموعتين من الأنواع. الأنواع *المفردة* (scalar) تحمل قيمة واحدة: الأعداد الصحيحة، والأعداد العائمة،
والقيم المنطقية، والمحارف. والأنواع *المركّبة* (compound) تجمع عدة قيم: الصفوف (tuples) والمتجهات.

## الأعداد الصحيحة

العدد الصحيح عدد بلا كسور. وللسلطان عدة أنواع منه، تختلف في الحجم وفي قبول القيم السالبة:

| الحجم | بإشارة (يقبل السالب) | بلا إشارة (لا يكون سالبا) |
| --- | --- | --- |
| 8 بت | `ص8` | `ط8` |
| 16 بت | `ص16` | `ط16` |
| 32 بت | `ص32` | `ط32` |
| 64 بت | `ص64` و `عدد` | `ط64` و `طبيعي` |

`عدد` و `طبيعي` هما النوعان ذوا الـ 64 بت، وهما ما تستخدمه إلا إذا كان لديك سبب لغيرهما: `عدد` للعدّ والحساب العاديين،
ومنه المواضع في المتجه، و `طبيعي` للقيم التي لا تكون سالبة أبدا. والأحجام الثابتة للبيانات التي يحدد عرضها شيء خارج
برنامجك: صيغة ملف، أو بروتوكول شبكة، أو مكتبة C.

ولكل نوع مدى. فالنوع ذو الإشارة بحجم `ن` بت يحمل من -2<sup>ن-1</sup> إلى 2<sup>ن-1</sup> - 1، فيحمل `ص8` من -128 إلى
127. والنوع بلا إشارة بحجم `ن` بت يحمل من 0 إلى 2<sup>ن</sup> - 1، فيحمل `ط8` من 0 إلى 255. ويصل `عدد` إلى قرابة
9.2 × 10<sup>18</sup> في كل اتجاه.

وتُكتب الأعداد الصحيحة الحرفية بالنظام العشري، أو الست عشري بعد `0x`، أو الثنائي بعد `0b`. ويجوز الفصل بين الأرقام بـ
`_` لتسهل قراءة الأعداد الطويلة:

```sultan
استورد المكتبة.دخ.اطبع_سطر;
استورد المكتبة.نصوص.أعداد;

عرف الرئيسية(): عدد {
    دع عشري: عدد = 255;
    دع ست_عشري: عدد = 0xFF;
    دع ثنائي: عدد = 0b1111_1111;
    دع مليون: عدد = 1_000_000;
    دع صغير: ص8 = -5;
    اطبع_سطر(عدد_إلى_نص(عشري + ست_عشري + ثنائي));
    اطبع_سطر(عدد_إلى_نص(مليون));
    اطبع_سطر(عدد_إلى_نص(صغير مثل عدد));
    أرجع 0;
}
```

```text
765
1000000
-5
```

### تجاوز الحد

ماذا يحدث حين لا تسع النتيجة نوعها؟ هنا تُحسب `127 + 1` في `ص8`:

```sultan
استورد المكتبة.دخ.اطبع_سطر;
استورد المكتبة.نصوص.أعداد;

عرف الرئيسية(): عدد {
    دع كبير: ص8 = 127;
    دع نتيجة: ص8 = كبير + 1;
    اطبع_سطر(عدد_إلى_نص(نتيجة مثل عدد));
    أرجع 0;
}
```

يترجم البرنامج، لأن المترجم لا يعرف القيم دائما. لكنه حين يعمل يتوقف عند الجمع، ويقول ما الخطأ وأين وقع:

```console
$ sultanc main.sn -o overflow
$ ./overflow
خطأ[SULTANC-RUNTIME-PROGRAM-STOPPED]: توقف البرنامج
تجاوز العدد الصحيح حدود نوعه عند main.sn:6:20
$ echo $?
1
```

و`main.sn:6:20` هو الملف والسطر والعمود لـ `كبير + 1`. فالبرنامج لا يكمل بعدد خاطئ، وهذا اختيار مقصود: فالقيمة الخاطئة التي
لا يلاحظها أحد تنتشر في باقي البرنامج، أما البرنامج المتوقف فيريك موضع المشكلة بالضبط. ويحدث الشيء نفسه حين ينزل `طبيعي` تحت
الصفر (`0 - 1`)، وعند القسمة على صفر، وفي الرسالة حينها `قسمة على صفر عند …`.

وحين يكون الالتفاف (wrapping) هو ما تريده، كما في دوال التجزئة (hash)، ففي `المكتبة.رياضيات.التفاف` دالة لكل عملية ونوع.
ودوالها التي تنتهي بـ `_متحقق` ترجع `اختياري` بدلا من ذلك، وتكون فارغة حين لا تسع النتيجة نوعها:

```sultan
استورد المكتبة.دخ.اطبع_سطر;
استورد المكتبة.نصوص.أعداد;
استورد المكتبة.رياضيات.التفاف;

عرف الرئيسية(): عدد {
    دع الأعلى: ط8 = 255;
    اطبع_سطر(طبيعي_إلى_نص(جمع_ط8_ملتف(الأعلى, 1) مثل طبيعي));
    طابق جمع_ص32_متحقق(2147483647, 1) مع
    | اختياري.موجود(ن) -> { اطبع_سطر(عدد_إلى_نص(ن مثل عدد)); }
    | اختياري.لا_شيء -> { اطبع_سطر("أكبر من أن يسعه ص32"); };
    أرجع 0;
}
```

```text
0
أكبر من أن يسعه ص32
```

### الحساب

العوامل هي `+` و `-` و `*` و `/` و `%` (الباقي). وتحذف قسمة الأعداد الصحيحة الكسر، مقرّبة نحو الصفر، ويأخذ الباقي إشارة
الطرف الأيسر:

```sultan
استورد المكتبة.دخ.اطبع_سطر;
استورد المكتبة.نصوص.أعداد;

عرف الرئيسية(): عدد {
    اطبع_سطر(عدد_إلى_نص(7 / 2));
    اطبع_سطر(عدد_إلى_نص(7 % 2));
    اطبع_سطر(عدد_إلى_نص(-7 / 2));
    اطبع_سطر(عدد_إلى_نص(-17 % 5));
    اطبع_سطر(عدد_إلى_نص((2 + 3) * 4));
    أرجع 0;
}
```

```text
3
1
-3
-2
20
```

ويأتي الضرب والقسمة والباقي قبل الجمع والطرح، والأقواس تغيّر الترتيب.

### الأنواع لا تختلط وحدها

يجب أن يكون طرفا العامل من النوع نفسه. فلا يُجمع `عدد` و `طبيعي` مباشرة:

```sultan fail
عرف الرئيسية(): عدد {
    دع أ: عدد = 1;
    دع ب: طبيعي = 2;
    أرجع أ + ب;
}
```

```text
خطأ[SULTANC-TYPE-MISMATCH]: النوع الموجود ⁨`طبيعي`⁩ لا يطابق النوع المتوقع ⁨`عدد`⁩ — طرفا هذا العامل من نوعين مختلفين.
  --> main.sn:4:14..4:15
   |
 4 |     أرجع أ + ب;
   |              ^
   |
  = مساعدة: حول القيمة صراحة بـ⁨`مثل`⁩
```

ويُكتب التحويل بـ `مثل`:

```sultan
استورد المكتبة.دخ.اطبع_سطر;
استورد المكتبة.نصوص.أعداد;

عرف الرئيسية(): عدد {
    دع أ: عدد = 1;
    دع ب: طبيعي = 2;
    اطبع_سطر(عدد_إلى_نص(أ + (ب مثل عدد)));
    اطبع_سطر(عدد_إلى_نص(300 مثل ط8 مثل عدد));
    اطبع_سطر(عدد_إلى_نص(3.99 مثل عدد));
    أرجع 0;
}
```

```text
3
44
3
```

تحوّل `مثل` بين أي نوعين من الأعداد. فإلى نوع صحيح أصغر تحتفظ بالبتات الدنيا: 300 هي 256 + 44، فتكون `300 مثل ط8` هي 44.
ومن عدد عائم إلى عدد صحيح تحذف الكسر. ولأن كل تحويل مكتوب، فكل موضع قد يتغير فيه حجم عدد أو تضيع دقته ظاهر في الشيفرة.

### عوامل البتات

وللأعلام والصيغ الثنائية، في الأعداد الصحيحة أيضا عوامل البتات: `&` (و)، و `|` (أو)، و `^` (أو الحصرية)، و `~` (ليس)، و `<<`
(إزاحة إلى اليسار)، وإزاحتان إلى اليمين: `>>` تملأ اليسار بالأصفار، و `>>>` تحفظ إشارة العدد السالب:

```sultan
استورد المكتبة.دخ.اطبع_سطر;
استورد المكتبة.نصوص.أعداد;

عرف الرئيسية(): عدد {
    اطبع_سطر(عدد_إلى_نص(6 & 3));
    اطبع_سطر(عدد_إلى_نص(6 | 3));
    اطبع_سطر(عدد_إلى_نص(6 ^ 3));
    اطبع_سطر(عدد_إلى_نص(~6));
    اطبع_سطر(عدد_إلى_نص(1 << 4));
    دع سالب: عدد = -8;
    اطبع_سطر(عدد_إلى_نص(سالب >>> 1));
    أرجع 0;
}
```

```text
2
7
5
-7
16
-4
```

## الأعداد العائمة

يحمل `ع64` و `ع32` أعدادا بكسور، في 64 و 32 بت. استخدم `ع64` إلا إذا كانت الذاكرة ضيقة. والعدد العائم الحرفي فيه نقطة
دائما: `7.0` لا `7`.

```sultan
استورد المكتبة.دخ.اطبع_سطر;
استورد المكتبة.نصوص.عشري;

عرف الرئيسية(): عدد {
    دع العرض: ع64 = 7.0;
    دع النصف: ع64 = العرض / 2.0;
    اطبع_سطر(ع64_إلى_نص(النصف));
    اطبع_سطر(ع64_إلى_نص(0.1 + 0.2));
    اطبع_سطر(ع64_إلى_نص(10 مثل ع64));
    أرجع 0;
}
```

```text
3.5
0.30000000000000004
10
```

تطبع `ع64_إلى_نص` من `المكتبة.نصوص.عشري` أقصر نص يُقرأ بعده العدد نفسه. ولذلك تظهر `0.1 + 0.2` بالقيمة
`0.30000000000000004`: فلا يوجد لـ 0.1 ولا لـ 0.2 تمثيل ثنائي دقيق، فمجموعهما أكبر قليلا من 0.3. وكل الأعداد العائمة
الثنائية القياسية تتصرف هكذا. ولطباعة عدد محدد من الأرقام استخدم التنسيق، من [الفصل الثالث عشر](ch13-00-formatting.md).

## القيم المنطقية

القيمة `منطقي` إما `صواب` أو `خطأ`. وتنتجها المقارنات:

| العامل | معناه |
| --- | --- |
| `==` | يساوي |
| `!=` | لا يساوي |
| `<` و `<=` | أصغر، أصغر أو يساوي |
| `>` و `>=` | أكبر، أكبر أو يساوي |

وتجمع بينها `&&` (و) و `||` (أو) و `!` (ليس). ولا تحسب `&&` و `||` طرفهما الأيمن إلا عند الحاجة: ففي `أ && ب`، إن كان `أ`
خطأ كانت النتيجة خطأ، ولا يُحسب `ب`.

```sultan
استورد المكتبة.دخ.اطبع_سطر;

عرف الرئيسية(): عدد {
    دع العمر: عدد = 20;
    دع معه_تذكرة: منطقي = صواب;
    دع يمكنه_الدخول: منطقي = العمر >= 18 && معه_تذكرة;
    إذا (يمكنه_الدخول) {
        اطبع_سطر("أهلا بك");
    };
    إذا (!(العمر == 18)) {
        اطبع_سطر("ليس 18 بالضبط");
    };
    أرجع 0;
}
```

```text
أهلا بك
ليس 18 بالضبط
```

## المحارف

النوع `حرف` محرف يونيكود واحد، بين علامتي تنصيص مفردتين: `'A'` و `'7'` و `'س'`. وتحويله إلى `ط32` يعطي رقمه في يونيكود،
وهو *code point*:

```sultan
استورد المكتبة.دخ.اطبع_سطر;
استورد المكتبة.نصوص.أعداد;

عرف الرئيسية(): عدد {
    دع الحرف: حرف = 'A';
    دع عربي: حرف = 'س';
    اطبع_سطر(طبيعي_إلى_نص(الحرف مثل ط32 مثل طبيعي));
    اطبع_سطر(طبيعي_إلى_نص(عربي مثل ط32 مثل طبيعي));
    أرجع 0;
}
```

```text
65
1587
```

أما النص، النوع `نص`، فسلسلة محارف مخزّنة بايتات UTF-8. وله قواعد خاصة، في الملكية وفي الفرق بين البايت والمحرف، ويغطيها
[الفصل الثامن](ch08-02-strings.md).

## الصفوف

يجمع *الصف* (tuple) عددا ثابتا من القيم، وقد تختلف أنواعها. ويسرد نوعه الأنواع بين قوسين، وتسرد قيمته القيم:

```sultan
استورد المكتبة.دخ.اطبع_سطر;
استورد المكتبة.نصوص.أعداد;

عرف الرئيسية(): عدد {
    دع النقطة: (عدد, عدد) = (3, 4);
    دع المدخل: (نص, عدد) = ("تمر", 45);
    طابق النقطة مع
    | (س, ص) -> { اطبع_سطر(عدد_إلى_نص(س * س + ص * ص)); };
    طابق المدخل مع
    | (الاسم, السعر) -> {
        اطبع_سطر(الاسم);
        اطبع_سطر(عدد_إلى_نص(السعر));
    };
    أرجع 0;
}
```

```text
25
تمر
45
```

تفكّك `طابق` الصف: فالنمط `(س, ص)` يسمّي كل جزء. والصفوف مفيدة لإرجاع قيمتين من دالة، كما يبين القسم التالي. وحين يكون
للأجزاء معان تستحق التسمية، فالسجل من [الفصل الخامس](ch05-00-records.md) أوضح.

## المتجهات

يحمل *المتجه* (vector) أي عدد من القيم من نوع واحد، واحدة بعد أخرى. ونوعه `متجه` ثم نوع العناصر، وقيمته تسرد عناصرها
بين قوسين مربعين:

```sultan
استورد المكتبة.دخ.اطبع_سطر;
استورد المكتبة.نصوص.أعداد;

عرف الرئيسية(): عدد {
    دع الأوليات: متجه عدد = [2, 3, 5, 7, 11];
    اطبع_سطر(عدد_إلى_نص(الأوليات[0]));
    اطبع_سطر(عدد_إلى_نص(الأوليات[4]));
    اطبع_سطر(عدد_إلى_نص(الطول(الأوليات)));
    أرجع 0;
}
```

```text
2
11
5
```

`الأوليات[0]` هو العنصر الأول: فالمواضع تبدأ من 0. وتعطي `الطول` عدد العناصر. والموضع الذي بعد النهاية يوقف البرنامج كما
يوقفه تجاوز الحد، بدلا من قراءة ذاكرة ليست من المتجه.

ويمكن للمتجهات أن تكبر، وأن تُمرَّر إلى الدوال، وأن تُرتَّب، ويغطيها [الفصل الثامن](ch08-01-vectors.md).

## الخلاصة

- `عدد` و `طبيعي` هما العددان الصحيحان الافتراضيان، ومن `ص8` إلى `ص64` ومن `ط8` إلى `ط64` أحجام محددة.
- تجاوز الحد، والنزول تحت الصفر في نوع بلا إشارة، والقسمة على صفر، والموضع الذي بعد نهاية المتجه، كلها توقف البرنامج.
- الأنواع لا تختلط وحدها: `مثل` تحوّل، وتُكتب دائما.
- `ع64` هو النوع العائم الافتراضي، وأعداده الحرفية فيها نقطة.
- `منطقي` يأتي من المقارنات، وتجمع بينها `&&` و `||` و `!`.
- `حرف` محرف يونيكود واحد، والصفوف تجمع عددا ثابتا من القيم، والمتجهات تحمل الكثير من نوع واحد.
