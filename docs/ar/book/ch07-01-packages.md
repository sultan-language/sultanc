# الحزم

تنشئ حزما منذ الفصل الأول: فـ `supax new` تنشئ حزمة. وينظر هذا القسم فيما تحويه الحزمة.

```console
$ supax new متجر
أُنشئت الحزمة "متجر"
$ cd متجر
```

```text
متجر/
├── .gitignore
├── Supax.toml
└── src/
    └── main.sn
```

`Supax.toml` هو *بيان* الحزمة (manifest): اسمها، وإصدارها، والحزم التي تعتمد عليها. ولكل حزمة بيان في أعلى مجلدها. ويحوي
المجلد `src` شيفرة الحزمة.

## البرامج والمكتبة

قد تحوي الحزمة نوعين من الشيفرة:

- **برامج**، كل منها ملف فيه الدالة `الرئيسية`، ويبنيه سوباكس ملفا تنفيذيا؛
- و**مكتبة**، وحدات تستوردها برامج الحزمة واختباراتها والحزم الأخرى.

و `src/main.sn` هو البرنامج الرئيسي للحزمة، ويحمل اسمها. والبرامج الأخرى في `src/bin`: فالملف `src/bin/report.sn` يصير
برنامجا اسمه `report`.

ولتجعل الوحدات التي في `src` مكتبة تُستورد بأسمائها، أضف القسم `[lib]` إلى البيان:

<sub>الملف: Supax.toml</sub>

```toml
[package]
name = "متجر"
version = "0.1.0"

[lib]
path = "src"

[dependencies]
```

ومن حينها يكون كل ملف تحت `src` وحدة اسمها اسم الحزمة ثم مساره: فالملف `src/prices/tax.sn` هو الوحدة `متجر.prices.tax`.
ويبني القسم 7.4 مكتبة كهذه خطوة خطوة، ويعطي وحداتها أسماء عربية.

## بناء عدة برامج

مع `src/main.sn` و `src/bin/report.sn` يبني `supax build` كليهما:

```console
$ supax build
        يبني متجر v0.1.0 (/projects/متجر)
       انتهى في 0.28 ث → build/bin/متجر, build/bin/report
```

ويشغّل `supax run --bin report` أحدهما:

```console
$ supax run --bin report
        يبني متجر v0.1.0 (/projects/متجر)
       انتهى في 0.14 ث → build/bin/report
       يشغّل build/bin/report
1150
```

## أسماء الحزم

اسم الحزمة هو ما تشير به إليها الشيفرة الأخرى: فكل وحدات مكتبتها تبدأ به. استخدم كلمات عربية، أو كلمات لاتينية صغيرة تصل
بينها `_`: `متجر` و `لعبة_التخمين` و `shop`. والاسم الذي في `Supax.toml` هو المعتبر، لا اسم المجلد.

## الأوامر

| الأمر | ما يفعله |
| --- | --- |
| `supax new الاسم` | ينشئ حزمة في مجلد جديد |
| `supax init` | ينشئ حزمة في المجلد الحالي |
| `supax build` | يبني كل البرامج في `build/bin/` |
| `supax run [--bin الاسم]` | يبني ثم يشغّل برنامجا |
| `supax check` | يفحص الحزمة دون بناء |
| `supax test` | يشغّل الاختبارات ([الفصل الحادي عشر](ch11-00-testing.md)) |
| `supax clean` | يحذف `build/` |

ولكل أمر اسم عربي أيضا يسرده `supax --help`: فـ `supax ابن` هو `supax build`، و `supax شغل` هو `supax run`.

والاعتماد على حزم أخرى موضوع [الفصل الرابع عشر](ch14-00-more-about-supax.md).
