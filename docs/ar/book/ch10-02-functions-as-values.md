# الدوال قيمًا

الدالة قيمة. تُخزَّن في متغير، وتُمرَّر إلى دالة أخرى، وتُرجَع من دالة.

## أنواع الدوال

يُكتب نوع الدالة `دالة(أنواع المعاملات): نوع القيمة`. فـ `دالة(عدد): عدد` أي دالة تأخذ `عدد` وترجع `عدد`، و
`دالة(&نص, &نص): عدد` تأخذ نصين مستعارين وترجع `عدد`.

وتصير الدالة المسماة قيمة حين تكتب اسمها دون استدعائها:

```sultan
استورد المكتبة.دخ.اطبع_سطر;
استورد المكتبة.نصوص.أعداد;

عرف مربع(س: عدد): عدد {
    أرجع س * س;
}

عرف مرتين(د: دالة(عدد): عدد, س: عدد): عدد {
    أرجع د(د(س));
}

عرف الرئيسية(): عدد {
    دع العملية: دالة(عدد): عدد = مربع;
    اطبع_سطر(عدد_إلى_نص(العملية(5)));
    اطبع_سطر(عدد_إلى_نص(مرتين(مربع, 3)));
    أرجع 0;
}
```

```text
25
81
```

لا تعرف `مرتين` ما تفعله `د`. تعرف فقط أن `د` تأخذ `عدد` وترجع `عدد`، وهذا يكفي لاستدعائها مرتين.

## تمرير الخطوة المختلفة

أشيع استخدام لمعامل من نوع دالة أن تعمل دالة عامة العمل العام، ويقدّم المستدعي الخطوة الوحيدة المختلفة. فـ `رتب_بالمقارنة` من
`المكتبة.مجموعات.ترتيب` ترتب متجها من أي نوع، بأي ترتيب، بمقارنة تعطيها إياها. وترجع المقارنة عددا سالبا حين يجب أن يأتي
وسيطها الأول أولا، وصفرا حين يتساويان، وعددا موجبا فيما عدا ذلك:

```sultan
استورد المكتبة.دخ.اطبع_سطر;
استورد المكتبة.نصوص.تحويل;
استورد المكتبة.مجموعات.ترتيب;

عرف بالطول(أ: &نص, ب: &نص): عدد {
    أرجع الطول(*أ) - الطول(*ب);
}

عرف الرئيسية(): عدد {
    دع الكلمات: متغير متجه نص = ["برتقال", "تين", "تفاح"];
    رتب_بالمقارنة(&متغير الكلمات, بالطول);
    اطبع_سطر(صل_النصوص(&الكلمات, &"، "));
    أرجع 0;
}
```

```text
تين، تفاح، برتقال
```

## الأنواع العامة والدوال قيمًا معا

تستطيع الدالة العامة أن تكتب `>` بين قيمتين من النوع `T`، ويفحصها المترجم في كل مرة تُستخدم فيها الدالة مع نوع: فمع `عدد`
تترجم، ومع `مدينة`، السجل أدناه، تكون الخطأ "العامل `>` غير معرف للنوع `مدينة`"، معلَّما عند `>` داخل الدالة، وبجواره الاستدعاء الذي
اختار `مدينة`. فالسجل لا ترتيب له في ذاته، وأي ترتيب يُقصد، بالسكان أم بالاسم، أمر يقوله المستدعي. ولذلك تطلب الدالة العامة
التي ينبغي أن تعمل مع أي نوع المقارنةَ من المستدعي:

```sultan
استورد المكتبة.دخ.اطبع_سطر;
استورد المكتبة.نصوص.أعداد;

نوع مدينة = { الاسم: نص, السكان: عدد };

عرف الأكبر<T>(القيم: &متجه T, أكبر: دالة(&T, &T): منطقي): اختياري T {
    إذا (الطول(*القيم) == 0) {
        أرجع اختياري.لا_شيء();
    };
    دع الأفضل: متغير عدد = 0;
    لكل (دع ع: متغير عدد = 1; ع < الطول(*القيم); ع := ع + 1) {
        إذا (أكبر(&(*القيم)[ع], &(*القيم)[الأفضل])) {
            الأفضل := ع;
        };
    }
    أرجع اختياري.موجود(استنسخ(&(*القيم)[الأفضل]));
}

عرف عدد_أكبر(أ: &عدد, ب: &عدد): منطقي {
    أرجع *أ > *ب;
}

عرف مدينة_أكبر(أ: &مدينة, ب: &مدينة): منطقي {
    أرجع أ.السكان > ب.السكان;
}

عرف الرئيسية(): عدد {
    دع الأعداد: متجه عدد = [4, 19, 7];
    طابق الأكبر(&الأعداد, عدد_أكبر) مع
    | اختياري.موجود(ن) -> { اطبع_سطر(عدد_إلى_نص(ن)); }
    | اختياري.لا_شيء -> { اطبع_سطر("فارغ"); };
    دع المدن: متجه مدينة = [
        { الاسم: "جدة", السكان: 4700000 },
        { الاسم: "الرياض", السكان: 7700000 }
    ];
    طابق الأكبر(&المدن, مدينة_أكبر) مع
    | اختياري.موجود(المدينة) -> { اطبع_سطر(المدينة.الاسم); }
    | اختياري.لا_شيء -> { اطبع_سطر("فارغ"); };
    أرجع 0;
}
```

```text
19
الرياض
```

الحلقة مكتوبة مرة واحدة. والجزء الوحيد الذي يعتمد على النوع هو المقارنة، ويعطي كل مستدعٍ مقارنته. والمكتبة القياسية تعمل
بالطريقة نفسها: `رتب_بالمقارنة` و `بحث_ثنائي_بالمقارنة` و `أنشئ_خريطة_شجرة_بي` و `أنشئ_مجموعة` كلها تأخذ دوالا للجزء الذي
يعتمد على النوع.
