# تنظيم المشاريع الكبيرة بالحزم والوحدات

كانت البرامج حتى الآن تسعها ملفات مفردة. أما البرامج الحقيقية فلا: تكبر إلى عشرات الملفات أو مئاتها، وتستخدم شيفرة كتبها
غيرك. وتنظّمها فكرتان:

- *الوحدة* (module) ملف `.sn` واحد. تجمع شيفرة مترابطة، وتقرر أي أسمائها يجوز لغيرها من الوحدات استخدامه، وأيها يبقى خاصا.
- و*الحزمة* (package) مشروع يبنيه سوباكس: `Supax.toml`، ومجلد `src` فيه الوحدات، وربما برامج واختبارات واعتماديات على حزم
  أخرى.

وتقسيم الشيفرة إلى وحدات يتيح لك قراءة جزء دون الباقي، وإخفاء تفاصيل لا ينبغي أن تعتمد عليها الأجزاء الأخرى، وتغيير تلك
التفاصيل بحرية لاحقا.
