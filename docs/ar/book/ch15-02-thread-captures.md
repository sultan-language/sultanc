# ما يجوز للخيط التقاطه

قد يعمل الخيط أطول من الدالة التي أطلقته. فلو حمل مرجعا إلى متغيرات تلك الدالة، لأشار المرجع إلى ذاكرة لم تعد موجودة بعد أن
ترجع الدالة. فالـ closure المرسل إلى خيط آخر لا يجوز أن يلتقط مرجعا:

```sultan fail
استورد المكتبة.خيوط.خيط;

عرف اعرض(ق: &متجه عدد): عدد {
    أرجع الطول(*ق);
}

عرف البداية(القيم: &متجه عدد): فراغ {
    طابق أطلق_بقيمة(دالة(): عدد -> اعرض(القيم)) مع
    | نتيجة.نجح(_) -> { }
    | نتيجة.خطأ(_) -> { };
}

عرف الرئيسية(): عدد {
    دع ق: متجه عدد = [1];
    البداية(&ق);
    أرجع 0;
}
```

تعير `البداية` القيم إلى الـ closure، لكن `البداية` ترجع فورا، والخيط قد يكون ما زال يعمل. فيرفض المترجم ذلك قبل أن يسوء شيء.

والإصلاح أن تعطي الخيط قيمة خاصة به: انقل القيمة إليه، كما فعلت `اجمع_في_خيط` في القسم السابق، أو استنسخها حين يحتاجها
المستدعي.

ويغطي الفحص نفسه القيم التي تتيح لخيطين تغيير شيء واحد في الوقت نفسه: فلا تُشارَك قيمة بين الخيوط إلا عبر الأنواع المصنوعة لذلك،
ويعرضها القسم التالي. ويعطي [التزامن](../reference/concurrency.md) في المرجع القواعد كاملة.
