# قراءة ملف

يحتاج البرنامج الآن إلى ملف يبحث فيه. أنشئ `poem.txt` في أعلى المشروع، بجوار `Supax.toml`:

<sub>الملف: poem.txt</sub>

```text
النهر لا يسأل الحجر
لماذا يقف في الطريق.
يدور حوله ويمضي في لحنه،
ويبلغ البحر ذات يوم.
اسأل الحجر، فلن يقول شيئا.
```

تقرأ `اقرأ_الملف(&المسار)` من `المكتبة.ملفات.قراءة_ملف` الملف كله `نص` واحدا. وقد تفشل القراءة (قد لا يوجد الملف، أو لا يُقرأ)،
فترجع `نتيجة`. وخطؤها رمز خطأ نظام التشغيل، من النوع `عدد`.

<sub>القائمة 12-2: حفظ الوسيطين وقراءة الملف. الملف: src/main.sn</sub>

```sultan ignore
استورد المكتبة.دخ.اطبع_سطر;
استورد المكتبة.عمليات.وسيطة;
استورد المكتبة.ملفات.قراءة_ملف;
استورد المكتبة.نصوص.تحويل;

عرف الرئيسية(): عدد {
    دع المطلوب: نص;
    طابق وسيطة(1) مع
    | اختياري.موجود(النص) -> { المطلوب := النص; }
    | اختياري.لا_شيء -> { اطبع_سطر("الاستخدام: باحث المطلوب الملف"); أرجع 2; };
    دع مسار_الملف: نص;
    طابق وسيطة(2) مع
    | اختياري.موجود(النص) -> { مسار_الملف := النص; }
    | اختياري.لا_شيء -> { اطبع_سطر("الاستخدام: باحث المطلوب الملف"); أرجع 2; };

    اطبع_سطر(صل_نصين(&"البحث عن ", &المطلوب));
    اطبع_سطر(صل_نصين(&"في الملف ", &مسار_الملف));

    طابق اقرأ_الملف(&مسار_الملف) مع
    | نتيجة.نجح(المحتوى) -> {
        اطبع_سطر("والنص:");
        اطبع_سطر(المحتوى);
    }
    | نتيجة.خطأ(_) -> {
        اطبع_سطر(صل_نصين(&"تعذرت قراءة ", &مسار_الملف));
        أرجع 1;
    };
    أرجع 0;
}
```

يستخدم هذا نمط "التصريح الآن والقيمة لاحقا" من الفصل الثالث: يأخذ `المطلوب` قيمته في فرع، والفرع الآخر يغادر الدالة.

```console
$ supax run -- الحجر poem.txt
        يبني باحث v0.1.0 (/projects/باحث)
       انتهى في 0.20 ث → build/bin/باحث
       يشغّل build/bin/باحث
البحث عن الحجر
في الملف poem.txt
والنص:
النهر لا يسأل الحجر
لماذا يقف في الطريق.
يدور حوله ويمضي في لحنه،
ويبلغ البحر ذات يوم.
اسأل الحجر، فلن يقول شيئا.

$ supax run -- الحجر missing.txt
        يبني باحث v0.1.0 (/projects/باحث)
       انتهى في 0.21 ث → build/bin/باحث
       يشغّل build/bin/باحث
البحث عن الحجر
في الملف missing.txt
تعذرت قراءة missing.txt
```

والمسار النسبي مثل `poem.txt` نسبي إلى المجلد الذي يبدأ منه البرنامج، وهو مع `supax run` مجلد المشروع.

يعمل البرنامج، لكن `الرئيسية` تفعل الآن كل شيء: تقرأ الوسائط، وتقرأ الملف، وتقرر ماذا تطبع، وتعالج كل خطأ. ومع نموه سيصعب
قراءته ويستحيل اختباره. ويصلح القسم التالي ذلك.
