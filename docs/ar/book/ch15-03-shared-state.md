# الحالة المشتركة

تحتاج عدة خيوط أحيانا إلى العمل على القيمة نفسها. ونوعان قياسيان يجعلان ذلك آمنا:

- `مشترك<ق>` يتيح لعدة مالكين تشارك قيمة واحدة. وتصنع `استنسخ_مشترك` *مالكا* آخر للقيمة نفسها، لا نسخة منها، وتُحرَّر القيمة
  حين يزول آخر مالك. وهو يعدّ مالكيه بأمان بين الخيوط.
- و `قفل<ق>` لا يتيح الوصول إلى القيمة التي فيه إلا لخيط واحد في كل وقت. وتنتظر `نفذ_مع_القفل(&ق, د)` دورها، ثم تستدعي `د`
  بمرجع قابل للتغيير إلى القيمة.

ومعا يكون `مشترك<قفل<عدد>>` عدّادا تستطيع خيوط كثيرة أن تضيف إليه:

```sultan
استورد المكتبة.دخ.اطبع_سطر;
استورد المكتبة.نصوص.أعداد;
استورد المكتبة.خيوط.خيط;
استورد المكتبة.تزامن.مشترك;
استورد المكتبة.تزامن.قفل;

عرف أضف_واحدا(ق: &متغير عدد): عدد {
    *ق := *ق + 1;
    أرجع *ق;
}

عرف عد_إلى_ألف(العداد: مشترك<قفل<عدد>>): فراغ {
    لكل (دع ع: متغير عدد = 0; ع < 1000; ع := ع + 1) {
        دع الآن: عدد = نفذ_مع_القفل(اقرأ_مشترك(&العداد), دالة(ق: &متغير عدد): عدد -> أضف_واحدا(ق));
    }
}

عرف الرئيسية(): عدد {
    دع العداد: مشترك<قفل<عدد>> = أنشئ_مشترك(أنشئ_قفل(0));
    دع المقابض: متغير متجه مقبض_خيط = [];
    لكل (دع خ: متغير عدد = 0; خ < 4; خ := خ + 1) {
        دع نصيبي: مشترك<قفل<عدد>> = استنسخ_مشترك(&العداد);
        طابق أطلق(دالة(): فراغ -> عد_إلى_ألف(نصيبي)) مع
        | نتيجة.نجح(م) -> { ألحق(المقابض, م); }
        | نتيجة.خطأ(_) -> { أرجع 1; };
    }
    لكل (دع ع: متغير عدد = 0; ع < الطول(المقابض); ع := ع + 1) {
        انضم(&متغير المقابض[ع]);
    }
    دع المجموع: عدد = نفذ_مع_القفل(اقرأ_مشترك(&العداد), دالة(ق: &متغير عدد): عدد -> *ق);
    اطبع_سطر(عدد_إلى_نص(المجموع));
    أرجع 0;
}
```

```text
4000
```

يضيف كل من الخيوط الأربعة 1000، والمجموع دائما 4000 بالضبط. فالقفل يجعل كل إضافة تنتهي قبل أن تبدأ التالية. وبدونه قد يقرأ
خيطان القيمة القديمة نفسها، ويضيف كل منهما واحدا، ويكتبان القيمة الجديدة نفسها: فتضيع إضافة.

ولا تستطيع في السلطان أن تنسى القفل. فلا تعطي `اقرأ_مشترك` إلا مرجعا للقراءة، `&ق`، إلى القيمة المشتركة، فيتيح `مشترك` وحده
للخيوط أن تقرأ لا أن تغيّر. ولتغييرها يجب أن تكون القيمة داخل `قفل`، تعطي `نفذ_مع_القفل` منه مرجعا قابلا للتغيير لخيط واحد في
كل وقت.
