# التحكم في التدفق

قليلا ما يعمل البرنامج من أعلى إلى أسفل مباشرة. فهو يختار بين طرق، ويكرر عملا ما دام شيء صحيحا. ويغطي هذا القسم `إذا`
و `طابق` اللتين تختاران، و `طالما` و `لكل` اللتين تكرران.

## `إذا`

تنفّذ `إذا` كتلة حين يكون شرطها صحيحا:

```sultan
استورد المكتبة.دخ.اطبع_سطر;

عرف الرئيسية(): عدد {
    ليكن الحرارة: عدد = 35;
    إذا (الحرارة > 30) {
        اطبع_سطر("حار");
    };
    أرجع 0;
}
```

```text
حار
```

الشرط بين قوسين دائما، والكتلة بين معقوفين دائما، ولو كانت سطرا واحدا. و `إذا` كلها جملة، فتنتهي بـ `;` بعد `}` الأخيرة.

ويجب أن يكون الشرط `منطقي`، فالعدد ليس شرطا:

```sultan fail
عرف الرئيسية(): عدد {
    ليكن العدد: عدد = 3;
    إذا (العدد) {
        أرجع 1;
    };
    أرجع 0;
}
```

```text
خطأ[SULTANC-TYPE-MISMATCH]: النوع الموجود ⁨`عدد`⁩ لا يطابق النوع المتوقع ⁨`منطقي`⁩ — يجب أن يكون الشرط قيمة منطقية.
  --> main.sn:3:10..3:15
   |
 3 |     إذا (العدد) {
   |          ^^^^^
   |
```

بعض اللغات تعدّ كل عدد غير الصفر صحيحا، أما السلطان فيطلب منك أن تقول ما تقصده: `إذا (العدد != 0)`. فيصير القصد مكتوبا
في الشيفرة، ويُكتشف العدد المستخدم خطأً.

### `وإلا` و `وإلا إذا`

تعطي `وإلا` كتلة تُنفَّذ حين يكون الشرط خاطئا، وتضيف `وإلا إذا` شرطا آخر. وتُختبر الشروط بالترتيب، وأول شرط صحيح يفوز، ولا
يُختبر ما بعده:

```sultan
استورد المكتبة.دخ.اطبع_سطر;

عرف التقدير(الدرجة: عدد): نص {
    إذا (الدرجة >= 90) {
        أرجع "ممتاز";
    } وإلا إذا (الدرجة >= 75) {
        أرجع "جيد";
    } وإلا إذا (الدرجة >= 50) {
        أرجع "ناجح";
    } وإلا {
        أرجع "راسب";
    };
}

عرف الرئيسية(): عدد {
    اطبع_سطر(التقدير(95));
    اطبع_سطر(التقدير(80));
    اطبع_سطر(التقدير(60));
    اطبع_سطر(التقدير(20));
    أرجع 0;
}
```

```text
ممتاز
جيد
ناجح
راسب
```

الدرجة 95 أكبر من 75 ومن 50 أيضا، لكن لا يُنفَّذ إلا أول فرع مطابق.

### `إذا` قيمةً

ويمكن أن تعطي `إذا` قيمة أيضا حيث تُنتظر قيمة: بعد `=` في `ليكن`، وبعد `:=`، وبعد `أرجع`، ووسيطا أو معاملا. وكل فرع قيمة،
أو كتلة آخر تعبير فيها، مكتوبا بلا `;`، هو القيمة:

```sultan
استورد المكتبة.دخ.اطبع_سطر;

عرف الحجم(ن: عدد): نص {
    أرجع إذا (ن == 0) "لا شيء" وإلا إذا (ن < 10) "صغير" وإلا "كبير";
}

عرف الرئيسية(): عدد {
    ليكن ن: عدد = 7;
    ليكن الوصف: نص = إذا (ن > 0) "موجب" وإلا "غير ذلك";
    ليكن الضعف: عدد = إذا (ن > 5) { ليكن ت: عدد = ن * 2; ت + 1 } وإلا { 0 };
    اطبع_سطر(الوصف);
    اطبع_سطر(الحجم(ن));
    أرجع الضعف - 15;
}
```

```text
موجب
صغير
```

و`إذا` المستعملة قيمةً لا بد لها من `وإلا`: بدونها لا قيمة حين يكون الشرط خاطئا (`SULTANC-PARSE-IF-WITHOUT-ELSE`).
ويعطي الفرعان النوع نفسه كما تفعل فروع `طابق` التي تعطي قيمة، ويجوز لفرع أن يرجع أو يخرج من حلقة أو يتابعها بدلا من ذلك،
لكن فرعا واحدا على الأقل يعطي قيمة (`SULTANC-TYPE-IF-WITHOUT-VALUE`)، والفرع الذي بلا قيمة لا يبلغ نهايته
(`SULTANC-FLOW-IF-BRANCH-WITHOUT-VALUE`).
والفرع المجرد يمتد ما أمكن، ففي `إذا (ش) أ وإلا ب + 1` تنتمي `+ 1` إلى فرع `وإلا`. والجملة التي تبدأ بـ`إذا` هي جملة `إذا`.
وقيمة `إذا` مطابقة على الشرط ([القسم 6.2](ch06-02-match.md)).

## `طابق`

حين تقرر قيمة واحدة بين حالات كثيرة، تكون `طابق` أوضح من سلسلة `وإلا إذا`. فهي تقارن القيمة بكل *نمط* بالترتيب، وتنفّذ فرع
أول نمط يطابقها:

```sultan
استورد المكتبة.دخ.اطبع_سطر;

عرف اسم_اليوم(اليوم: عدد): نص {
    طابق اليوم مع
    | 5 -> { أرجع "الجمعة"; }
    | 6 -> { أرجع "السبت"; }
    | 1 | 2 | 3 | 4 | 7 -> { أرجع "يوم عمل"; }
    | _ -> { أرجع "ليس يوما"; };
}

عرف الرئيسية(): عدد {
    اطبع_سطر(اسم_اليوم(5));
    اطبع_سطر(اسم_اليوم(2));
    اطبع_سطر(اسم_اليوم(9));
    أرجع 0;
}
```

```text
الجمعة
يوم عمل
ليس يوما
```

أجزاء `طابق`:

- `طابق القيمة مع` تبدؤها.
- كل فرع هو `| النمط -> { … }`.
- داخل النمط، `|` تعني "أو": `1 | 2 | 3` يطابق أيا من الثلاثة.
- `_` يطابق أي شيء. وفي الفرع الأخير يلتقط كل قيمة لم تطابقها الفروع التي قبله.
- `;` بعد الفرع الأخير تنهي `طابق` كلها.

ويمكن أن تعطي `طابق` قيمة أيضا، وفروعها `| النمط -> قيمة`؛ ويبين [القسم 6.2](ch06-02-match.md) كيف.

ويطابق *مجال القيم* `أ..ب` كل قيمة من `أ` إلى `ب`، والحدّان داخلان:

```sultan
استورد المكتبة.دخ.اطبع_سطر;

عرف صف(ن: عدد): نص {
    طابق ن مع
    | 0 -> { أرجع "صفر"; }
    | مدى 1..9 -> { أرجع "رقم واحد"; }
    | مدى 10..99 -> { أرجع "رقمان"; }
    | _ -> { أرجع "أكبر، أو سالب"; };
}

عرف الرئيسية(): عدد {
    اطبع_سطر(صف(7));
    اطبع_سطر(صف(42));
    اطبع_سطر(صف(-3));
    أرجع 0;
}
```

```text
رقم واحد
رقمان
أكبر، أو سالب
```

وتعمل `طابق` مع المحارف والنصوص أيضا:

```sultan
استورد المكتبة.دخ.اطبع_سطر;

عرف الجواب(الكلمة: نص): نص {
    طابق الكلمة مع
    | "نعم" | "حسنا" -> { أرجع "موافق"; }
    | "لا" -> { أرجع "رافض"; }
    | _ -> { أرجع "غير واضح"; };
}

عرف نوع_الحرف(الحرف: حرف): نص {
    طابق الحرف مع
    | مدى 'a'..'z' -> { أرجع "حرف لاتيني صغير"; }
    | مدى '0'..'9' -> { أرجع "رقم"; }
    | _ -> { أرجع "شيء آخر"; };
}

عرف الرئيسية(): عدد {
    اطبع_سطر(الجواب("حسنا"));
    اطبع_سطر(الجواب("ربما"));
    اطبع_سطر(نوع_الحرف('q'));
    اطبع_سطر(نوع_الحرف('7'));
    أرجع 0;
}
```

```text
موافق
غير واضح
حرف لاتيني صغير
رقم
```

### كل قيمة يجب أن تُعالَج

يجب أن يكون في `طابق` فرع لكل قيمة ممكنة. فبدون `_` تترك `طابق` على `عدد` أغلب الأعداد بلا فرع، ويرفضها المترجم:

```sultan fail
عرف الحجم(ن: عدد): عدد {
    طابق ن مع
    | 0 -> { أرجع 0; }
    | 1 -> { أرجع 1; };
}

عرف الرئيسية(): عدد {
    أرجع الحجم(1);
}
```

```text
خطأ[SULTANC-PATTERN-NON-EXHAUSTIVE]: نمط غير شامل: لا تغطي الأذرع ⁨`_`⁩ — يجب أن تطابق كل قيمة من النوع المطابَق إحدى الأذرع.
  --> main.sn:2:10..2:11
   |
 2 |     طابق ن مع
   |          ^
   |
  = مساعدة: أضف ذراعًا لكل حالة غير مغطاة
```

تعلّم الرسالة القيمة المطابَقة، `ن`. و`_` فيها تقوم مقام كل الأعداد التي لا يأخذها فرع؛ ويعالجها فرع `| _ -> { … }` في
الآخر.

وهذا الفحص هو ما جعل `طابق` على `اقرأ_السطر()` في الفصل الثاني تطلب فرعا للخطأ. وهو أنفع ما يكون مع التعدادات في
[الفصل السادس](ch06-02-match.md): فحين تضيف حالة جديدة إلى تعداد، يشير المترجم إلى كل `طابق` لا تعالجها بعد.

## الحلقات

### `طالما`

تكرر `طالما` كتلتها ما دام شرطها صحيحا. ويُختبر الشرط قبل كل دورة، فإن كان خاطئا من البداية لم تُنفَّذ الكتلة أبدا:

```sultan
استورد المكتبة.دخ.اطبع_سطر;
استورد المكتبة.نصوص.أعداد;

عرف الرئيسية(): عدد {
    ليكن المجموع: متغير عدد = 0;
    ليكن ن: متغير عدد = 1;
    طالما (ن <= 100) {
        المجموع := المجموع + ن;
        ن := ن + 1;
    }
    اطبع_سطر(عدد_إلى_نص(المجموع));
    أرجع 0;
}
```

```text
5050
```

ويجب أن يكون في الحلقة شيء يجعل الشرط خاطئا في النهاية، وهو هنا `ن := ن + 1`. ولاحظ أن كتلة الحلقة، بخلاف كتلة `إذا`، لا
تتبعها `;`.

### `لكل`

للحلقة التي تعدّ ثلاثة أجزاء: متغير يبدأ من قيمة، وشرط، وخطوة. وتكتبها `لكل` في سطر واحد، بينها `;`:

```sultan
استورد المكتبة.دخ.اطبع_سطر;
استورد المكتبة.نصوص.أعداد;

عرف الرئيسية(): عدد {
    لكل (ليكن ع: متغير عدد = 1; ع <= 5; ع := ع + 1) {
        اطبع_سطر(عدد_إلى_نص(ع * ع));
    }
    أرجع 0;
}
```

```text
1
4
9
16
25
```

يُنفَّذ الجزء الأول مرة واحدة قبل الحلقة، ويُختبر الشرط قبل كل دورة، وتُنفَّذ الخطوة بعد كل دورة. ولا يوجد العدّاد `ع` إلا
داخل الحلقة.

وللمرور على متجه، عُدّ مواضعه من 0 إلى طوله:

```sultan
استورد المكتبة.دخ.اطبع_سطر;
استورد المكتبة.نصوص.أعداد;

عرف الرئيسية(): عدد {
    ليكن الأسعار: متجه عدد = [12, 45, 30];
    ليكن المجموع: متغير عدد = 0;
    لكل (ليكن ع: متغير عدد = 0; ع < الطول(الأسعار); ع := ع + 1) {
        المجموع := المجموع + الأسعار[ع];
    }
    اطبع_سطر(عدد_إلى_نص(المجموع));
    أرجع 0;
}
```

```text
87
```

### `اخرج_من_حلقة` و `تابع_حلقة`

تخرج `اخرج_من_حلقة` من الحلقة فورا. وتتخطى `تابع_حلقة` باقي الدورة الحالية وتبدأ التالية، وفي `لكل` تُنفَّذ الخطوة مع ذلك:

```sultan
استورد المكتبة.دخ.اطبع_سطر;
استورد المكتبة.نصوص.أعداد;

عرف الرئيسية(): عدد {
    لكل (ليكن ع: متغير عدد = 1; ع <= 20; ع := ع + 1) {
        إذا (ع % 2 == 0) {
            تابع_حلقة;
        };
        إذا (ع > 9) {
            اخرج_من_حلقة;
        };
        اطبع_سطر(عدد_إلى_نص(ع));
    }
    أرجع 0;
}
```

```text
1
3
5
7
9
```

وفي الحلقات المتداخلة تعمل `اخرج_من_حلقة` و `تابع_حلقة` على الحلقة الداخلية.

والحلقة التي تعمل حتى يحدث شيء داخلها تُكتب `طالما (صواب)` مع `اخرج_من_حلقة`، كما في لعبة الفصل الثاني. وهذه تعدّ خطوات
متتالية كولاتز من 27 إلى 1:

```sultan
استورد المكتبة.دخ.اطبع_سطر;
استورد المكتبة.نصوص.أعداد;

عرف الرئيسية(): عدد {
    ليكن ن: متغير عدد = 27;
    ليكن الخطوات: متغير عدد = 0;
    طالما (صواب) {
        إذا (ن == 1) {
            اخرج_من_حلقة;
        };
        إذا (ن % 2 == 0) {
            ن := ن / 2;
        } وإلا {
            ن := 3 * ن + 1;
        };
        الخطوات := الخطوات + 1;
    }
    اطبع_سطر(عدد_إلى_نص(الخطوات));
    أرجع 0;
}
```

```text
111
```

## الخلاصة

رأيت الآن الأجزاء الأساسية للبرنامج: المتغيرات، والأنواع، والدوال، والتعليقات، والتحكم في التدفق. وللتمرن، جرّب كتابة
برامج:

- تحوّل درجات الحرارة بين المئوية والفهرنهايت؛
- تطبع أول 20 عددا من متتالية فيبوناتشي؛
- تطبع جدول الضرب من 1 × 1 إلى 9 × 9.

والفصل التالي عن جزء من السلطان لا تملكه أغلب اللغات: الملكية.
