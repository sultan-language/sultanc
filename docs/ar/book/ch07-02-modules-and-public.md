# الوحدات و `عام`

كل ملف `.sn` وحدة. والوحدة تقرر أي تصريحاتها تستخدمه الوحدات الأخرى: المعلَّم منها بـ `عام` (public). وكل ما سواه *خاص*
(private): يُستخدم داخل الوحدة، ولا يُرى خارجها.

هذه وحدة في الملف `geometry.sn`:

<sub>الملف: geometry.sn</sub>

```sultan file=geometry.sn
عام نوع مستطيل = { العرض: عدد, الارتفاع: عدد };

عام عرف المساحة(م: &مستطيل): عدد {
    أرجع م.العرض * م.الارتفاع;
}

عام عرف المحيط(م: &مستطيل): عدد {
    أرجع ضاعف(م.العرض + م.الارتفاع);
}

عرف ضاعف(القيمة: عدد): عدد {
    أرجع القيمة * 2;
}
```

وبجوارها برنامج يستوردها باسم ملفها:

<sub>الملف: main.sn</sub>

```sultan
استورد "geometry.sn";
استورد المكتبة.دخ.اطبع_سطر;
استورد المكتبة.نصوص.أعداد;

عرف الرئيسية(): عدد {
    ليكن الغرفة: مستطيل = { العرض: 5, الارتفاع: 4 };
    اطبع_سطر(عدد_إلى_نص(المساحة(&الغرفة)));
    اطبع_سطر(عدد_إلى_نص(المحيط(&الغرفة)));
    أرجع 0;
}
```

```text
20
18
```

ترجم البرنامج كالمعتاد، مسمّيا الملف الذي فيه `الرئيسية` فقط، فيتبع المترجم الاستيراد ويجد `geometry.sn` وحده:

```console
$ sultanc main.sn -o rooms
```

يستخدم `main.sn` الأسماء `مستطيل` و `المساحة` و `المحيط`، وهي `عام`. أما `ضاعف` فليست كذلك: فهي دالة مساعدة تحتاجها
`المحيط`، ولا تستطيع وحدة أخرى استدعاءها:

```sultan fail
استورد "geometry.sn";

عرف الرئيسية(): عدد {
    أرجع ضاعف(4);
}
```

## لماذا تبقي أشياء خاصة

كل ما تجعله الوحدة عاما قد تعتمد عليه وحدات أخرى. فتغيير اسم دالة عامة أو معاملاتها يعني حينها تغيير كل وحدة تستخدمها. أما
الدالة الخاصة فتتغير متى شئت، لأن المترجم يضمن أن لا شيء خارج وحدتها يستخدمها.

فاجعل عاما ما تحتاجه الوحدات الأخرى فقط: الأنواع والدوال التي هي غرض الوحدة. وأبقِ الدوال المساعدة التي تنفّذها خاصة.
والتصريحات العامة في الوحدة هي *واجهتها* (interface): ما يستطيع باقي البرنامج الاعتماد عليه.

## الأنواع العامة وحقولها

نوع السجل `عام` يُرى مع حقوله: فالوحدة التي ترى `مستطيل` تستطيع أن تصنعه بـ `{ العرض: 5, الارتفاع: 4 }` وأن تقرأ
`الغرفة.العرض`. وحين يكون للنوع قواعد يجب أن تتبعها حقوله، فقدّم دالة عامة تبنيه بشكل صحيح، مثل `من_المئوية` في الفصل
الخامس، ودع الوحدات الأخرى تستخدمها.
