# دوال تعمل على السجلات

العمليات على السجل في السلطان دوال عادية تأخذ السجل معاملا. ولا يوجد نوع خاص من الدوال ينتمي إلى نوع ما. فالدالة التي تعمل
على `مستطيل` تُكتب كأي دالة، وتُستدعى كأي دالة: `المساحة(&المستطيل)`.

وما تختاره هو كيف تأخذ الدالة السجل، وتحدده قواعد الفصل الرابع:

| الدالة… | تأخذ | ويكتب الاستدعاء |
| --- | --- | --- |
| تقرأ السجل فقط | `&مستطيل` | `المساحة(&المستطيل)` |
| تغيّر سجل المستدعي | `&متغير مستطيل` | `كبّر(&متغير المستطيل, 2)` |
| تحتفظ بالسجل أو تستهلكه | `مستطيل` | `خزّن(المستطيل)` |
| تصنع سجلا جديدا | لا شيء، وترجع `مستطيل` | `دع م: مستطيل = مربع(5);` |

## الوصول إلى الحقول عبر مرجع

حين تأخذ دالة `&مستطيل` يكون معاملها مرجعا لا سجلا. فالسجل هو `*المستطيل_المعار`، وحقله `(*المستطيل_المعار).العرض`.
والأقواس لازمة لأن `.` أقوى ارتباطا من `*`: فـ `*المستطيل_المعار.العرض` تعني "القيمة التي يشير إليها
`المستطيل_المعار.العرض`".

وحذف `*` خطأ يكتشفه المترجم:

```sultan fail
نوع مستطيل = { العرض: عدد, الارتفاع: عدد };

عرف المساحة(المستطيل_المعار: &مستطيل): عدد {
    أرجع المستطيل_المعار.العرض * المستطيل_المعار.الارتفاع;
}

عرف الرئيسية(): عدد {
    دع المستطيل: مستطيل = { العرض: 30, الارتفاع: 50 };
    أرجع المساحة(&المستطيل);
}
```

```text

  --> main.sn:4:26..4:31
   |

```

تقول الرسالة إن `العرض` غير معروف، مع أن `مستطيل` يصرّح به. وذلك لأن المرجع لا حقول له، فالحقول للسجل الذي يشير إليه. فحين
ترى هذه الرسالة لحقل تعرف أنه موجود، فتأكد هل القيمة مرجع، واكتب `(*الاسم).الحقل`.

## دالة تغيّر سجلا

```sultan
استورد المكتبة.دخ.اطبع_سطر;
استورد المكتبة.نصوص.أعداد;

نوع حساب = { المالك: نص, الرصيد: عدد };

عرف أودع(الحساب: &متغير حساب, المبلغ: عدد): فراغ {
    (*الحساب).الرصيد := (*الحساب).الرصيد + المبلغ;
}

عرف اطبع_الحساب(الحساب: &حساب): فراغ {
    اطبع_سطر(استنسخ(&(*الحساب).المالك));
    اطبع_سطر(عدد_إلى_نص((*الحساب).الرصيد));
}

عرف الرئيسية(): عدد {
    دع المدخرات: متغير حساب = { المالك: "ليلى", الرصيد: 100 };
    أودع(&متغير المدخرات, 50);
    اطبع_الحساب(&المدخرات);
    أرجع 0;
}
```

```text
ليلى
150
```

تغيّر `أودع` حساب المستدعي، فتأخذ `&متغير حساب`، ويكتب الاستدعاء `&متغير المدخرات`. أما `اطبع_الحساب` فتقرأ فقط، فتأخذ
`&حساب`.

## دوال تصنع السجلات

الدالة التي تبني سجلا وترجعه هي الطريقة المعتادة لصنع قيم يجب أن تتبع قاعدة. فهنا يجب أن يتفق حقلا `حرارة` دائما، و
`من_المئوية` هي المكان الوحيد الذي يحسبهما:

```sultan
استورد المكتبة.دخ.اطبع_سطر;
استورد المكتبة.نصوص.أعداد;

نوع حرارة = { مئوي: عدد, فهرنهايت: عدد };

عرف من_المئوية(م: عدد): حرارة {
    دع ح: حرارة = { مئوي: م, فهرنهايت: م * 9 / 5 + 32 };
    أرجع ح;
}

عرف الرئيسية(): عدد {
    دع اليوم: حرارة = من_المئوية(30);
    اطبع_سطر(عدد_إلى_نص(اليوم.فهرنهايت));
    أرجع 0;
}
```

```text
86
```

وتسمى هذه الدوال غالبا *البانيات* (constructors). والعرف في أسمائها أن تبدأ بـ `أنشئ_` ثم النوع، أو أن تقول من أين تأتي
القيمة، مثل `من_المئوية`.

## جمع الأجزاء

هذا برنامج المستطيل من القسم السابق، بثلاث دوال على `مستطيل`:

```sultan
استورد المكتبة.دخ.اطبع_سطر;
استورد المكتبة.نصوص.أعداد;

نوع مستطيل = { العرض: عدد, الارتفاع: عدد };

عرف مربع(الضلع: عدد): مستطيل {
    دع م_جديد: مستطيل = { العرض: الضلع, الارتفاع: الضلع };
    أرجع م_جديد;
}

عرف المساحة(المستطيل_المعار: &مستطيل): عدد {
    أرجع (*المستطيل_المعار).العرض * (*المستطيل_المعار).الارتفاع;
}

عرف يسع(الخارجي: &مستطيل, الداخلي: &مستطيل): منطقي {
    أرجع (*الخارجي).العرض > (*الداخلي).العرض && (*الخارجي).الارتفاع > (*الداخلي).الارتفاع;
}

عرف كبّر(المستطيل_المعار: &متغير مستطيل, المعامل: عدد): فراغ {
    (*المستطيل_المعار).العرض := (*المستطيل_المعار).العرض * المعامل;
    (*المستطيل_المعار).الارتفاع := (*المستطيل_المعار).الارتفاع * المعامل;
}

عرف الرئيسية(): عدد {
    دع الكبير: متغير مستطيل = { العرض: 30, الارتفاع: 50 };
    دع الصغير: مستطيل = مربع(10);
    اطبع_سطر(عدد_إلى_نص(المساحة(&الكبير)));
    إذا (يسع(&الكبير, &الصغير)) {
        اطبع_سطر("الكبير يسع الصغير");
    };
    كبّر(&متغير الكبير, 2);
    اطبع_سطر(عدد_إلى_نص(المساحة(&الكبير)));
    أرجع 0;
}
```

```text
1500
الكبير يسع الصغير
6000
```

وحين يكون في البرنامج دوال كثيرة على نوع واحد، ضعها في وحدة خاصة بها بجوار النوع، ويبين
[الفصل السابع](ch07-00-packages-and-modules.md) كيف.

## الخلاصة

- يُصرَّح بالسجلات بـ `نوع الاسم = { الحقل: النوع, … };` وتُبنى بـ `{ الحقل: القيمة, … }`.
- كل حقل يجب أن يُعطى، وحقول السجل `متغير` تتغير بـ `:=`.
- تأخذ الدوال على السجل `&ن` للقراءة، و `&متغير ن` للتغيير، و `ن` للاحتفاظ به.
- عبر المرجع، الحقول هي `(*م).الحقل`.
- الدالة التي ترجع سجلا جديدا هي مكان قواعد حقوله.

السجلات تجمع قيما موجودة كلها معا. والفصل التالي عن قيم تكون واحدا من عدة احتمالات.
