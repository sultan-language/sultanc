# تشغيل برامج أخرى

يستطيع البرنامج أن يبدأ برامج أخرى، وينتظرها، ويقرأ كيف انتهت. وتبني `المكتبة.عمليات.أمر` *أمرا*: البرنامج الذي يُشغَّل
ووسائطه. وتشغّله `شغل_الأمر` وتنتظر انتهاءه، وترجع *حالة خروجه*:

```sultan
استورد المكتبة.دخ.اطبع_سطر;
استورد المكتبة.نصوص.أعداد;
استورد المكتبة.نصوص.تحويل;
استورد المكتبة.عمليات.أمر;
استورد المكتبة.عمليات.عملية_ابن;

عرف الرئيسية(): عدد {
    ليكن صدى: متغير أمر = أنشئ_أمرا(&"echo");
    أضف_وسيطة_للأمر(&متغير صدى, &"أهلا من عملية طفلة");
    طابق شغل_الأمر(&صدى) مع
    | نتيجة.نجح(حالة_إنهاء.خرج(الرمز)) -> { اطبع_سطر(صل_نصين(&"حالة الخروج ", &عدد_إلى_نص(الرمز))); }
    | نتيجة.نجح(_) -> { اطبع_سطر("أوقفته إشارة"); }
    | نتيجة.خطأ(_) -> { اطبع_سطر("تعذر تشغيل echo"); أرجع 1; };
    أرجع 0;
}
```

```text
أهلا من عملية طفلة
حالة الخروج 0
```

والبرنامج الجديد، *العملية الطفلة* (child process)، يرث الخرج القياسي لأبيه، فيظهر سطره قبل سطر الأب.

وتأخذ `أنشئ_أمرا` اسم البرنامج، والاسم الذي بلا مجلد، مثل `echo`، يُبحث عنه في المجلدات المسرودة في المتغير `PATH`. وتضيف
`أضف_وسيطة_للأمر` وسيطا واحدا، ويُمرَّر كل وسيط كما هو دون shell بينهما، فلا تحتاج المسافات وعلامات التنصيص في الوسيط إلى تهريب،
ولا يُساء فهمها.

وحالة الخروج تعداد: `حالة_إنهاء.خرج(الرمز)` حين ينتهي البرنامج بنفسه بحالة، أو حالة أخرى حين يوقفه النظام بإشارة. وتقول
`هل_نجح_الأمر(&الحالة)` هل انتهى بـ 0.

وتستطيع `المكتبة.عمليات.أمر` أيضا أن تعطي الطفل مدخلاته، وأن تلتقط خرجه في متجه بايتات بدلا من تمريره، وأن تضبط بيئته ودليل
عمله، وأن تبدأه دون انتظار ليعمل بجوار أبيه. وفي مجلد `examples/ar/process` من المستودع برنامج لكل منها.
