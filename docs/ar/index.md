# توثيق السلطان

هذا توثيق السلطان، وهي لغة برمجة أنظمة مستضافة ذاتيًا (self-hosted)، وكلماتها المفتاحية موجودة بالعربية
والإنجليزية بوصفهما واجهتين للصياغة نفسها. والصفحات مجمّعة بحسب الغرض: الدليل يعلّم اللغة، والمرجع يحدد قواعدها،
وصفحات البنية الداخلية تصف طريقة عمل المترجم، وصفحات المساهمة تشرح كيف تعدّله.

يقدم [ملف README](../../README.md) نظرة موجزة على المشروع وطرق بنائه.
