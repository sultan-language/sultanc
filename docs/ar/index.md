# توثيق السلطان

هذا توثيق لغة السلطان، وهي لغة برمجة أنظمة مستضافة ذاتيًا (self-hosted)، تُكتب كلماتها المفتاحية بالعربية
أو بالإنجليزية، وكلتاهما صياغة للغة نفسها. وقد قُسّمت الصفحات بحسب الغرض منها: فالدليل يعلّم اللغة، والمرجع يحدد
قواعدها بدقة، وصفحات البنية الداخلية تشرح طريقة عمل المترجم، وصفحات المساهمة تشرح كيفية تعديله.

وتقدّم [الصفحة الرئيسية للمشروع](../../README.md) نظرة موجزة عليه وعلى طرق بنائه.
