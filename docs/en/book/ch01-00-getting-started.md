# Getting Started

This chapter gets SultanC onto your computer and runs your first two programs: one compiled by hand
with `sultanc`, and one built by Supax, the package manager. It has three sections:

- [Installation](ch01-01-installation.md): building the compiler on Linux, macOS, Windows and other
  systems, and installing it with Supax.
- [Hello, World!](ch01-02-hello-world.md): writing and running a program, and reading the compiler's
  error messages.
- [Hello, Supax!](ch01-03-hello-supax.md): creating a project, the way the rest of this book works.
