# Common Programming Concepts

This chapter covers ideas that appear in almost every programming language, and how they work in
SultanC: variables, the basic types, functions, comments and control flow. Every SultanC program uses
them, and every later chapter builds on them.

Chapter 2 used several of these without much explanation. Here each one gets its full rules: what you
may write, what the compiler refuses, and why.

The language reserves some words for itself, the *keywords*: `def`, `let`, `if`, `match` and others.
You cannot use them as names of variables or functions. Each keyword has an English and an Arabic
spelling, and both mean the same thing. [Appendix A](appendix-01-keywords.md) lists them all.
