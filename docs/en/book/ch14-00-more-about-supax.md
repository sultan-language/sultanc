# More about Supax

Chapter 7 used Supax to build a package with a library, and chapter 11 to test it. This chapter covers
what Supax does for code you did not write: depending on other packages, keeping builds exactly
repeatable, and publishing your own package for others.

- [Dependencies](ch14-01-dependencies.md)
- [`Supax.lock` and Reproducible Builds](ch14-02-the-lock-file.md)
- [Publishing a Package](ch14-03-publishing.md)

`supax --help` lists every command, and the [Supax guide](https://github.com/sultan-language/supax/blob/main/docs/en/guide.md)
describes every option.
