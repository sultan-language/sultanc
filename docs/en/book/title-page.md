# The SultanC Book

*by the SultanC contributors*

This book teaches SultanC, a systems programming language whose keywords exist in Arabic and in English.
It starts from installing the compiler and ends with a multithreaded web server.

This edition writes its programs with the English keywords. The [Arabic edition](../../ar/book/title-page.md)
teaches the same language with the Arabic keywords, in the same chapters, with the same programs.

Every program in this book is compiled and run against the current compiler by
`tools/docs/check_guide.py`, and every output shown is what the program printed.
