# Using Records to Structure Related Data

A *record* groups several values that belong together, and gives each one a name: a point has an `x`
and a `y`, a bank account has an owner and a balance. Records are how you describe, in types, the things
your program is about.

A tuple also groups values, but its parts have no names. A record's fields do, so `account.balance`
explains itself, and the compiler checks every use of every field by name.

This chapter shows how to define records and make values of them, works through a program that gets
clearer with each step toward records, and shows how functions work with records.
