# Why SultanC

When I was young I loved programming and wanted to learn it, but everything in it was in English: the
languages, the books, even the error messages. I did not know English then, so the dream waited years until I
learned it. Ever since, I have wished for a real Arabic programming language: not a teaching toy for children,
and not a word-for-word translation of another language's keywords, but a complete systems language you can
build real software with.

SultanC grew out of that wish. Work on it began in 2024, and the road was not easy: the compiler was
first written in OCaml, the way Rust began, then rewritten entirely in C, and finally written in SultanC itself
until it could compile itself. The first OCaml versions are still preserved on the
repository's releases page.

The goal is that anyone standing today where I stood back then finds a way into programming in their own
language: Arabic keywords, Arabic error messages and Arabic documentation, without giving up the power and
performance of a systems language.
